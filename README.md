## 이 실험실이 하는 일

작품 하나가 세상에 나왔을 때 **어디까지 갈지의 순위**를 예측한다.
절대값("관객 몇 명")은 팔지 않는다 — 자릿수를 유의미한 확률로 틀린다는 것을
스스로 측정했기 때문이다. 파는 것은 셋이다.

|  | 무엇 | 조건 |
|:--:|---|---|
| **1** | **순위와 구간** — 도메인 안에서의 상대 위치 | 챔피언 합동 모형 · 판 ρ **0.47034** |
| **2** | **드리프트 보정 절대값** | **자(불확실성 눈금)와 함께만** · 노트 791~809 사슬 |
| **3** | **정직한 능력 카드** | 무엇을 **못 보는지**의 목록까지 포함 |

## 🔴 자(尺) — 이 저장소에서 제일 중요한 한 줄

> **채택 문턱이 없으면 문턱이 결론의 부호를 정한다.**
> 같은 자료·같은 팔인데, 자를 바꾸면 같은 결론이 **36%도 되고 146%도 됐다**(노트 890~891).

```
판 ρ            0.47034 ± 0.0021  ← 0.0021 은 SD 다. SE 아님 (SE = 0.00060)
분모            12 도메인 · 유보 3,775 행 · 씨앗 0~11
재현            python3 -m runners.rerun112  →  runners/out112_board.json
                (2026-08-10 실측 · 씨앗 0 단독 0.4731063028988083 · 측정 산출물은
                 runners/out898_board.json · 판정은 runners/out898_verdict.json)

🔴 2026-08-10 · 이슈 #117(노트 898) — 판과 자가 **다른 스피어만**을 쓰고 있었다
                판:  state/rank_test.py 의 서수 순위(동률을 **배열 순서**로 깬다)
                자:  ruler890.sp · thresh891 의 동률 평균(midrank)
                그래서 「판 Δ 를 문턱에 댄다」가 성립하지 않았다. **판을 자에 맞췄다.**
                근거는 크기가 아니라 원칙이다 — 행을 20번 섞으면 옛 함수는 12/12
                도메인에서 ρ 가 갈렸고 폭이 최대 0.1562 였다(새 함수는 0/12 · 폭 0).
                옮김 +0.00051922 ± 0.00003993(SE) · BCa [+0.00044, +0.00059] · 12/12 양수
                움직인 것은 사실상 한 도메인 — 시장팝업(126행에 예측 고유값 15) 이
                판 기여의 98.4% 다. ⚠ 개선이 아니라 **편의 제거**다
딱지 붙은 값    0.46982 ± 0.0020  ← **서수 시대 값**(2026-08-10 오전). 이력으로만 읽는다

딱지 붙은 값    0.4710 ± 0.0021   ← **837 시대 값**. 837 경로로는 **오늘도 재현된다**
                (0.4709970 ± 0.0021019 · runners/out112_refit837.json). 재현 안 되는 것은
                "챔피언 경로로" 다 — 그래서 판정에서 뺐다(이슈 #112 · 티처 #59 C1).
                은퇴한 두 규약 위의 수다 —
                ① 채점 배치 = post ∩ 라벨(노트 855 가 post 전체로 바꿨다)   +0.00072
                ② 스피어만 구현 = 동률 평균(scipy) 대 서수(state/rank_test.py:44) +0.00062
                (씨앗 0 실측 · 합 +0.00133952 가 비트 동일 · runners/out898_wire.json)
                🔴 옛 인쇄물의 원인 ②("_fit_on 이 GBM random_state 를 씨앗으로 갈아
                끼운다")는 **틀렸다** — lab/forms.py:702-703 이 자루마다 random_state 를
                자루 색인 k 로 덮으므로 kw['random_state'] 는 GBM 에 한 번도 안 닿는다
                (노트 898 실측: kw=7 인데 자루 32개가 [0..31] · 이슈 #117 · 티처 #60 C1)

🔴 자는 하나가 아니다 — 개입의 꼴에 달렸다 (노트 892)
 ① 열 수가 그대로인 개입   0.00353   손잡이·치환·자료 고침 (잠정 · 대역 0.00312~0.00393)
 ② 열이 느는 개입          0.01055   축을 하나 더 넣는다 (1열) — ①의 2.99배
                           0.01735   (2열)
                           0.02126   (3열) — ①의 6.02배

은퇴한 자       0.0045  ← 11 도메인·유보 3,369 시대 유물. 어느 쪽에도 쓰지 않는다
실격된 자       0.0011  ← 씨앗 잡음만 담아 표본 잡음이 없다
```

①은 **"두 팔이 실제로 같을 때 판 Δ 가 흔들리는 폭의 2σ"** 다 —
**참 Δ = 0 인 널 팔 쌍**(같은 팔의 씨앗 0–5 앙상블 대 6–11 앙상블)으로 실측한다.
씨앗 잡음과 표본 잡음을 **둘 다** 담지 않은 자는 자격이 없다.

②는 **"신호가 0 인 같은 꼴의 개입이 판을 흔드는 폭의 μ+2σ"** 다 —
순수 난수 열을 **뽑기 12회**로 넣어 실측한다(1열 μ +0.00558 · 3열 μ +0.01335 ·
12뽑기 전부 판이 내린다). **참 Δ 가 0 이 아니다** — 신호가 하나도 없어도
열이 늘면 판이 움직인다. 열이 느는 개입에 ①의 자를 대면 **3배 헐겁게 읽는다.**

> ⚠️ **0.00353 은 아직 '정본'이 아니라 '잠정'이다.** 프레시 티처 세션(#54)이
> *"이 실험실이 잰 잡음 바닥보다 낮다"* 를 지적했고, **노트 892 가 12도메인에서
> 다시 재서 그 지적이 옳음을 확인했다** — 다만 티처가 인용한 0.0043 은 노트 742 가
> 이미 이상치로 격하한 **죽은 숫자**였고, 실제 격차는 1.22배가 아니라 **2.99~6.02배**다.
> 🔴 **그래서 답은 "문턱을 올려라" 가 아니라 "널이 두 종류다" 였다.**
> 새 바닥의 **정본 채택은 다음 사이클의 확인 측정 뒤다**(첫 양수를 그대로 채택하지 않는다 · 노트 133).

## 연구 루프 — 한 사이클의 규율

**모든 사이클은 프레시 세션에서 돈다.** 누적 맥락이 다음 사이클을 오염시키지 않게 하기
위해서다. 그래서 **세션 사이의 유일한 전달 수단은 저장소와 인계 카드**이고,
사이클 끝의 카드 갱신은 선택이 아니라 필수다.

```
① 사이클 열기 (ingest.cycle_open — 수집·전향·규약검사·트랙)
② 프레시 연구 세션 ─ 사전등록 → 배선 검사 → 측정 → 판정
③ 논문 (figure + 창의적 제목) → build → Slack DM
④ 원장 기재 → 커밋 → note/NNN-slug push → PR
⑤ 프레시 티처 세션 ─ 이 사이클을 안 돈 눈이 수치를 직접 다시 센다
⑥ 인계 카드 갱신 ─ 빼먹으면 프레시 세션 전략 자체가 무효다
⑦ 멈추지 않는다
```

**순서는 강제다.** 사전등록보다 측정이 먼저 오면 그 측정은 무효다.
배선 검사(sha256 비트 대조 · 그 열이 정말 모형에 닿았나 · 항등 통제)를
통과하지 못한 수는 "측정했다"고 부르지 않는다.

- **첫 양성은 채택하지 않는다** (노트 133) — 확인 사이클이 따른다.
- **씨앗 SE 는 재현성이지 일반화가 아니다** (노트 613) — 채택 문턱은 표본 잡음을 담아야 한다.
- **바닥(잡음 추정)도 뽑기 6회 이상** (규약 20 확장) — 잡음의 잡음을 안 재면 비율을 두세 배 틀린다.
- **문턱 미달은 "못 넘었다"가 아니라 "이 자를 못 넘었다"** 로 적고 도메인 Δ 를 병기한다.
- **BQ/GCP 는 읽기 전용** — SELECT 와 메타 조회만. 변경물은 로컬로 준비해 담당자에게 전달.
- **유료 API 는 기본 차단** (`core/noapi.py`) — 무료 2패스 경로(`--agent-dir` / `--predictor agent`)가 기본값이다.

### 티처 세션이 하는 일

이 사이클을 돌지 않은 세션이 **편들 이유 없이** 비평한다. 넷을 본다 —
① 인용된 수치가 실제로 그 값인지 **직접 센다** ② 죽은 숫자(은퇴한 상수가 살아 있는 곳)
③ **배선 없이 "측정했다"고 한 곳** ④ 규약 위반. 치명·중대·경미 전량을 원장에 적고
**다음 사이클의 입력으로 쓴다.**

<details>
<summary><b>티처가 실제로 뒤집은 것들</b> (펼치기)</summary>

- **#52** — *"아이돌 항목 0개"* 라고 적힌 것을 세어 보니 **6개**였다.
- **#53** — 노트 890 의 머리기사가 **판정 불능인 차**였다(오차막대가 없었다). 그리고 같은 자료가
  *"가중이 아이돌을 3.52배 누른다"* 를 보여 주는데 노트는 반대로 읽었다.
- **#54** — 새로 세운 채택 문턱이 **이 실험실이 잰 잡음 바닥 아래**로 내려갔다.
  덤으로: 오발률을 문턱이 담은 두 잡음원 중 **하나만** 담은 널에 댔고,
  "예측 8/8 적중"은 **0/8 예측 · 8/8 검산**이었다.
- **노트 892 가 #54 를 되받았다** — C1 의 **결론은 옳고 근거는 죽은 숫자**였다.
  인용한 0.0043 은 노트 742 가 이미 3.7σ 이상치로 격하한 값이고, 그 정정은
  `ingest/audit.py` 의 죽은 숫자 표에 **등록돼 있었다** — 오늘 검출기를 돌리면
  티처가 적은 인계 카드 그 줄이 걸린다. 12도메인 실측은 **1.22배가 아니라 2.99~6.02배**다.
  그리고 M6 의 *"살아 있는 판정 ≥17파일"* 은 과대 계수였다(실제 셋).
  **비평도 자기 저장소의 검출기를 먼저 돌려야 한다.**

</details>

## 정직 조항 (능력 카드 발췌)

- 맨 절대값 예측은 **팔지 않는다** — 보정 후에도 자릿수(10배)를 14% 확률로 틀린다.
- *"50건이면 전이와 동급"* 온보딩 서사는 **폐기됐다**(노트 821~822) — 과거 자료를 가진
  고객은 자기 릿지가 우리 전이보다 낫다. 전이의 가치는 **자료 0건 구간**과
  단독 모형이 성립 불가한 도메인이다.
- 감쇠–이중피크 곡선 구분은 현재 자(RMSE)로 **못 본다** — 형태 특징 자로 수리 중(노트 823).
- 예측은 오픈 전 봉인 — **커밋 해시 없는 예측은 존재하지 않는 예측이다.**
- 생존 편향(실행된 것만 관측된다)은 모든 리포트에 명시하고 안고 간다.
- **역사 기록은 고치지 않는다** — 원장·논문·주석의 옛 문턱 0.0045 는 그때 그 자로 내린
  판정이라 고치면 이력이 거짓이 된다. **판정에 쓰는 곳만** 새 값을 쓴다.
