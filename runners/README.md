# runners — 판정을 낳은 러너와 출력의 보존소

**규약(티처 #10 · 2026-08-08): 판정을 낳은 러너·출력 JSON 은 판정과 같은 커밋에 넣는다.**

배경: 노트 683 이 "채택 숫자를 낸 코드가 커밋에 없다"를 적발했고(규약 44 의 어미),
노트 828 이 자(pairboot)를 저장소에 넣었는데, 841~843 의 문패 종결·상업 창 판정이
다시 스크래치 러너 위에 섰다(티처 #10 적발 — 커밋 변경 파일이 장부 셋뿐).
이 디렉터리는 세션 스크래치에 살아남아 있던 러너 151개 + 출력 23개를 소급 보존하고,
이후 사이클은 **새 러너를 판정 커밋에 같이 넣는다.**

- 파일명 규칙: `<이름><노트번호>.py` · 출력은 `out<노트번호>*.json`
- 러너는 스크래치 경로(sys.path)에 의존할 수 있다 — 재실행 시 경로만 고치면 된다.
  보존 목적이 우선이고 실행 보증은 각 노트의 "재현" 절이 정본이다.
