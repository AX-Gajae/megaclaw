## §2 러너와 CLI — 🔴 **원리상 도는 명령을 적는다**

971 의 사전등록은 자 팔 CLI 를 `--only a b c d`(공백)로 적었는데 `--only` 는 **쉼표 구분
하나**라 **원리상 안 돌았다**. 그리고 `--genver` 를 안 적어 「항진명제 0」이 **기본값에서는
거짓**이었다. 972 는 **돌 명령을 그대로 박는다.**

### §2-가 자 팔 — `runners/meta965.py` (972 가 `--poolscope` 를 더한다)

```
python3 runners/meta965.py \
  --only runners/predict971.py,runners/dropaudit969.py,runners/recommit970.py,runners/meta965.py \
  --mine runners/predict971.py \
  --genver 2 --slicer new --passkey suffix --poolscope file \
  --out runners/out972_meta_file.json
```
그리고 같은 명령에서 `--poolscope func` → `out972_meta_func.json`,
`--passkey exact` 짝 둘 → `out972_meta_file_exact.json` · `out972_meta_func_exact.json`.
🔴 **`--genver 1` 짝도 낸다**(`out972_meta_g1_*.json`) — 971 의 「항진명제 0」이
**`--genver 2` 에서만 참**이었기 때문이다.

🔴 **새 인자 `--poolscope file|func`**
- `file` = 965~971 그대로. 자 B 의 값·열쇠 풀을 **파일 전체 AST** 에서 거둔다.
- `func` = **972 수리**. 자리를 **감싸는 함수의 AST** 에서만 거둔다(감싸는 함수가 없으면 모듈).
- 🔴 **기본값을 `func` 로 바꾼다.** 노트 898 의 「기본값 보존」 규칙과 정면으로 부딪히지만,
  **`file` 은 원리상 틀린 자**다(무관한 줄이 판정을 뒤집는다). **바꾼 사실을 산출물과
  원장에 크게 적고 `file` 을 인자로 남겨 전후를 나란히 싣는다.**

## §3 예측 팔 — 🔴 **채택 조건을 다시 못 박는다**

### §3-가 정본 자 (**하나**)
🔴 **묶음 Δρ_pred(C−B) 의 유보 결과 순열 귀무에서의 단측 p.**

- 귀무: 도메인 **안에서** 유보 결과 `y_ho` 를 무작위로 섞는다. 예측 `pB`·`pC` 는
  **학습에서만 적합**되어 고정이므로, 섞기는 **결과와 예측의 짝만** 깬다.
- 뽑기 **B_perm = 4000** · 씨앗 **972**.
- p = (섞은 Δ ≥ 실측 Δ 인 뽑기 수 + 1) / (4000 + 1).
- 🔴 **채택: p ≤ 0.05.** 그 하나다.
- 🔴 **무작위 열 귀무(p = 0.0220)는 안 쓴다** — 티처 #110 실측으로 그 귀무의 중심이
  **−0.0056** 이라 **반보수적**이다.

### §3-나 별도 자 (**부호 일관성** · 1-ⓓ)
🔴 **같은 순열 귀무에서 「7 도메인 전부 Δ > 0」의 p.**
- 971 은 ⑤를 「≥5」로 못 박아 **자기 결과를 과소평가**했다(≥5 는 귀무에서 22.6%).
- **채택: p ≤ 0.05.** 🔴 **이것은 §3-가 와 다른 것을 가른다** — 크기가 아니라 **부호 일관성**.
- 🔴 **둘을 한 판정으로 안 섞는다.** 각각 따로 적는다(조항 60).

### §3-다 폭 — 🔴 **학습을 재표집한다**
971 의 붓스트랩은 **유보만** 되뽑았다. 972 는 셋을 전부 낸다:
1. **유보만**(971 판 · 재현 대조)
2. **학습만** 재표집(도메인 안에서 학습 행을 되뽑아 **다시 적합**, 유보는 고정)
3. **이중**(학습·유보 둘 다)
뽑기 **2000** · 씨앗 **972**. 🔴 **판정에 쓰는 폭은 ③ 이중이다.**

### §3-라 잎-하나-빼기 (**사전등록에 박는다**)
🔴 도메인 하나를 빼고 묶음 Δ 를 다시 낸다. **7 개 전부.**
- 보고: **최소값** · **어느 도메인이 최대 기여인가** · **기여 %**.
- 🔴 **이것은 채택 조건이 아니라 필수 병기 항목이다** — 안 적으면 F 반증조건에 걸린다.
