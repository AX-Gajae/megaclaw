### §0-라 🔴🔴🔴 **법을 «먼저» 적는다** — 군집 SE 의 기대 크기

도메인 `d` 개, 도메인 `d` 의 유보 행 `n_d`. 도메인별 통계량 `v_d`(ρ 또는 Δρ)를

```
v_d = μ + u_d + e_d,     u_d ~ (0, τ²)  «도메인 사이 진짜 흩어짐»
                          e_d ~ (0, σ²/n_d)  «유보 표본 잡음»
```

로 본다. 도메인 균등 평균의 **군집 SE** 는

```
🔴  SE_clu(d, n)  =  sqrt( (τ² + σ²/n̄) / d )
🔴  바닥(n→∞)     =  τ / √d          ← 자료를 아무리 늘려도 «못 내려간다»
🔴  t > 2 에 필요한 도메인 수  d* = 4 (τ² + σ²/n̄) / μ²
```

**그러므로:**

- **`N_B` 는 `d` 도 `n̄` 도 못 만진다**(§0-나). 🔴 **`N_B` 가 군집 SE 에 닿는 유일한 통로는
  `τ`(도메인 사이 흩어짐)와 `μ`(효과 크기)뿐이다.**
- **벽은 「자료의 벽」이 아니라 「`d` 의 벽」이다.** 이것이 이 사이클의 세계 명제 후보다.

**이 법을 994 의 실측에 «되맞춰» 검산했다**(비맹검 · §0-사):
`out994_org.json` 의 원점1 거리1 대 거리4 도메인별 ρ 차 —
`게임 −0.074062 · 만화 +0.402320 · 모바일 +0.235349 · 세계애니 +0.197818 · 애니 −0.109727 ·
웹툰 +0.361476 · 펀딩 −0.101336`.
→ `d=7 · μ̂=0.130262 · τ̂=0.222135 · SE=τ̂/√7=0.083959 · t=1.5515`.
**994 가 뽑기로 낸 `t_clu` 1.58 과 «2 % 안»에서 맞는다.** 법이 선다.
→ **994 의 `d* = 4τ̂²/μ̂² = 11.632` — 즉 「도메인 12 개」면 넘었다. 994 는 7 이었다.**
