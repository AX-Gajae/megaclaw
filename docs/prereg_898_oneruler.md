## 🔴 판정 규칙 — **측정 전에 못 박는다**

> **"어느 쪽이 큰가"로 고르지 않는다.** 큰 쪽을 고르는 규칙은 사후 선택이다.
> 아래 규칙은 **Δ 의 부호와 크기를 보기 전에** 결정을 낸다.

### 원칙

- **P1 · 순서 불변** — 통계량이 **자료의 행 순서**에 의존하면 안 된다.
  같은 자료를 섞었더니 값이 바뀌는 것은 통계량이 아니라 **정렬의 함수**다.
- **P2 · 자는 하나다** — 판과 자가 다른 함수를 쓰면 「판 Δ 를 문턱에 댄다」는 문장이 성립하지 않는다.
- **P3 · 표준 정의** — Spearman ρ 의 표준 정의는 **midrank**(동률 평균)다.

### 규칙

- **R-1** 측정 러너가 **행 순서 의존성을 먼저 실측한다**: 12도메인 각각에서 (예측, 라벨) 짝을
  무작위로 **20번 섞어** 두 함수로 ρ 를 재고 **값의 가짓수**를 센다.
  - 서수가 **가짓수 > 1**(순서 의존) 이고 동률 평균이 **가짓수 = 1**(불변)이면 → **팔 B 를 정본**으로 삼는다(P1).
- **R-2** R-1 이 예상과 다르면(둘 다 불변 / 둘 다 의존) P1 로는 못 고른다 → **P3 로 팔 B**,
  그리고 *"P1 이 안 갈랐다"* 를 판정문에 적는다.
- **R-3** 🔴 **팔 B 를 못 채택하는 유일한 사전 조건**(실패 조건):
  - (a) **887형 중립화** — midrank 가 NaN 하나로 열을 통째 NaN 으로 만드는 경로가 채점에 열려 있고
    `_score_one` 의 `ok` 마스크가 그것을 못 막는다. **실측으로 확인한다**(NaN 을 심어서).
    못 막으면 **팔 A 유지** + 사유 기재.
  - (b) 동률 평균 아래에서 **12도메인 중 어느 하나라도 ρ 가 유한하지 않게** 된다.
  - ⚠ 동결 대조(890 배선 ㄷ `EXPECT_POOLED_K1_S0` · 891 배선 ㄴ)가 **깨지는 것은 실패 조건이 아니다** —
    팔 B 는 그 값을 바꾸는 것이 목적이므로 **예상된 결과**다. 동결값을 갱신하고 옛 값은 이력으로 남긴다.
- **R-4** 🔴 **결정이 정본을 얼마나 옮기는지는 결과로만 보고**한다. Δ 의 부호·크기는 **판정에 안 쓴다.**
- **R-5 · 자에 대한 사전 예측(반증 가능하게 적는다)**: 팔 B 를 골라도 **문턱 0.00353 은 안 움직인다.**
  근거: `thresh891` 의 R5 = 2·√(씨앗성분² + 행짝성분²) 인데 두 성분이 **전부 `R890.sp`(동률 평균)**
  으로 계산된다(`thresh891.py:144,154-158,219`). `rank_test` 는 R5 에 안 들어간다.
  - 이 예측을 **실측한다** — `runners/out891_fits.npz` 캐시(재적합 없음)로 **팔 A 아래의 R5**
    (모든 `sp` 를 서수로 바꾼 것)를 다시 계산해 두 값을 병기한다.
  - **예측이 틀리면**(팔 B 아래 R5 ≠ 0.00353) 그 사실을 판정문 **맨 앞**에 적는다.
  - ⚠ 문턱 0.00353 은 티처 #54 가 **「잠정」**으로 강등했고 방어 대역은 **0.00312~0.00393** 이다.
