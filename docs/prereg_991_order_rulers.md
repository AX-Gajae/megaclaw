### 1-1 명제 `W1′` — **분해의 답은 「순서」가 정한다. 순서를 고르는 것이 곧 답을 고르는 것이다**

> 🔴🔴🔴 **990 의 `W1`(「부호를 만든 것은 굶김이다」)은 «무조건 명제»가 아니다.
> 그것은 「`R_pool` 자 · 순서 A」라는 «두 조건» 아래의 명제다.**

**예산 `N` · `α = 0.95` 에서 네 칸을 정의한다(같은 씨앗·같은 겹·같은 λ·같은 뽑기 색인):**

| 칸 | 정의 |
|---|---|
| `B` | `ρ(base N)` — hplt 0 |
| `M` | `ρ(base N + hplt round(αN))` |
| `H` | `ρ(base N−round(αN) + hplt round(αN))` — 🔴 **977 이 실제로 쓰는 칸** |
| `S` | 🔴 **`ρ(base N−round(αN))` — hplt 0.** **991 이 «새로» 재는 칸이다** |

**두 순서와 대칭 배분:**

| | 증강 | 굶김 | 합 |
|---|---|---|---|
| **순서 A**(증강 먼저) | `A = M − B` | `S_A = H − M` | `≡ Δ` |
| **순서 B**(굶김 먼저) | `A′ = H − S` | `S_B = S − B` | `≡ Δ` |
| **상호작용** | 🔴 `A′ − A` (`= S_A − S_B`) | | |
| **대칭(Shapley)** | `(A + A′)/2` | `(S_A + S_B)/2` | `≡ Δ` |

- 🔴🔴🔴 **`Δ ≡ 증강 + 굶김` 은 `(x−y)+(z−x) = z−y` 라 «어떤 수를 넣어도» 성립한다.
  그러므로 「잔차 0」은 «검정력 0» 이고 세계에 대해 아무것도 안 말한다.**
  **991 은 그 잔차 검사를 배선 명부에서 «진단»으로 내린다**(§1-4 ㉠).
- 🔴🔴🔴 **명제의 꼴**: **「`R_pool` 자 · 순서 A 에서 굶김이 Δ 의 98.63% 를 진다.
  같은 자 · 순서 B 에서는 증강이 `+0.028` 로 «양수»다. 균등·챔피언 자에서는 굶김이 «양수»다.
  그러므로 「무엇이 부호를 만들었나」는 «자료의 사실이 아니라 자와 순서의 사실»이다.」**
- 🔴 **여섯 성분(자 3 × 순서 2) 각각에 «도메인 군집 SE» 와 `t_clu` 와 LODO 를 붙인다**(§1-3).
  **「굶김이 98.63% 를 만들었다」가 SE 를 넘는지 아무도 안 쟀다.**

### 1-3 🔴🔴 **SE 는 「도메인 군집」으로** (식을 측정 전에 박는다 · 990 §1-6 승계)

- 도메인 `d` 를 군집으로 본다. `Δ = Σ_d w_d Δ_d` (`Σ w_d = 1`, `Δ_d` = 씨앗 평균), 그러면
  **`SE_clu² = (G / (G−1)) · Σ_d w_d² (Δ_d − Δ)²`** (`G` = 도메인 수). **`t_clu = Δ / SE_clu`.**
- 🔴🔴🔴 **991 은 이 식을 `Δ` 뿐 아니라 «여섯 성분 전부»와 «상호작용»과 «대칭 배분»에 물린다.**

  유보 표집 분산이 원리상 0 이므로 판정에 «못 쓴다».**
