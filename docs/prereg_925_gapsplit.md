## §0 이 사전등록의 약점 — 🔴 **먼저 적는다**

### §0-가 · 같은 커밋이면 증거는 mtime 뿐이다

이 사전등록과 러너와 산출물이 **같은 커밋에 들어가면**, "측정 전에 박았다"의 증거는
**파일 mtime 하나뿐이고 mtime 은 위조 가능하다**. 커밋 사이의 순서를 보여 줄 수 없다.
읽는 사람은 이 문단을, 그리고 `mtime(사전등록) < mtime(러너) < mtime(산출물)` 만 갖는다.

🔴 **그리고 티처 #73 M8 이 922 에서 잡은 병을 여기서는 피한다**: 헤더의 시각을 **손으로 타자하지 않는다.**
절차 — ① 이 파일을 `2026-08-11T18:15:27+09:00 (KST) = 2026-08-11T09:15:27+00:00 · st_mtime = 1786439727.304272` 자리표시자로 쓴다 ② 스크립트가 `st_mtime` 을 읽어 그 자리에 박는다
③ 스크립트가 `os.utime` 으로 mtime 을 **원래 값 그대로 되돌린다**.
그래서 헤더 시각과 mtime 은 **정의상 같다**. 어긋날 수가 없다. (스크립트: `scratchpad/g925/stamp.py`)

### §0-다 · 🔴 **이 사이클의 목표값은 이미 남이 재 봤다**

## §6 판정 규칙 — 🔴 **측정 전에 박는다. 어느 쪽이든 끝난다. 「판정 불능」 출구는 없다**

  → 🔴 **「이 자로는 순서를 못 잰다」가 확정된다.** ③ 의 첫째 자는 **0.5 → 0** 으로 되돌린다.

  다음 자의 후보를 최소 하나 이름 짓는다.

- 🔴 **어느 쪽이든 다음 두 줄을 반드시 헤드라인에 같이 적는다**:
  1. **바닥이 0 이 아니다** — 시간 구조가 전혀 없는 세계에서도 이 자는 유의하게 이긴다.
     기후값 팔이 **격자를 모르는 팔**이기 때문이다. 그 이득 중 `prevmed` 의 몫을 **내가 세어** 적는다

## §7 병기 — 🔴 **바닥을 0 으로 내려 본다** (티처 #73 M4 · #177 의 덤)

N2 세계에서도 자가 **+0.2827 로 유의하게 이기는** 이유는 기후값 팔이 **격자를 모르는 팔**이라서다.
그래서 **기후값 팔에 격자 정보를 넣은 판**을 하나 더 낸다.

- **새 바닥 팔 `가′ 기후값+prevmed`**: `T["2수준"][(dow, qtr, bin(prevmed))]` → 없으면 달력 셀 → 없으면 전체 중앙값.
  즉 **조건부(주) 팔에서 `mag` 만 뺀 팔**이다
- **자′ = MAE(가′) − MAE(나 조건부(주))** — 두 세계에서 잰다
- **규칙**: N2 세계에서 자′ 의 BCa 가 **0 을 물고** 진짜 세계에서 `lo > 0` 이면
  → **바닥이 0 으로 내려왔다**(922 사전등록 §6-1 의 「깨끗한 갈래」가 처음 발화한다)
- 🔴 **이것은 주 판정이 아니다. 병기다.** 주 판정은 §6 으로만 한다

## §8 ③ 의 **둘째 자** — 구간 덮음. 🔴 **900노트 만에 처음으로 이 자로 판정한다**

지금 명목 0.80 대 실측 **0.9047(기후값) / 0.8796(조건부)** — **둘 다 ±0.05 밖 · 과대 덮음**.

**눈금 맞추기(측정 전에 박는다)**:

1. 학습 격자를 다시 **80/20** 으로 가른다 — `sha256("925cal"+격자) % 100 < 80`.
   앞을 **눈금용 학습**, 뒤를 **눈금 확인**이라 부른다. 🔴 **홀드아웃 격자는 이 절차에 한 톨도 안 들어간다**
2. α 를 `0.050, 0.0625, …, 0.350`(2.5%p 눈금의 절반 간격 · 25개)에서 훑는다.
   각 α 로 눈금용 학습에서 셀별 `[α, 1−α]` 분위 구간을 만들고 **눈금 확인**에서 덮음을 잰다
3. **조건부 구간의 눈금 확인 덮음이 0.80 에 가장 가까운 α** 를 고른다(동점이면 작은 α).
   기후값 구간의 α 도 같은 방식으로 따로 고른다
4. 고른 α 로 **전체 학습 격자**에서 구간을 다시 만들고 **홀드아웃**에서 잰다

**통과 규칙**: 홀드아웃에서 `|실측 덮음 − 0.80| ≤ 0.05` **이면서** 조건부 구간의 평균 폭이
기후값 구간의 평균 폭보다 **좁으면** → 🔴 **③ 의 둘째 자를 처음으로 넘는다**.
**못 맞추면 「이 자를 못 넘었다」로 적고 실측치를 병기한다** — 「안 했다」가 아니라 「했는데 못 넘었다」다.
