## §2 흔들 요인 다섯과 **격자값** — 🔴 측정 전에 못 박는다

🔴 **Cobra 의 다섯 칸에 1:1 로 붙인다.** 각 수준은 **밑판에서 그 요인 하나만** 바꾼다.
**나머지 칸은 전부 밑판 값 그대로다.**

| # | 요인 | Cobra 칸 | 격자값 (**밑판에 `*`**) |
|---|---|---|---|
| **R1** | **능형 λ** | optimizer | `0.1` · `1.0*` · `10.0` · `100.0` |
| **R2** | **특징 집합** | architecture | `전량6*` · `수준3`(mean·last7·last28) · `모양3`(slope·std·max−median) · `평균1`(mean 하나) |
| **R3** | **학습 창 길이** | curriculum | `전량*` · `≥2018-01-01` · `≥2021-01-01` · `≥2022-01-01` |
| **R4** | **도메인 가중** | objective | `균등*` · `역빈도`(w ∝ 1/n_d) · `역빈도√`(w ∝ 1/√n_d) |
| **R5** | **원천 혼합** | data mixture | `C(HPLT 전량)*` · `B(HPLT 없음)` · `C′(974 게이트 H1~H4)` |

**적합 수 = 1(밑판) + 3 + 3 + 3 + 2 + 2 = 14.**

🔴 **R1 에 대한 사전 경고(티처 #113 ④)**: 974 의 `E1b` 실측은 **능형 λ 를 키우는 것이
파괴가 아니다**(순위 보존)이다. 다만 그것은 **특징이 표준화된 한 블록**일 때의 성질이고,
여기 설계행렬은 **특징 6 + 도메인 원핫 7** 이라 λ 가 두 블록의 **상대 수축비**를 바꾼다.
🔴 **그래서 R1 의 Δ 가 0 근처로 나오면 그것은 실패가 아니라 E1b 의 재확인이다** — 그렇게 적는다.

## §3 자 — **Δ ± SE**

- **성능** = 도메인별 유보 스피어만(`predict971.spear`)의 **유보 행 가중 묶음**
  (`predict971.pooled_delta` · 분모 = 유보 행 합 **728**).
- **Δ(수준)** = `pooled(수준) − pooled(밑판)`. 밑판 자신의 Δ 는 정의상 0 이다.
- 🔴 **SE** = **짝지은 군집 붓스트랩**의 표준편차. 유보 행을 **도메인 안에서** 되뽑고
  **같은 되뽑기로 두 수준을 동시에** 채점한다(적합은 고정 · 971 `boot_ci` 의 짝지음과 같은 뜻).
  **뽑기 B = 2000 · 씨앗 975.**
- **요인의 크기** = `스팬 = max_수준 Δ − min_수준 Δ` (밑판의 0 을 포함해 센다).
- **요인 순위** = **스팬 내림차순**. 동률이면 `max |Δ|/SE` 로 가른다.

### 🔴 채택 문턱 (측정 전에 못 박는다 · 노트 133)
어떤 수준이 **「capability 를 정한다」**고 말하려면 **둘 다** 넘어야 한다:
1. `|Δ| ≥ 2 × SE(Δ)`
2. `|Δ| ≥ 0.00353` (카드 문턱 · 🔴 이 자에 맞는 문턱인지 자체가 미결이므로 **진단값**으로만 쓴다)

🔴 **첫 양수를 그대로 채택하지 않는다.** 문턱 미달이면 판정문에 **「이 자를 못 넘었다」**로
적고 **도메인별 Δ 를 병기**한다.

## §4 예측 P1~P8 (측정 전에 적는다)

## §7 🔴 반증조건 (하나라도 걸리면 이 사이클은 **실패**다)

1. **요인을 하나만 안 흔들면 실패** — 각 수준이 밑판과 **정확히 한 칸만** 다름을 산출물이
   기계로 확인해야 한다(`요인 하나만 흔들었나 = True` 가 14/14).
2. **Δ 에 SE 를 안 붙이면 실패.**
3. **본문(판정문·카드·논문·원장)에 산출물이 안 내는 수가 하나라도 있으면 실패.**
4. **카드까지 채점 안 하면 실패.**
5. **머지 뒤 `HEAD` ≠ 디스크면 실패.**
6. **유보가 수준마다 달라지면 실패** — 14 개 적합의 유보 행 집합 지문이 **하나**여야 한다.
7. **격자값을 측정 뒤에 바꾸면 실패.**
8. **첫 양수를 문턱 검사 없이 채택하면 실패.**

## §8 배선 W / 파괴 대조 E (측정 **전에** 돌린다 · 마지막 커밋본에서 다시 돌린다)

- **W1** 가중 능형이 **가중 1 에서 생산 함수 `layers957.ridge_fit` 과 같은 답**을 낸다.
- **W2** 특징 부분집합이 실제로 열 수를 줄인다.
- **W3** 학습 창 자름이 실제로 행을 줄이고 **유보는 안 건드린다**.
- **W4** 도메인 가중이 실제로 계수를 바꾼다.
- **W5** 원천 팔 셋의 학습 행 수가 서로 다르다.
- **W6** 짝지은 붓스트랩이 **같은 되뽑기**를 두 수준에 쓴다.
- **W7** 밑판 대 밑판의 Δ 가 **정확히 0** 이다.
- **W8** 14 수준의 유보 지문이 하나다.
- **E1** 학습 x↔y 짝을 깨면 유보 상관이 죽는다.
- **E2** 유보 y 를 섞으면 상관이 죽는다.
- **E3** 부호 일관성 p 의 **고침**이 실제로 관측값을 본다(관측 7/7 과 4/7 에서 다른 값).
- **E4** 「출처 키 경로 일치」 채점기가 **`525 → 524` 를 잡는다**(974 판은 못 잡는다).
- **E5** `head_vs_disk` 게이트가 **「양쪽에 있고 바이트가 다름」**에서 발화한다.
