# 공통 축 다섯이 도메인마다 실제로 무엇인가 (노트 164)

슬롯 이름은 다섯이지만 **같은 이름이 도메인마다 다른 구성물을 담는다.**
코드(`ingest/*_axes.py`)에서 그대로 읽은 것이다. 노트 140이 이것을 의심했고
노트 164가 코드로 확인했다.

## target_breadth — 구성물 하나 (도달 폭)

| 도메인 | 실제로 재는 것 |
|---|---|
| 팝업 | 사람 태깅 (0=코어 팬덤, 4=전 연령 대중) |
| 웹툰·만화·세계애니 | 태그 수 |
| 애니 | 연령 등급 |
| 모바일 | 지원 언어 수 |
| 게임·도서·아이돌 | 가중 평균(복수 신호) |
| 펀딩 | 후원자 폭 지표 |

태그 수·언어 수·연령 폭은 전부 "얼마나 많은 부류에 닿나"다. **일관됨.**

## goods_scale — 구성물 하나 (분량·부피)

| 도메인 | 실제로 재는 것 |
|---|---|
| 팝업 | 사람 태깅 (굿즈 규모) |
| 웹툰·만화 | 주당 회차 수 |
| 세계애니 | log(에피소드 × 러닝타임) |
| 모바일 | 앱 용량 MB |
| 게임 | 디스크 용량 GB |
| 도서 | 양장본 여부 |
| 펀딩 | 리워드 단계 수 |
| 아이돌 | 수록곡 수 |

전부 "얼마나 많이 담겼나"다. **일관됨.**

## venue_prominence — 구성물 넷 ⚠

| 도메인 | 실제로 재는 것 |
|---|---|
| **팝업** | **매장 내 물리적 위치 노출도** |
| 만화·세계애니·모바일·도서·펀딩·아이돌·게임 | **제작사/개발사의 사전 출시작 수** |
| 애니 | 스튜디오 수 |
| 웹툰 | 연재 요일 수 |

**슬롯 이름이 틀렸다.** 열 중 일곱에서 이 축은 "장소"가 아니라
**제작 주체의 이력**이다. 팝업에서만 이름대로다.

## entry_friction — 구성물 넷 ⚠

| 도메인 | 실제로 재는 것 |
|---|---|
| **팝업** | **입장 허들(무료 워크인 ↔ 유료·사전예약)** |
| 애니·모바일·도서·펀딩·아이돌 | 가격 |
| 웹툰 | 유료 회차(daily pass) |
| 만화·세계애니 | **성인물 여부** |

가격과 연령 제한은 다른 것이다.

## media_push — 구성물 다섯, 덮음도 얇다 ⚠

| 도메인 | 실제로 재는 것 |
|---|---|
| 팝업 | 사람 태깅 |
| 애니 | 더빙 + 독점 여부 |
| 모바일 | 스크린샷 수 |
| 게임 | 퍼블리셔 규모 |
| 아이돌 | 가중 평균 |
| 웹툰·만화·세계애니·도서·펀딩 | **관측 없음** |

## 왜 중요한가

노트 163이 잰 손잡이 정확도와 나란히 놓으면:

| 축 | 구성물 수 | 부호 정확 | 평균 \|효과\| |
|---|---|---|---|
| target_breadth | 1 | **100%** | .0593 |
| goods_scale | 1 | **98%** | .0454 |
| media_push | 5 | 75% | .0417 |
| venue_prominence | 4 | 74% | .0097 |
| entry_friction | 4 | 68% | .0230 |

구성물이 하나인 축만 손잡이로 쓸 수 있다. 다만 구성물 수와 효과 크기가
얽혀 있어(노트 164) 인과는 못 가른다 --- media_push 가 유일한 분리 사례다
(효과는 큰데 구성물이 다섯이고 정확도 75%).

## 규약

**새 도메인에 축을 배선할 때 슬롯 이름이 아니라 구성물을 맞춘다.** 맞출 수
없으면 그 도메인에서 그 축은 관측 없음으로 둔다 --- 억지로 채우면 슬롯이
평균을 흐린다.
