> 🔴 출처: 사용자가 외부 심사 세션과 함께 작성해 조타수에게 지시한 설계 문서의 전사판.

## 0. 설계 원칙 셋 (어기면 아래 전부 무효)
- **원칙 1 — 시점 정합**: 모든 산출물은 as_of 를 갖고 그 시각에 «알 수 있었던 것»만으로 계산. 코드 관문(누수 검사 L1..Ln): `assert max(input.published_at) < as_of`.
- **원칙 2 — 결정/맥락 분리**: 결정 변수 A(고를 수 있는 것 → 개입 대상) · 맥락 변수 C(못 고르는 것 → 조정 대상) · 결과 Y(효용 → 채점 대상). 뭉치면 do(a) 입구가 없다.
- **원칙 3 — 자를 먼저 고친다**: 현행 판 넷은 「곡선 맞히기」 자 — 결정 품질 자가 0. §L5.

## 층 구조
L0 시간 정합(발행일·3중 날짜·누수 관문 — 전제) → L1 담론 장 인코더 ∥ L2 개입 원장 → L3 반사실 추정기(새 모형 0) → L4 개입 가능 예보기(액션 채널) → L5 결정 자(판 개편). L5 는 L3 «전» 착수.

## L0. 시간 정합
- **L0-1 발행일 추출**(HPLT/FineWeb): 사슬 ①구조화 메타(JSON-LD·OG) ②HTML 메타 ③URL 경로 ④본문 정규식(첫 200자) ⑤실패 = null = «못 읽었다» — 🔴 크롤일 대체 «금지»(조항 59).
- **L0-2 3중 날짜**(개입 기록): announced_at(발표=개입 시작) · opened_at(개최) · closed_at · lead_days. 🔴 개입 시점 = announced_at — 개최일 기준 「이전 90일」엔 발표 스파이크가 들어가 반사실이 부푼다. lead_days 는 결정 변수.
- **L0-3 누수 관문**: `assert_no_leak(inputs, as_of, tag)` — 사후 입력 있으면 «측정 없이 중단» · 반환 스탬프 게재(부칙 4 미러).
- 완료 조건: 추출률 분모 병기 · announced_at 채움률 실측(현재 0) · 심은 사후 문서 1건으로 관문 붉히기.

## L1. 담론 장 인코더 (노트 957 실체화 · 현재 등기부 담론 원천 0)
- L1-0 등기부 등록 선행(뉴스·커뮤니티·yt 댓글 확장·HPLT/FineWeb — 발행일 추출 «후»에만).
- L1-1 두 장 분리: 개체 장 Φ_ent(e,t) / 배경 장 Φ_bg(dom,t)(e 미언급).
- L1-2 관심 점유율 SoV = |Φ_ent| / (|Φ_ent|+|Φ_bg|) — 🔴 안 하면 크롤 스케줄을 학습.
- L1-3 망각 상태: s_disc = Σ w(t−pub)·emb / Σw · w(Δ)=2^(−Δ/τ) · 🔴 τ 격자 {30,90,180,365} 사전 고정 · 정본 τ 사전 지정 · 뒤집힘 지점 게재.
- L1-4 상태 벡터: [위키 90 · s_disc(896) · SoV(90) · s_bg(896) · 기존 C] — 전항 t 이전 발행만(L0-3 강제).
- 검증 실험(최우선): 팝업(announced_at 후) · 팔 ⓐ곡선만/ⓑ곡선+담론/ⓒ담론만 · 결과 실측 방문자(328 · A/B 225) · 게이트 ⓑ−ⓐ > MDE(`mde_guard`) · ⓒ≈ⓐ면 콜드스타트 직결.

## L2. 개입 원장 (1,027건 정본화)

- **L2-4 효용 U — 정본 «측정 전» 고정**: 채택 = 권장안 **② 일평균 방문자**(기간 정규화 효율) · 부차 관찰 = ③ 매출. 여러 U 재고 고르면 전부 무효.

## L3. 반사실 추정기 (새 모형 0 · 관측→인과 첫 칸)
- L3-1 합성통제: 처치=팝업 연 IP · 공여 풀=같은 도메인·기간·안 연 IP(3,006 패널 — 현재 사용 0) · 사전 창=announced_at 이전 90일 · w≥0, Σw=1 · 효과=실제−합성. L1 예보기와 **이중 기준선**(일치=강화 · 갈림=정보).
- **L3-2 위약 검정 = MDE 무료**: 안 연 개체 N에 같은 절차 → 「효과」 분포 = 설계의 MDE(부칙 6 칸) · 0 중심 안 서면 설계 결함(자기 검사 내장).
- L3-3 백도어 조정: 팝업은 무작위 아님(선택 효과) — s_disc(announced_at)로 조정 = L1 의 진짜 용도(식별). 🔴 정직 신고 둘: 「혼란 전부 관측」은 검증 불가 — 민감도 분석 병기 · s_disc 는 announced_at 이전 발행만(현행 크롤일 텍스트 그대로 쓰면 인과 반드시 망가짐).
- L3-4 부수: 관심↔방문자 환율(도메인별·구간).
