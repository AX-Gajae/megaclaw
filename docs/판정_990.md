## 4. 🔴🔴🔴 세계 명제 `W1` --- **부호를 만든 것은 「굶김」이다**

**`Δ(N)` 을 두 성분으로 «정의상» 가른다**(같은 씨앗 · 같은 겹 · 같은 λ):

- **증강** `A(N) = ρ(base N + hplt αN) − ρ(base N)` --- base 를 «안 건드리고» hplt 만 더한다
- **굶김** `S(N) = ρ(base (1−α)N + hplt αN) − ρ(base N + hplt αN)` --- hplt 를 고정하고 base 만 깎는다
- **`A(N) + S(N) ≡ Δ(N)`** --- 배선 `W6` 이 전 눈금 · 전 자에서 잔차 0 를 확인했다

예산 `1800` 에서: **증강 -0.000182(0.0137) · 굶김 -0.01311(0.9863).**

### 4-1 🔴 그리고 **증강 팔은 «단조»가 아니다**

base 를 «각 씨앗의 자기 천장»으로 고정하고 hplt 만 흔들면:

| hplt 행 | ρ |
|---|---|
| 0 | 0.371518 |
| 1710 (977 이 실제로 쓴 수) | 0.370658 |
| 6080 | 0.372498 |
| 35641 (전량) | 0.375973 |

- 🔴 **`ρ` 가 hplt 에 단조 증가인가**: **거짓**
- 🔴 **hplt `0` 보다 «나쁜» 눈금**: [200, 400, 800, 1,710, 1,800]
- 🔴🔴 **군집 SE 의 두 배를 넘은 눈금 수**: **0**
  --- 즉 **증강 효과는 어느 눈금에서도 군집 SE 로는 «안 산다».**

### 4-2 🔴🔴 대체 팔 --- **`α = 0.95` 는 절벽 «오른쪽»이다**

총량을 `1800` 으로 고정하고 α 만 흔들면 `ρ` 는 **α 에 단조 감소가 «아니다»**(거짓):

| α | ρ |
|---|---|
| 0.0 | 0.371007 |
| 0.8 | 0.375139 |
| 0.95 (977 이 고른 값) | 0.357714 |
| 1.0 | -0.192093 |

🔴 **사전등록 «밖» 탐색 팔**(채점 분모에 «안» 든다 · `docs/루프.md` ⓪ 방향 설계):
총량 `1800` 을 고정한 채 base 행 수를 직접 흔들면 판정 자의 `ρ` 는
**base = 450 에서 가장 높고(0.375145)**,
**977 이 쓴 base = 90 자리의 값은 0.357714** 다 ---
**최적 대비 0.017431 을 잃는다.** 🔴 **그 자리가 절벽의 오른쪽인가: 참.**

🔴🔴 **그런데 같은 탐색을 병기 자로 하면 최적 base 가 균등 자 90 ·
챔피언가중 90 다** --- **977 의 선택이 그 두 자에서는 «최적»이다.**
**같은 배치가 한 자에서는 절벽 위이고 다른 자에서는 꼭대기다.**
