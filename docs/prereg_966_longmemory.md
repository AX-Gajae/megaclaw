## §2 무엇을 만드나 — 열 **하나**

**들뜸 열** `wiki_excite`. 개체의 일별 조회수 `v[d]` 에서:

```
s      = 시작일(그 개체의 축 파일이 정한 날. wiki_daily 레코드의 "시작일")
최근   = [s-90, s-1]      ← 판이 이미 보는 띠
긴기저 = [s-455, s-91]    ← 🔴 판이 원리상 못 보는 띠
wiki_excite = log1p(mean(최근)) - log1p(mean(긴기저))
```

- **결측 없는 날 = 0 조회**(원천이 0 인 날을 빠뜨린다 · `lab/wikiaxes._ZERO_IS_DATA = True` 와 같은 결정)
- **유효 규칙**: `s-455 >= 2015-07-01`(원천 개시일) **그리고** 그 개체에 자료가 1행 이상.
  🔴 원천 개시일 밖은 **0 이 아니라 결측**이다 — 안 받은 것과 0 을 섞지 않는다(조항 59).
- 표시자(indicator) = 유효면 1, 아니면 0. 무효 행은 `harness.load` 규약대로 **중립 0.5**.
- 🔴 **판에 넣기 전에 도메인 안에서 순위정규화**한다(눈금이 도메인마다 다르다).

## §4 ⓪-가 검출력 줄 — 🔴 **못 채우면 측정으로 안 넘어간다**

```
자        = 판 ρ
표본 n    = 유보 3,775
군집 K    = 씨앗 12
잡음      = SD 0.0021 (SE 0.00060)
가를 수 있는 최소 효과 = 0.01055   ← 열 1개 증가 문턱
```

🔴 **그리고 이것이 P2 의 근거다.**
부착률이 **21.51%** 이므로, 판 전체에서 0.01055 를 내려면 **부착 부분모집단에서**
`0.01055 / 0.2151 ≈ 0.049` 의 Δρ 가 필요하다.
**판 ρ 의 전 역사에서 열 하나가 0.049 를 움직인 전례가 없다**(문턱 0.00353 의 14배).

🔴 **그러므로 주 증거는 판이 아니다.** 주 증거는 **부분 스피어만 팔**이고 그 분모는
**개체 3,562 · 도메인 11**(도메인별 n 은 산출물에 전부 싣는다).
🔴 **두 수를 이어 붙이지 않는다**(조항 60) — 판 Δρ 와 부분 상관은 **분모가 다르다**.

**바닥**: 도메인마다 **라벨 순열 1,000회**의 |ρ| 분포를 같이 낸다. 바닥 없이 「지지」를 안 쓴다.

## §6 🔴 C1 결정 — **조항 64 를 고친다**(면제를 사전등록으로 되돌리지 않는다)

티처 #104 C1: *「면제를 사전등록으로 되돌리든가 조항 64 를 고치든가 하나를 정하라」*.

**정한다: 조항 64 를 고친다.** 이유:

1. 🔴 **상수 `False` 는 항진명제의 증거가 아니다** — 생성기가 그 검사의 **유효 입력 영역에
   한 번도 못 닿았을 수 있다**(조항 59). 그것은 「항진명제」가 아니라 **「모른다」**다.
2. 🔴 **가지 안의 리터럴은 상수가 아니다** — `if 잘못됐다: return {"통과": False}` 는
   **가지 자체가 자**다. 965 의 구현이 옳고 965 의 사전등록 문구가 거칠었다.
3. **전역 의존**도 「전역이 망가지면 떨어진다」이지 항진명제가 아니다.

**그러므로 개정 조항 64 는 세 갈래를 「모른다」로 갈라 적기를 요구하고, 항진명제로 안 센다.**
🔴 **대신 값을 치른다 — 「모른다」의 수를 반드시 분자·분모와 함께 신고한다.**
그리고 🔴 **이 사이클의 F1 은 두 벌로 신고한다**: 개정 자(면제 적용) · 965 사전등록 자(면제 없음).
**실패 판정은 개정 자로 한다**(이 문장이 측정 전에 적혔다는 것이 F8 의 방어다).
