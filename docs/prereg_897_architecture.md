## 2. 1단계 — 표현 수준의 감쇠 (이것이 본 측정)

### 왜

노트 756 이 1열 축(`field_spread_ff` = 장 인코더가 낸 30일 앞 예보 Δ 의 **동네 간 SD**)에서
찾은 무늬: **가장 해로운 둘이 학습 +0.082 · +0.077 → 유보 +0.022 · +0.020.
뒤집히지 않고 4분의 1로 사라진다.** 노트 759·765 가 기제 후보 다섯(방향 뒤집힘 · 결측 무늬 ·
거칠기 · 공변량 이동 · 감쇠)을 재고 **넷을 지웠다** — 남은 41% 는 **기제 미상**으로 닫혔다.

그런데 **그 다섯 후보는 전부 「1열」위에서 잰 것**이다. 장 인코더의 표현은 `dim` 차원인데
판에는 **스칼라 하나**로 들어간다. 그러면 두 갈래다:

- (가) **1열로 눌러서 생긴 손실**이면 — 표현 전체를 쓰는 합류 구조가 살릴 것이 있다.
- (나) **자료의 성질**이면 — 크로스 어텐션이든 게이팅이든 **같은 벽**이다.

🔴 **여기서 0 이면 어떤 합류 구조도 못 살린다. 그러면 2단계로 안 간다.**

### 무엇을 재나

`data/state/fieldmodel/enc.pt`(노트 736 의 검증-최선 가중)를 얼린 채로,
날짜마다 표현 `h ∈ R^{D×dim}` 을 낸다(D = 동네 수). 관측된 동네에 대해 차원마다
**평균과 표준편차**를 내어 `2·dim` 열로 요약한다. 1열 축(예보 Δ 의 동네 간 SD)은 대조군이다.

도메인마다 시작 시각으로 그 날의 열을 붙이고(노트 753 의 **앞채움**),
학습(<2025) / 유보(≥2025) 로 가른다.

    1열   ρ_학습 = spearman(축, 라벨 | 학습),  ρ_유보 = spearman(축, 라벨 | 유보)
    표현  능형회귀(α=1)를 학습에서 적합. **학습 쪽도 표본 밖으로 만든다** —
          날짜 GroupKFold(5) OOF. 안 그러면 감쇠가 자동으로 커진다.

🔴 **군집을 날짜로 두는 이유**: 특성이 **날짜만의 함수**라 같은 날 행은 완전히 종속이다.
무작위 분할도, 프랜차이즈 군집도 그 사실을 못 본다. 규약 47 의 재표집 단위(프랜차이즈)보다
**날짜가 상위 군집**이므로 날짜를 쓰고 **산출물에 병기**한다.

### 판정 통계 S — 하나만 쓴다

    S = Σ_d n_d · sign(ρ_학습,d) · ρ_유보,d / Σ_d n_d      (n_d = 도메인 d 의 유보 행수)

**부호를 학습에서 고정**하므로 사후에 유리한 부호를 고르는 일이 없다.
S 는 *"학습에서 배운 방향이 유보에서 얼마나 남나"* 를 그대로 답한다.

### 🔴 널을 직접 뽑는다 (891 방식) — 남의 문턱을 안 빌린다

1. **순열 널** — 유보 라벨을 **도메인 안에서** 1,000회 섞고 S 를 다시 낸다. 예보는 고정.
   → 널 평균 · 널 SD · **널 2σ** · 백분위 [2.5, 97.5].
2. **군집 BCa** — `lab/pairboot.cluster_boot`, 군집 = 날짜, B=2,000. **BCa 가 아니면 폴백 사유를
   산출물 필드에 명기**(규약 47). 병합률을 직접 세서 적는다(티처 #59 m3).
3. **위약 팔** — 행의 **날짜 연결만** 무작위로 끊는다(특성 주변분포는 그대로). 씨앗 8971·8972·8973.

## 3. 2단계 — 후보 구조 (F2 일 때만 연다 · 지금 사전등록만 해 둔다)

크로스 어텐션은 **후보 하나**다. 넷을 같은 자(S · 같은 널)로 겨룬다.

| 후보 | 꼴 | 왜 후보인가 |
|---|---|---|
| **늦은 합류** | `ŷ = w·f_텍스트(e) + (1−w)·f_장(g)` | 제일 싸다. **기준선이 돼야 한다** — 이걸 못 이기면 나머지는 값이 없다 |
| **이어붙이기** | `ŷ = h([φ(e); ψ(g)])` | 표현 둘을 붙여 공유 헤드. 현행 판이 열로 하는 일의 신경망 판본 |
| **크로스 어텐션** | `ŷ = h(φ(e) + Attn(q=φ(e), k=v=ψ(g(·,t))))` | 사용자가 든 것. **이벤트가 장의 어느 자리를 볼지 고른다** |
| **게이팅** | `ŷ = h(φ(e) ⊙ σ(W ψ(g)))` | `L(g, event)` 의 제일 단순한 곱셈 꼴 |

**같은 자**: 위 S · 같은 순열 널 · 같은 날짜 군집 BCa · 같은 씨앗 집합.
**채택선**: 늦은 합류를 기준으로 Δ**S** 가 그 팔의 널 2σ 밖.

## 4. 🔴 `L(g, event)` — 함수로 적는다 (이 사이클의 **최소 산출**)

원장 5738행에서 사용자가 지적했다: *"장을 유체역학적으로 생각하자고 했는데 잘 하고 있나"*
→ 답은 *"절반만 하고 있었다"*. **방문자 축은 `L` 이 아니라 `g(x,t₀⁻)` 를 한 점에서 읽은 것이고
상호작용항이 없다.** 그 함수를 한 번도 적은 적이 없다. 여기서 적는다.

### 연속 꼴

개입 `e` 가 시각 `t_e`, 자리 `x_e` 에서 일어난다. 장 `g(x,t) ∈ R^{dim}`.
개입이 낳는 변화의 궤적을 `Δŷ(e, τ)` (τ = 개입 이후 경과) 라 하면

```
    Δŷ(e, τ) = h( L(g, e), φ(e), τ )

    L(g, e) = ∫_X a(x; e) · [ W_v g(x, t_e⁻) ] dx
                                                     ⟨ W_q φ(e), W_k g(x, t_e⁻) ⟩
    a(x; e) = softmax_x  ( ────────────────────────────────────────────────── + κ(‖x − x_e‖) )
                                                              √dim
```

- `φ(e)` — 이벤트 인코더(텍스트/구조: 무엇을 · 어디서 · 언제 · 얼마나).
- `ψ(g) = W_k g` — **정보전이장 인코더**(이미 있다: `state/fieldmodel.py` → `enc.pt`).
- `a(x; e)` — **합류**. 이벤트가 장의 **어느 자리를 볼지** 고른다. 이것이 크로스 어텐션이다.
- `κ(‖x−x_e‖)` — 거리 감쇠 사전확률. 노트 644 가 실측했다(0~10km +0.787 · 10~25km +0.656 ·
  25~50km +0.488 · 50~100km +0.236). **이 항은 자료에서 나온 것이지 가정이 아니다.**
- `h(·, ·, τ)` — 시기 헤드. 사용자가 원한 *"특정 시기에"* 가 여기 붙는다.

### 🔴 현행 판이 쓰는 축은 이 식의 **퇴화 꼴**이다

`field_spread_ff` 를 이 식으로 쓰면:

```
    a(x; e) ≡ 1/|X|        (균일 · e 와 무관)
    W_v = I,  W_q = 0      (질의가 없다)
    그리고 1차 모멘트 대신 2차 모멘트만 남긴다:
    축 = std_x [ head(g(x, t_e⁻)) ]
```

즉 **`e` 가 식에서 완전히 사라진다.** `L(g, e)` 가 `e` 에 안 의존하면 그것은 `L` 이 아니라
`g` 의 요약 통계이고, **상호작용항이 정확히 0 이다.** 판이 곱셈 상호작용을 만들 수 있는 유일한
길은 트리의 축 정렬 분할인데, 그것은 `g` 를 **한 점 · 한 스칼라**로만 본다.

**그래서 이 사이클의 1단계가 묻는 것이 정확히 이것이다** — `a` 를 균일에서 풀기 전에,
`ψ(g)` 안에 라벨과 이어질 것이 **남아 있기는 한가.**

## 🔴 사전등록의 정정 (이 사이클이 스스로 잡은 것)

**지시서와 `docs/아키텍처.md` §6 이 *"`L(g,event)` 를 함수로 적어 본 적이 한 번도 없다"*
고 적었는데 — 원장을 읽으니 틀렸다.** 노트 **688** 이 이미 적었다:

    L = a·g + b·(g × 이벤트 규모)

그리고 노트 **770·771** 이 **쟀다**: 62행 · 시군구 10 · MDE(a×SD(g)) **0.2345** =
실무 문턱(방문객 10% = 0.041 log10)의 **5.7배** · **필요 행수 2,028**(현재의 33배) →
**판정 불가**. 점추정 −0.0454 는 있으나 **부호를 안 읽었다**.
🔴 **그러므로 이 사이클이 더한 것은 「처음 적는다」가 아니라 「일반화」다** —
688 의 식은 §4 어텐션 식에서 **주의가 균일하고 `g` 를 한 점 스칼라로 읽은 특수해**다.
