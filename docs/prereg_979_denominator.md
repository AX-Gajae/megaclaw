## §1 자의 족(族) — 🔴 **닫힌 꼴을 더한다**

모든 자는 도메인별 스피어만 `ρ_d` 의 가중평균이다. 다른 것은 가중치뿐이다.

| 이름 | 가중치 | 뜻 |
|---|---|---|
| `R_pool 묶음` | `w ∝ n_d` | 유보 행 가중 (975~976 의 정본) |
| `R_eq 균등` | `w ∝ 1` | 도메인 균등 (977 이 올리고 978 이 되돌렸다) |
| `R_z 순열SE 역가중` | `w ∝ 1/s_d` | `s_d` = 도메인 안 순열 귀무 SD (**978 의 정본**) |
| `R_iv SE² 역가중` | `w ∝ 1/s_d²` | 최소분산 가중 |
| 🔴 `R_z* 닫힌꼴` | `w ∝ √(n_d−1)` | **979 신설 — 뽑기 없는 `1/s_d`** |
| 🔴 `R_iv* 닫힌꼴` | `w ∝ (n_d−1)` | **979 신설 — 뽑기 없는 `1/s_d²`** |

🔴 **닫힌 꼴의 근거(측정 전에 적는다).** `s_d` 는 고정 벡터와 **도메인 안에서 순열한 유보
`y`** 의 스피어만 SD 다. 스피어만은 중간순위 위의 피어슨이고, 두 고정 점수벡터를 무작위
순열로 짝지으면 상관의 분산은 **동률이 있든 없든 정확히 `1/(n−1)`** 이다. 그러므로

> **`s_d = 1/√(n_d − 1)` (닫힌 꼴)** · **`1/s_d = √(n_d−1)`** · **`1/s_d² = n_d − 1`**

이고, 🔴 **`R_iv` 는 `−1` 보정을 빼면 `R_pool` 과 같은 자다.** 노트 978 이 산문으로 적은
「최소분산 가중은 묶음으로 되돌아간다」는 **근사가 아니라 항등식**이다.
이 사이클은 그 항등식을 **뽑기 추정과 나란히 세워** 확인한다(예측 Q3·Q4).

🔴 **뽑기판 `R_z`·`R_iv` 를 안 버린다** — 노트 978 산출물과 바이트로 견줄 자리가 필요하다
(조항 66-③: 자를 고치면 구판/신판 전후를 같이 싣는다).
