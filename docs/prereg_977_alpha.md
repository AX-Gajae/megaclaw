## §0 왜 이 설계인가 — 티처 #115 가 낸 사실 둘

티처 #115 가 976 산출물을 다시 돌려 **두 개의 실측**을 냈다.

1. **`hplt y` 전량을 부수면 밑판 1,800 행 중 1,710(95%)의 라벨이 깨지는데
   Δ = −0.023616 = 0.52 SE_이중**(씨앗 다섯 평균 0.89 SE).
   → **학습 행 95% 의 라벨을 통째로 부숴도 자가 안 움직인다.**
2. **`α=0`(HPLT 를 학습에서 완전히 뺀 base 1,800 행)이 976 격자 32 수준 중 최대 개선이다**
   — 묶음 ρ **0.370644**(Δ **+0.127683**) · 도메인 균등 Δ **+0.200579**.
   976 은 이 수를 본문 셋 어디에도 안 적었고 R5 를 오직 파괴 끝점(α=1)으로만 서술했다.

🔴 **그런데 976 산출물 자신이 그 둘을 곧바로 못 믿게 만든다**: R5 격자에서 **λ 가 α 와 같이 움직였다**
(α=0 의 겹별 λ 는 [1,1,1,10,1] · α=0.95 는 [1000×5] · α=1 은 [10000×5]).
**α 의 효과와 속겹 CV 의 λ 선택이 얽혀 있다.** 976 의 사다리에서 티처 #115 가 지목한 것과 같은 얽힘이다.

→ **977 은 α 를 정본 축으로 올리되 λ 를 얼려서 다시 잰다.**

## §4 🔴🔴 §S2 — **라벨 파괴 대조** (「95% 를 부숴도 안 움직인다」의 뜻을 판정한다)

밑판(α=0.95 · λ 등록값)에서 **학습 라벨만** 부순다. 유보는 한 줄도 안 만진다.

| | 부수는 것 | 밑판 1,800 중 | 왜 |
|---|---|---|---|
| **D1** | `hplt` y 전량 섞기 | **1,710 (95%)** | 티처 #115 재현 |
| **D2** | `base` 학습 y 전량 섞기 | **90 (5%)** | 🔴 **결정적 대조** |
| **D3** | `hplt` y 중 무작위 90 행 섞기 | 90 (5%) | D2 의 크기 맞춤 대조 |
| **D4** | 둘 다 섞기 | 1,800 (100%) | 바닥 |

- 섞기 씨앗 **5개** × 겹 씨앗 **5개** → 자리마다 **25 벌** 평균.

🔴 **판정 규칙(측정 전에 박는다)**
- **|Δ(D2)| ≥ |Δ(D1)| 이면** → 「모형은 base 90 행 위에 서 있다」가 **실측으로 참**이고,
  973~976 의 C3 서사(「원천을 하나 더 들였다」)를 **정정한다**.
- **|Δ(D2)| < |Δ(D1)| 이면** → 위 문장을 **철회하고** 그대로 적는다.
- **|Δ(D4)| 가 두 문턱을 다 넘지 못하면** → 🔴 **이 자는 학습 라벨을 원리상 못 본다**는 뜻이고
  그러면 **§S1 의 모든 Δ 해석을 그만큼 깎는다**(측정 전에 적는다).
