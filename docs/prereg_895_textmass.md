# 노트 895 사전등록 초안 — **텍스트 존재량의 자** (v2)

> **저장소로 옮긴 이유**: v1 이 세션 스크래치패드에 있었다. 인계 카드가 *"세션 사이의
> 유일한 전달 수단은 저장소와 이 카드"* 라 못 박은 **바로 그 규칙 위반**이었다
> (티처 #57 m9 · 주 세션 잘못). 세션이 끝나면 사라졌을 것이다.
>
> **v2 는 티처 #57 이 v1 에서 찾은 구멍 셋을 고친 판이다.** 아직 사전등록이 아니다 —
> 895 를 여는 프레시 세션이 **읽고 검토해서 고쳐 쓴 뒤** 원장에 올린다.

---

## 왜 이 자인가

노트 893 이 G2 를 무효로 만들었고(음성 통제 0.74), 티처 #56 추가분과 노트 894 가
**독립으로 같은 결론**에 왔다 — **유효 수확으로 세면 실물 작품당 중앙값 0**.
그리고 인과가 반대였다: ***"자료가 이름을 따라오지 않는다. 이름이 자료를 따라온다."***
이름은 열쇠가 아니라 **이미 쌓인 텍스트 더미로 들어가는 색인**이다.

→ **크롤하기 전에** *"이 작품에 대한 텍스트가 실제로 존재하는가"* 를 재야 한다.
이 자가 없으면 229시간을 태워도 **잡동사니만 늘어난다**.

🔴 **이 자는 크롤을 게이트하므로 크롤을 요구하면 안 된다**(순환). 싸야 한다.

## 🔴🔴 v1 의 구멍 셋 — 티처 #57 이 값으로 찾았다. **이걸 안 고치면 895 는 가짜 성공을 낸다.**

### 구멍 ① 정답지가 **채점하려는 구간에서 전부 0** 이다

| 물음 | 값 |
|---|---|
| 실물 200 중 유효 수확 0 | **136 (68%)** — 220 중 **152 가 0 에 묶임** |
| **정답지가 음성 20 을 실물 200 과 가르는가** | **AUC = 0.5564 · MWU p = 0.4061** |
| 조건 맞춰도(뉴스 양쪽 판정불가 실물 73 대 음성 20) | AUC **0.5216** · 양쪽 중앙값 **0** |
| 타이 없는 **완벽한** 자의 스피어만 천장 | **0.8278** |

**정답지는 자가 판단해야 할 바로 그 구간(롱테일)에서 아무 신호가 없고, 음성 통제조차
못 가른다.** B 를 통과해도 상위 32% 의 순서를 맞춘 것이지 게이트가 옳다는 뜻이 아니다.

🔴 **고침(v2 채택)**
- **정답지를 다시 낸다** — ⓐ **확인된 0(28건)만 0**, 나머지 108 은 **결측**(0 으로 읽지 않는다 · 조항 59)
- ⓑ **연속량으로 바꾼다** — `prec_one`(어절 **전부** 포함) 대신 **어절 겹침 비율의 합**. 타이가 줄어 천장이 오른다
- ⓒ **B 의 통과선을 천장 대비로** 적는다 (새 정답지의 천장을 먼저 재고 그 60% 를 선으로)

### 구멍 ② 채점 A 는 v1 문장으로는 **완벽한 자도 못 넘는다**

*"음성 20 이 전부 하위 10% 안"* — 220 의 하위 10% 는 **22칸**인데 **0 에 묶인 것이
152건**이다. 중간순위면 음성 20 이 전부 타이 블록 한가운데(≈76위)라 **하위 22칸에
0개**가 든다. **정답지 자신을 자로 써도 A 는 0/20 으로 실패한다.**
그리고 **R2 는 이진**이라 "하위 10%" 가 정의되지 않는다.

🔴 **고침(v2 채택)** — A 를 **타이에 견디는 문장**으로:
> **A: `AUC(음성 < 실물) ≥ 0.85`** (부트 95% 하한 > 0.70)
> 보조: `max(음성 점수) < 실물 점수의 10분위수` 를 병기.
> 타이는 **최악 순위**(타이 블록 상단)로 부여한다고 명시.

### 구멍 ③ 채점 C 가 통제하는 것이 **교락이 아니다**

C 는 *"층 안에서도 갈리는가"* 인데 티처 #56 C2 가 확정한 교락은 **층이 아니라
원산국/국내 유통**이다(한글 별칭 보유 **KR 96% · JP 10% · CN 18%**). 그리고
**층 안에서도 길이 자가 살아 있다** — 어절수↔유효수확 **상 −0.40 · 중 −0.56 ·
하 −0.57**. 즉 **순전히 질의어 길이의 함수인 자도 C 를 통과한다.**
칸 크기도 무리다: (중, synonyms) **3** · (하, synonyms) **3**.

🔴 **고침(v2 채택)**
> **C: `partial Spearman(자, 정답지 | 질의 어절수, 원산국, 층)` 가 0 과 갈린다**
> (부트 95% 가 0 을 안 문다)

그리고 **티처 #56 의 3순위 팔을 895 안에서 뽑는다** — **한글 별칭 있는 JP 롱테일
(611건 모집단)** 대 **한글 별칭 없는 KR(7건 — 이 칸이 작아 부분 검정만 된다)**.
그 팔이 없으면 어떤 자를 세워도 **"언어를 재는 자"와 구별이 안 된다.**

## 자 후보 (작품당 요청 ≤ 2)

### 🔴 R1 · 정확 구문 검색 총량 — **지금은 못 쓴다. 양성 통제 없이 점수 매기지 마라**
네이버 웹 검색이 **차단 중**이다(`naver_alive()` → `살았나 false` · 체인소맨 0건 ·
72,547바이트 · `id="notfound"`). **차단된 원천은 모든 작품에 0 을 주고, 그러면 음성
20 도 0 이라 A 를 만점 통과하면서 아무것도 안 재는 자가 된다** — 🔴 **조항 59 의 새
형태가 이 설계 맨 위에 놓여 있다.**
- 열려면 **`openapi.naver.com`**(`.env` 에 `NAVER_SEARCH_ID/SECRET` · 웹 검색과 **다른 채널**).
  ⚠ `naver_search_api` docstring: *"024 Scope Status Invalid = 앱에 이 API 미등록"*.
- **양성 통제 필수** — 알려진 양성 질의(체인소맨 등 ≥3건)가 0 이면 **그 사이클의 R1 은 전부 판정 불가**.
- ⚠ **R1 은 길이 자와 공선이다**(구문이 길수록 total 이 준다 · 정답지도 길이 자) →
  **B 통과가 길이 때문인지 반드시 갈라라**(C 의 편상관 없이는 무의미).

### R2 · 베이스 모델 탐침 — 요청 0 · 이미 있다
`core/probe.py` 가 **안다 / 모른다 / 판정 불가** 셋으로 답한다(로컬 ollama · 유료 아님).
탐침 결과(**상 4/4 · 중 0/3 · 하 1/4**)가 유효 수확 표와 **같은 순서**다.
- 점수 = 안다 1 / 모른다 0 / **판정 불가는 결측**
- n=11 → **220 전량**으로 넓혀야 자가 된다
- 🔴 **통과해도 쓰면 안 될 수 있다** — 카드가 *"우리 값은 중·하위 롱테일"* 이라 적었는데
  R2 로 게이트하면 **값이 있는 구간을 정확히 잘라낸다**. **채점 통과와 게이트 효용을 갈라 적어라.**

### R3 · 문서 존재와 길이 — 작품당 1~2요청
나무위키·위키백과 문서 유무와 **본문 글자수**(체인소맨 나무위키 **116,800자** 실측).
- 점수 = `log1p(글자수)` · 문서 없음 = 0 · **가져오기 실패 = 결측**
- 시간축엔 못 쓰지만(최종 수정 시각 하나뿐) **존재량에는 쓸 수 있다**

## 예측 (측정 전 · **적기 전에 grep 으로 파일에 없는 값인지 확인할 것**)
- **P1** R3 가 셋 중 B 가 제일 높다
- **P2** R2 는 B 는 넘고 **C 에서 죽는다**(상위권만 알기 때문)
- **P3** R1 은 **양성 통제부터 실패**한다(네이버가 아직 막혀 있을 것)
- **P4** 새 정답지(확인된 0 만 · 연속량)의 스피어만 천장이 **0.83 → 0.9 이상**으로 오른다

## 반증 조건 (**발화가 산술적으로 가능한 것만** — v1 의 F3 은 불가능 형태였다)
- **F1** 셋 다 A 미달(AUC < 0.85) → **자 후보 전체를 바꾼다**
- **F2** 셋 다 C 에서 편상관 구간이 0 을 문다 → **우리가 만든 건 길이·언어 대용이지 텍스트 존재량이 아니다**(실패가 아니라 값진 결과)
- **F3** ~~"정답지가 크게 바뀐다"~~ → **수를 박는다**: 수리 전/후 스피어만 **0.9935** · 0건 135→136 · native 중앙 14→13 · 평균 7.28→6.80. **선: ρ < 0.95 면 정답지부터 다시.** ✅ **이미 통과했다**
- **F4** R1 양성 통제가 0 → **그 사이클의 R1 은 전부 판정 불가로 적고 점수를 안 매긴다**

## 판정 규칙
1. **A·B·C 를 다 넘는 자가 있으면** → **제안**하고 **확인 측정은 다음 사이클**(노트 133 — 구간과 무관하게 첫 양성 채택 금지).
2. 못 넘으면 → *"이 자를 못 넘었다"* 로 적고 **어느 기준에서 얼마나** 못 넘었는지 병기.
3. **구간법을 측정 전에 못 박는다**(티처 #57 M5 — 894 가 안 적어 판정이 방법 선택에 걸렸다). 기본은 **BCa**(규약 47) · 퇴화하면 **Clopper–Pearson** 을 폴백으로 쓰고 **사유를 필드에 명기**.
4. **점추정만 내지 마라.** 층·언어·원산국을 **갈라** 보고하라.
5. **파싱 실패를 `없음` 으로 읽지 마라** — 894 가 이 병을 **한 사이클에 세 번** 저질렀다(갤 파서 · `끝쪽=None` · 「136 이 0」).
