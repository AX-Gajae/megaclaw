## §3 배선 검사 — 🔴 **각 assert 를 국소적으로 시험한다** (티처 #67 m3 처방)

904 의 약점 둘을 이번에 고친다:
- **m3**: W-ㄷ 이 두 assert 의 **OR** 이라 하나만 지워도 다른 하나가 대신 발화했다
- **m2**: W-ㄹ 이 심는 결함이 생산 함수의 **인자**(시험 전용 가지)라 나머지와 성질이 달랐다

**이번 설계**
1. 생산 함수의 모든 검사를 `_A(아이디, 조건, 메시지)` 로 **번호를 붙여** 쓴다.
   모듈 전역 `OFF: set[str]` 에 그 아이디가 있으면 **그 검사 하나만 꺼진다.**
2. 심는 결함은 **전부 입력 파손**이다 — 시험 전용 인자를 쓰지 않는다(m2 처방).
3. 각 검사에 대해 **세 번** 돌린다:
   - ㉮ 파손 입력 · 전부 켬 → **발화해야 한다**
   - ㉯ 🔴 파손 입력 · **그 검사 하나만 끔** → **발화하면 안 된다**
     (발화하면 다른 검사가 대신 잡은 것이므로 **국소 시험 실패** — m3 가 걸린 자리)
   - ㉰ 정상 입력 · 전부 켬 → **발화하면 안 된다**(음성 대조)
4. **진입 계수기 `CALLS` 는 생산 함수 첫 줄**에 둔다. ㉮㉯㉰ 각각에서 늘어야 한다.
5. **통과 조건**: 심은 결함 n 에 대해 `발화 n · 국소 n · 음성 n · 계수기 n`.
   하나라도 어긋나면 🔴 **측정을 안 한다**(산출물을 쓰고 rc=1 로 죽는다).
