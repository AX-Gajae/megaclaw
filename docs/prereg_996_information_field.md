#### 정정 ④ — **「위약은 ρ 를 못 바꾼다」는 «고정 모형»에서만 항등식이다**

🔴 **반만 맞다.** 참인 것은 이것이다:

> **고정된 모형의 예측에 「블록 «안»에서 상수인 성분」을 더하면 블록 안 순위가 안 바뀐다 ⇒ ρ 가 «정확히» 그대로다.**

🔴 **그런데 「열을 넣고 «다시 적합»한다」는 다르다** — 능형이든 부스팅이든 열이 하나 늘면
**다른 열의 계수가 같이 바뀐다.** 그래서 `Δρ ≠ 0` 이 «배선 누출이 아니어도» 난다.

**그래서 위약을 «둘»로 나눈다:**

| | 무엇 | 무엇이어야 하나 |
|---|---|---|
| **위약 ㉠**(구조 항등식) | 고정 모형 + 블록 상수 오프셋 | 🔴 `Δρ = 0` (1e-12 안) — **항등식이므로 `㉮` 로 등기하고 「통과」로 «안» 센다.** 대신 **떨어질 수 있음을 대조판으로 보인다**(행별로 «변하는» 오프셋을 더하면 `Δρ ≠ 0`) |
| **위약 ㉡**(재적합) | `Z` 주효과만 넣고 다시 적합 | 🔴 `|Δρ(주효과)| < |Δρ(상호작용)|` — **상호작용이 «이겨야»** 정보장이 「축의 계수를 돌린다」는 뜻이다 |

### §0-다 🔴🔴 **티처 #134 의 정정을 받는다 — 분모가 흔들린다**

**① 학습량 교란은 「아직 못 갈랐다」가 아니라 「원리상 못 가른다」.** 설계 팔이 직접 다시 쟀다:

|---|---:|---:|

| 2 | 9 | 9,116 |
| 3 | 9 | 13,671 |
| 4 | 11 | 18,225 |

증분 **4,560 / 4,555 / 4,554** · 🔴 **`corr(원점 지표, 학습 행) = 0.99999995`**(연기 시험 `S3`).
**거리와 학습량은 «완전 공선»이다 — 관찰만으로는 어떤 자를 써도 못 가른다.**
갈 길은 하나다: **학습 집합을 «잘라 맞추고» 원점만 옮긴다.**

**② 몫은 이미 잰 수로 낼 수 있다.** `out994_ctl.json C3`(유보·시대 그대로 · 학습 행만 19,018→4,556):
ρ `0.470997 → 0.417725` ⟹ **`C0 − C3 = 0.053272`** ⟹ `0.183381` 의 **29.0 %**(단순 차) ·
**28.2 %**(log 기울기)가 **정보장과 아무 상관 없는 「학습 행 수」**다.

🔴🔴🔴 **그러므로 `Z_t` 팔의 분모는 `0.183381` 이 «아니라» 팔 0 이 내는 «잔여 낙차»다.**
🔴 **그리고 그 나눗셈은 «정비 팔»이 채점에서 한다** — 측정 팔은 서로 안 읽는다(조항 74-3).
측정 팔은 **분자와 자기 세계의 분모**만 낸다.

**③ 「쪼개면 아무거나 하나는 넘는다」.** 티처 #134 가 귀무(4칸 추세 0 · 도메인 12 · 995 판정식)에서
2 만 번 돌렸다: **하나라도 넘는다 `0.2104`** · **셋 다 넘는다 `0.00275`** · 합이 넘는다 `0.0770`.
🔴 **그래서 996 은 조각 판정을 「이접(any)」이 아니라 «연언(k/k)»으로 채점하고, 「통과 조각 / 분모 조각」과
«부호뒤집기 순열 p»를 헤드라인 «칸»에 넣는다.** 그 순열은 **`2^d` 를 «전부 세어» 정확히** 낸다
(몬테카를로 아님 · 씨앗 없음 · `delta996_common.signflip_exact`).

**④ 「합」을 넷째 통과로 세지 마라.** `0.074859+0.048355+0.060167 = 0.183381` 은 **항등 합**이다.
`㉮-2` 로 등기하고 **「크기」로만 쓴다.**

**⑤ 부호 규약을 코드와 맞춘다.** `seg_from` 은 `per_by[뒤] − per_by[앞]` 이다 ⟹
🔴 **「가까운 원점 − 먼 원점」 · 양수 = 원점이 «가까울수록» 좋다.**
`out995_champ.json §C3` 의 문구 *"「먼 원점 − 가까운 원점」"* 은 **코드와 반대**다(티처 #134).
