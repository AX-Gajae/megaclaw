## §1 🔴🔴🔴 세계 명제 (`조항 73` · 분모 **2**)

> 🔴 이 절에는 자기 자·채점기·규약을 «못» 넣는다.

### 1-1 명제 `W6` — **「최적 base」는 이 SE 로 「해상도가 없다」. 이분 문제로 다시 세운다**

🔴 **992 의 격자 8 칸은 실제로 「하나」밖에 안 가른다** — `base 45`(`0.260135`) 대
나머지 일곱(`0.357~0.375`). 판정 자 최적 집합이 **7/8** 이고 `R_eq`·`R_champ` 는 **8/8** 이다.

**993 은 격자를 «더 넓히지 않는다».** 같은 8 칸에서 **이분 대비**를 «측정 전에» 박는다:

```
CONTRAST = mean(ρ | base ∈ {90,135,270,450,675,900,1200}) − ρ(base = 45)
```

- 🔴 **도메인 군집 SE 로 `t_clu` 를 낸다**(§1-3 식). `|t_clu| > 2` 면 「갈린다」고 적는다.
- 🔴 **`argmax` 를 「최적」이라 «안» 적는다**(`조항 68-다` 승계).
- 🔴 **`base = 90` 칸이 판정 `H` 칸과 «같은 물건»임을 실측해 다시 적는다**(`조항 68-나` 승계).

### 1-2 명제 `W7` — **「무엇이 사는가는 자의 사실」을 「자 «사이» 차의 군집 SE」로 「직접」 잰다**

🔴🔴🔴 **992 의 헤드라인 `W5` 는 「자 A 에서 `t=1.4671` · 자 B 에서 `t=2.2260`」이다.**
**그것은 「두 자가 다르다」의 «증거가 아니다»** — 두 수가 각각 문턱의 양쪽에 떨어졌다는
관측일 뿐이고, **「차」 자체는 한 번도 안 쟀다.**

**993 은 «차»를 «짝으로» 잰다**: 도메인 `d` 마다
`δ_d = (챔피언 자의 성분 기여)_d − (판정 자의 성분 기여)_d` 를 내고, 그 가중합의
**군집 SE 로 `t_clu(차)`** 를 낸다. **자 3 개 중 짝 3 개 × 성분 8 = 24 칸을 전량 낸다.**

- 🔴 **판정식**: `|t_clu(차)| > 2` 면 「자가 실제로 가른다」이고, 아니면
  **「992 의 `W5` 서사는 «차의 유의성»으로는 안 선다」**로 적는다.

### 1-3 🔴 SE 는 「도메인 군집」으로 (식을 측정 전에 박는다 · 990·991·992 승계)

`Δ = Σ_d w_d Δ_d` (`Σ w_d = 1`) 일 때 **`SE² = (G/(G−1)) · Σ_d w_d² (Δ_d − Δ)²`**.
LODO 는 도메인 하나를 빼고 남은 가중으로 다시 낸다.

### 1-4 🔴🔴🔴 배선 명부 — **㉢ 은 「널칸을 「뺀」 격자」에서 잰다**

> 🔴🔴🔴 **992 의 병.** 992 는 각 검사의 설정 격자에 **「변이 크기 0」인 널칸을 넣고**
> `㉢ = not const_t and not const_f` 로 판정했다. **널칸에서 변이체는 «정의상» 원본과
> 같으므로 `any(mut)` 이 «언제나» 참이고, `const_f` 는 «원리상» 못 켜진다.**
> 🔴 **「일곱 전부 검정력 있음」은 「격자에 항등원을 넣은 것」의 항등식이고 검정력이 `0` 이다.**
> 🔴🔴 그리고 **991 을 잰 격자에는 널칸이 «없다»** — 거꾸로 991 의 여섯에 널칸을 넣으면
> **전부 ㉢ 이 된다.** 「992 0, 991 6」은 검사의 성질이 아니라 **「격자에 항등원을 넣었나」
> 하나가 낳은 수**다.

**993 부터 각 배선 검사는 「널칸 명부」를 «측정 전에» 갖는다.**

| 칸 | 정의 (전부 실측) |
|---|---|
| **널칸 sanity** | 널칸에서 `변이체 == 원본` 이어야 한다. 아니면 그 널칸 신고가 «거짓»이다 |
| **㉠ 구성상 «참»** | **널칸을 «뺀»** 격자의 어느 칸에서도 변이체가 «안» 떨어졌다 (`all(mut_nn)`) |
| **㉡ 구성상 «거짓»** | **널칸을 «뺀»** 격자의 어느 칸에서도 변이체가 «떨어졌다» (`not any(mut_nn)`) |
| **㉢ 검정력이 있다** | **널칸을 «뺀»** 격자에서 결과가 «갈린다» (㉠ 도 ㉡ 도 아니다) |

- 🔴 **널칸은 sanity check 로만 쓰고 「검정력 분자」에서 «뺀다».**
- 🔴🔴 **990·991·992 를 「같은 규약」으로 다시 재고 「널 포함 / 널 제외」 두 수를 «나란히» 낸다.**
  **「990 7 → 991 6 → 992 0」의 진보 서사가 자의 비대칭이 만든 것인지 여기서 갈린다.**
- 🔴 **널칸이 «없는» 검사는 「널칸 0」이라 적고 그 사실을 게재한다**(조용히 넘기지 않는다).

### 1-4-가 🔴🔴🔴 널칸 명부 — **「변이 크기 0」인 칸을 «측정 전에» 이름으로 박는다**

> 🔴 **널칸은 «결과»로 정하면 안 된다.** 「변이체가 원본과 «같은 답»을 낸 칸」을 널칸이라 부르면
> ㉢ 이 «원리상» 못 켜진다(992 와 반대 방향의 같은 병). **널칸은 «구성»으로 정한다** —
> **「그 칸에서 변이체 코드가 원본 코드와 «같은 물건»이 되는가」.**

| 검사 | 널칸 (변이 크기 0) |
|---|---|
| **X1 색인 대조** | `off == 0`(reseed 어긋남 없음) |
| **X2 팔 B·S 안 채움** | `nb <= av`(그 씨앗·겹의 base 천장 아래 — 채울 것이 «없어» `pick_filling` 이 `pick` 과 같은 물건이다) |
| **X3 유보 미접촉** | `k == 0`(겹 필터 shift 0 — `pick_wrongfold` 가 `pick` 과 같은 물건이다) |
| **X4 세 자가 다르다** | `t == 1.0`(가중 섞임 없음) |
| **X5 세계 자료 지문** | 경로 == 원본 |
| **X6 977 재현** | `α == 0.95` |
| **X7 외부 닻** | `n == 1800` |
| **991 의 여섯** | `X1 off=0` · `X2 nb=512` · `X3 겹 «거른» 뽑기` · `X4 t=1.0` · `X5 원본 경로` · `X6 α=0.95` |
| **990 의 일곱** | `W1 n=1800` · `W2 nb=512` · `W3 겹 «거른» 뽑기` · `W5 «안 끼운» 결과 딕트` · `W7 t=1.0` |
| **990 `W4`·`W6`** | 🔴🔴🔴 **널칸이 «구성상» 없다** — «판정식»을 손으로 뒤집은 변이체(`공표값 + 0.1` · `잔차 문턱 1e-3`)에는 **「변이 크기 0」이 «원리상» 없다** |

🔴🔴🔴 **그래서 「널칸이 구성상 있나」는 「그 변이체가 «코드» 변이체인가」의 «기계 자»다**
(`조항 66-가` 가 ❌ 로 못 박은 꼴을 «자동으로» 가른다). **993 은 그 칸을 검사마다 낸다.**
🔴 **널칸이 «없는» 검사는 격자에서 아무것도 안 빼고 두 수가 «같다»고 적는다.**
