## §3 층 셋의 정의 — 🔴 열이 모형에 닿는지를 층마다 따로 본다

### 팔 A — 격자에 붙는 팝업 쌍 **47** (층 ①②③ 전부)
### 팔 B — wiki 쌍 **584** (층 ①③ 만 · ②는 원리상 없다)

🔴 **두 팔의 분모가 다르다. 두 팔의 수를 서로 빼지 않는다**(조항 60).

### 층 ① 개체 — 지금 `s` 의 전부
`s_상태.값` = 액션 앞 90일 일별 위키 조회수. 특징 여섯:
`f1` log10(1+평균) · `f2` log10(1+마지막 7일 평균) · `f3` log10(1+마지막 28일 평균) ·
`f4` log10(1+s) 의 90일 OLS 기울기 · `f5` log10(1+s) 의 SD · `f6` log10(1+최대)−log10(1+중앙값).

### 층 ② 물리 장 — 서울 생활인구 250m
`data/ingest/seoul_lifepop/*.zip` 19개(2025-01~2026-07)에서 **그 쌍의 격자**의
액션 앞 90일 일별·시간별 `생활인구합계`. 특징 여섯:
`g1` log10(1+일합 평균) · `g2` log10(1+마지막 7일 평균) · `g3` 90일 기울기 ·
`g4` SD/평균 · `g5` 주말평균/주중평균 · `g6` 12~17시 몫.
- 격자 = `runners/out901h_link.py:grid_of(lat,lon)`(EPSG:5179 · 자기시험 있음).
- 좌표 = `grid915_attach.json` 우선 · 없으면 `geo919_coords.json`.
  🔴 **919 좌표는 「사전 묶음 퍼짐」이 최대 237,841.9 m 인 것이 있다 — 원천을 열로 실어
  두 원천을 갈라 본다**(§6-라).
- 행 단위는 **(행정동, 격자)** 쌍이라 격자 값은 **행정동을 넘어 합산**한다.
- 마스킹 `*` 는 「≤3」이지 0 이 아니다 — 0 으로 접고 **건수를 따로 센다**.

### 층 ③ 무관 배경 — 🔴 **「무관」의 정의를 여기 박는다**
쌍 `p`(개체 `e`, 도메인 `d`, 액션일 `T`)의 배경은:

> **같은 도메인 `d` 의 다른 개체 중, 그 개체의 액션일이 `T` 로부터 **90일 넘게** 떨어져 있고,
> `[T−90, T)` 구간에 위키 일별 조회수가 **하루 이상** 있는 개체 전부.**

- `N_p` = 그 개체 수 — **쌍마다 산출물에 싣는다**(고정 상수가 아니다).
- 배경 곡선 `b_p[t]` = 그 `N_p` 개체의 `log10(1+조회수[t])` 의 **평균**.
- 편차 `r_p[t] = log10(1+s[t]) − b_p[t]`.
- 특징 여섯 = 층 ① 과 **같은 여섯 모양**을 `r` 위에서 계산(log 를 두 번 안 씌운다).
- 🔴 자기 자신은 배경에서 **뺀다**(배선 검사 W6 이 코드로 단언).
- 🔴 `N_p < 5` 면 그 쌍은 팔에서 **뺀다**. 뺀 수를 싣는다.

**붙이는 방식**: 기본은 **덧붙임**(①의 여섯 옆에 ③의 여섯을 더한다).
부차로 **치환**(①의 여섯을 ③의 여섯으로 바꾼다)도 재서 싣는다. 판정은 덧붙임으로 한다.

## §6 판정 — 🔴 **재기 전에 세 판정을 다 적는다**

문턱 `T = max(0.00353, 2·SE_boot(Δρ))`.
`SE_boot` = 짝지은 부트스트랩 2,000회(팔 A 는 **격자**로 묶어 재표집 · 팔 B 는 **개체**로).

**채택은 셋을 전부 만족할 때만.** ㉠ `Δρ > T` (주 표적) ㉡ 부 표적에서 부호가 안 뒤집힌다
㉢ 라벨 순열 100회의 Δρ 분포 상위 5% 밖. 🔴 **첫 양수를 그대로 채택하지 않는다**(노트 133).

### 미리 적는 세 판정

| 갈래 | 관측 | 🔴 그러면 무엇을 한다 |
|---|---|---|
| **가** | `Δρ(②) > T` 이고 ㉠㉡㉢ 다 만족 | **층 ② 를 `s` 의 정의에 넣는다.** 다음 사이클은 생활인구를 붙이는 쌍을 늘린다(격자 23 → 더) |
| **나** | `\|Δρ(②)\| ≤ T` | **층 ② 를 안 넣는다.** 🔴 그리고 **「안 들었다」가 아니라 「이 n 에서는 못 가른다」로 적는다** — `T` 를 같이 싣는다 |
| **다** | `Δρ(②) < −T` | **층 ② 를 뺀다**(잡음 열이다). 왜 내렸는지 산출물에 싣는다 |
| **가′** | `Δρ(③) > T` (팔 B) | **`s` 를 배경 대비 편차로 바꾼다** — 전 도메인에 적용 |
| **나′** | `\|Δρ(③)\| ≤ T` (팔 B) | 🔴 **이것이 주 세션 예측의 반증이고 더 큰 소득이다** — 지금 ρ 가 배경 추세를 맞히고 있었다는 뜻이 **아니라는** 증거가 되므로, 다음 사이클의 물음이 바뀐다 |
| **다′** | `Δρ(③) < −T` | 배경 차분이 신호를 지운다 — **`s` 를 절대값으로 둔다** |

**층 ①+②+③ 동시**(팔 A): `Δρ(②+③) = ρ(①+②+③) − ρ(①)`. 위와 같은 규칙으로 별도 판정.
