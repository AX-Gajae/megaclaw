## §2 규격 — 967 이 재는 것

**규격 A(966 재현)**: 966 의 자 그대로 — `argsort` 순위 · 띠 안 0행 = 0 · `wiki_level` 만 통제.
**규격 B**: 동률평균 순위로만 바꾼다.
**규격 C**: B + **띠 안 0행을 결측으로 가른다**.
**규격 D(주 판정)**: C + **자기 열의 최근 90일 항(`recent_term`)도 같이 통제** + **두 띠 모두 실자료 1행 이상인 행만**.

```
recent_term = log1p( sum(v[s-90 .. s-1]) / 90 )
long_term   = log1p( sum(v[s-455 .. s-91]) / 365 )
excite      = recent_term - long_term
n_rec, n_lon = 그 띠 안에 실제로 **행이 있는** 날 수
```

🔴 **조항 59 를 띠 안에도 적용한다**: `n_lon == 0` 이면 `long_term` 은 **0 이 아니라 결측**이다. 966 은 원천 개시일 **밖**에만 이 원칙을 적용했고 **띠 안에는 안 했다**. 그리고 966 의 유효 규칙(`if not r["날짜"]`)은 사전등록 문구(*「그 개체에 자료가 1행 이상」*)와 다르게 **아무 데나 1행이면 통과**시킨다(조항 62).

**통제 집합**: 규격 A·B·C 는 `{wiki_level}` · 규격 D 는 `{wiki_level, recent_term}`.
**잔차화**: 순위변환 → 통제 열들에 최소제곱 회귀 → 잔차끼리 피어슨.

## §3 🔴 다중비교 보정 — **측정 전에 정한다**

- **Holm–Bonferroni · α = 0.05 · 분모 = 그 규격에서 실제로 잰 도메인 수.**
- p 값은 **라벨 순열 2,000회**의 양측 p = `(1 + #{|ρ_null| ≥ |ρ_obs|}) / (1 + 2000)`.
- 🔴 **보정 전 계수와 보정 후 계수를 둘 다 신고한다.** 966 은 도메인마다 α=0.05 를 따로 썼고 그 사실을 안 적었다.
- 🔴 **주 판정은 Holm 뒤의 수로 한다.**

## §6 판정 규칙 — 🔴 **측정 전에 정한다**
