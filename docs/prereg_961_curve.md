## §3 🔴 **평평함의 자** — 측정 전에 문턱까지 적는다

`m(n)` = 그 칸의 **씨앗 30개 Δρ 평균**. `se(n)` = 씨앗 표준오차 = `sd/√30`.

**칸 사이 기울기**(로그 n 단위):

    s_i = (m_{i+1} − m_i) / (ln n_{i+1} − ln n_i)
    se(s_i) = √(se_i² + se_{i+1}²) / (ln n_{i+1} − ln n_i)

**정의 — 그 칸이 「평평하다」**:

    |s_i| < F   그리고   |s_i| < 1.96 · se(s_i)      (즉 95% 신뢰구간이 0 을 품는다)

    F = 0.00353 (= CARD_T)

**🔴 F 의 근거**: 「n 을 **e배**(2.718배) 늘려도 Δρ 가 **카드 문턱보다 덜** 움직인다」.
카드 문턱은 이 저장소가 900노트 동안 「가/나/다」를 가르는 데 쓴 바로 그 수다.
자의 눈금보다 작은 변화는 **이 자로는 안 보인다**.

**🔴 두 조건을 **둘 다** 요구하는 이유**: 신뢰구간 조건만 쓰면 **씨앗을 줄일수록 「평평하다」가
늘어난다**(구간이 넓어진다) — **자를 나쁘게 만들면 답이 좋아지는 자**다. 크기 조건만 쓰면
잡음이 큰 칸이 우연히 통과한다.

**「평평해지는 n 이 있다」**:

    ∃ i 이고, i 이후 **모든** 칸이 평평하다  →  그 n_i 를 「평평 시작점」으로 원장에 박는다
    없다  →  🔴 「이 자로는 「대리변수인가」를 물을 수 없다」를 원장에 박는다

**곁으로 같이 낸다**(판정에 안 쓴다 · 곡선의 모양을 적기 위한 것):
- **포화 적합** `m(n) = a − b·n^(−1/2)` 최소제곱. `â` = 점근값. **씨앗 부트 1,000회로 `â` 의 95% 구간.**
  🔴 **구간이 0 을 품으면 「n→∞ 의 부호를 이 자는 모른다」**.
- **영교차점 n\*** — `m(n)` 이 0 을 지나는 n(선형 보간) · 씨앗 부트 95% 구간.
- **못 가르는 띠** — `verdict(m(n), T(n))` 이 「나 — 못 가른다」인 n 의 구간.

## §7 🔴 판정을 「가/나」로 안 찍는다
