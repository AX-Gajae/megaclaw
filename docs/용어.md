## 평가

**판(board)** — 도메인별 유보 Spearman ρ 의 평균. 지금 **0.4932**.

> 이름 충돌 주의: `lab/harness.py:311` 의 `board()` 는 **단순 평균**이고,
> 사이클 스크립트의 판은 **유보 채점 행 수 가중 평균**이다. 노트 수치는
> 가중 쪽. 두 정의의 순위 일치는 아직 안 쟀다.

**자(instrument)** — 채택 판단에 쓰는 다섯 잣대.

| 자 | 뜻 |
|---|---|
| 판 | 위 |
| 날짜 통제 판 | 발매 연도를 통제한 편상관 — "요즘 게 잘 된다"만 배웠나 |
| 무리 안 판 | `gen`/`grp` 로 쪼갠 뒤 무리 **안에서만** ρ — 무리 간 순서 착시 방지 |
| KR 만화 | 학습에 없던 수집 1,716행 (집 밖) |
| 비게임 앱 | 같은 취지 1,600행 (집 밖) |

**집 밖 짝** = 위 둘. 학습 "집" 밖의 수집. 이 둘은 ALL5 축만 갖는다
(trend/wiki/tag/gen/grp 는 0%).

## 실험 방법

| 말 | 뜻 |
|---|---|
| 씨앗 | 난수 시드 |
| 짝 씨앗 | 기준과 후보에 **같은 시드**를 써서 차를 잰다. 효과가 시드 잡음보다 작아 필수 |

| 팔 | 실험 조건 하나 |
| 손잡이 | 설정값 — `TRAINR`, `DOMDROP`, `TRAINCAP` … |
| 갈래 | 연구 방향 (문맥에 따라 나무 가지를 뜻하기도 한다) |
| 사전 등록 | 돌리기 **전에** 채택/기각 기준을 원장에 적는 것 |
| 원장 | `data/lab/denominator.json` |
| 조항 | 실험에서 얻어 방법론에 박은 규칙 |
| 관문 | 채택 심사 — 자 다섯 + 거부권 |
| 환율 | 집 밖 손해 ÷ 판 이득. 1 넘으면 기각 |
| 챔피언 / 도전자 | 현행 최고 / 후보 |
| 되돌림 | 채택을 물릴 때의 이름 붙은 상태 (예: "`TRAINCAP` 이 빈 F18") |
| 천장 | 그 도메인 자기 행만으로 교차검증한 상한 |

## 가드 — 모든 실행에 자동 (`lab/guards.py`, 19개)

지시문의 "가드 여덟" 은 오래된 수다.

| 이름 | 무엇을 잡나 |
|---|---|
| 엿보기 | 채점 라벨을 섞어도 예측이 안 변해야 한다 — 라벨 누수 |
| 치환 | 라벨 섞어 귀무분포, p ≤ 0.05 |
| 재현 | 씨앗 넷, 안정성 ≥ 0.95 |
| 분모 | 채점 대상 집합이 기준과 같은가 |
| 빈칸 | 축이 다 관측됐는데 값이 한 점에 붙은 레코드 = 미태깅 |
| 묶음 · 평탄 | 예측이 뭉쳤거나 거의 상수 — ρ 가 잡음을 잰다 |
| 시점 · 쌓임 | 예측 시점에 알 수 없는 축을 썼나 |
| 맨몸 | 유보 행에 손 축이 하나도 없는 비중 |
| 한철 | 유보에선 상수인데 학습에서만 변하는 열 |
| 그늘 | 판은 올랐는데 어느 도메인이 무너졌나 |
| 집단 | 합친 ρ 가 집단 **간** 순서를 재고 있나 |
| 귀착 | 남의 도메인 축을 흔들면 내 예측이 얼마나 남나 |
| 겹말 · 출처 · 살아있음 · 분해능 · 양규약 | 중복 축 · 자료원 혼입 · 유효 도메인 수 · 탐지 한계 · 규약 둘 |

## 학습 행 손잡이 (이번 사이클 채택분)

| 손잡이 | 하는 일 |
|---|---|
| `DOMDROP` | 도메인별로 어떤 축 계열을 가린다 (`{애니: trend_}`) |
| `TRAINCAP` | 그 도메인 학습 행을 비율만큼 표집 (`{만화: 0.5}`) |
| `TRAINW` | 도메인 학습 행 무게 = (유보 몫 / 학습 몫) 을 잘라 쓴다 |
| `TRAINR` | 행 무게 × `0.5^((2025-연도)/8)` — 학습 쪽 최근성 |
| `OOC_DROP` | 집 밖 예보 때 `entry_friction` 을 가린다 (부호가 수집마다 뒤집혀서) |
