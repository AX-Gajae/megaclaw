## §-1 🔴 증거력의 한계를 먼저 적는다 (조항 61)

이 사이클이 **못 증명하는 것**을 본문보다 먼저 적는다.

1. 🔴 **「이 저장소에 항진명제가 이제 없다」를 증명하지 못한다.** 내가 만드는 메타 검사는

5. 🔴 **이 사이클은 세계에 관한 어떤 명제도 새로 못 세운다.** 도메인 자를 **세우기만** 하고

## §3 판정 규칙 — 🔴 측정 전에 못 박는다

1. **자 A(정적 · 리터럴)** — `통과` 값을 만드는 표현식의 **자유 이름이 0개**면 항진명제로 센다.
   상수 접기(`bool(True)`·`1 == 1`) 뒤에도 자유 이름이 0개면 같다.
2. **자 B(동적 · 슬라이스 뿌리 변조)** — `통과` 표현식에서 **뒤로 슬라이스**해 감싸는 함수 안의
   의존 문장만 남기고, **슬라이스의 뿌리**(그 슬라이스가 대입하지 않는 이름)를 무작위로 `N=200` 회 변조해
   값을 모은다. **성공한 호출이 `N_min=20` 회 미만이면 「모른다」** 를 내고 `통과` 를 안 낸다.
   성공 호출의 값이 **전부 같으면 항진명제**로 센다.
3. **자 C(정적 · 자기 재계산 대조)** — 한 호출 자리에서 인자 둘이 ㉠ 어떤 순수함수 `f(**kw)` 의
   결과에 묶인 이름과 ㉡ **구문상 같은 `kw`** 로 `f` 를 다시 부르는 호출/람다면 항진명제로 센다.
4. 🔴 **세 자의 결과는 「합집합」으로 신고하되 자별 계수를 따로 낸다** — 어느 자가 무엇을 잡았는지
   안 적으면 다음 사이클이 자를 못 고른다.
5. 🔴 **검정력은 심어서 잰다.** 자마다 **심은 항진명제 ≥ 1** 과 **음성 대조(진짜 검사) ≥ 1** 을 넣고,
   **잡은 수 / 심은 수**와 **거짓 양성 / 음성 대조 수**를 둘 다 낸다.
6. 🔴 **「실행됐다」로 세지 않는다.** 심은 키의 계수는 **그 심기가 `통과` 를 True → False 로
   실제로 뒤집었을 때만** 1 로 센다.
7. 🔴 **무작위 인자가 판정을 안 물면 그 심기는 계수에서 뺀다** — 티처 #103 이 964 의
   「True 508 / False 1,492」를 분해해 보였듯, **손으로 변조했나만 결정하는 하네스는 감도가 아니다.**
   자 B 는 **뿌리별 감도**(어느 뿌리를 갈았을 때 값이 변했나)를 같이 낸다.
