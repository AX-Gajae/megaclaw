## §2 자 — 🔴 **정본은 「모형 고정 · 채점만 좁히기」다**

### 자 A (정본) — 고정 모형 within/between
1. 팔 전량에서 **한 번만** 적합한다. `rho_of(X, y, groups=개체, seeds=0..9, k=5)` 로
   씨앗 평균 OOF 예측 두 벡터를 얻는다 — `P₁ = P(①)` · `P₊ = P(①+③)`.
   🔴 **이 두 벡터는 그 뒤 절대 다시 만들지 않는다.**
2. 묶음 g(팔 B = **도메인** · 팔 A = **좌표원천**)마다 **채점만 좁힌다**:
   `ρ_g(①) = spearman(P₁[g], y[g])` · `ρ_g(①+③) = spearman(P₊[g], y[g])` · `Δρ_g = 차`.
3. 🔴 **분자 · 분모를 한 줄에 하나씩**:
   - 분자: `Σ_g n_g · Δρ_g` (n_g ≥ N_min 인 묶음만) · 분모: `Σ_g n_g` → **쌍 가중 안쪽 평균 Δρ_within**
   - 분자: `Δρ_합산 = ρ_전체(①+③) − ρ_전체(①)` · 분모: 팔의 쌍 전량 → **합산 Δρ**
4. 🔴 **차이가 자 A 의 전부다** — 957 의 수와 자 A 의 수는 **같은 물음에 대한 두 답이 아니라
   서로 다른 두 물음의 답**이다. 나란히 싣되 **이어 붙이지 않는다**(조항 60).

### 자 B (탐색 팔) — 켄달 일치쌍 짝 단위 분해
모든 지수 짝 (i,j), `y_i ≠ y_j` 인 것만. `s = sign(y_i − y_j)` ·
모형 M 의 기여 `c_M(i,j) = sign(P_M,i − P_M,j) · s ∈ {+1, 0, −1}`.
짝을 **안(같은 묶음)** 과 **사이(다른 묶음)** 로 가른다.
- 분자: `Σ_{안} (c₊ − c₁)` · 분모: **안쪽 짝 수** → 짝당 안쪽 이득
- 분자: `Σ_{사이} (c₊ − c₁)` · 분모: **사이 짝 수** → 짝당 바깥쪽 이득
- 분자: `Σ_{안} (c₊ − c₁)` · 분모: `Σ_{전체} (c₊ − c₁)` → 🔴 **안쪽 몫**
🔴 **동점 처리**: `y` 동점 짝은 **분모에서 뺀다**(그 짝은 어느 모형도 못 맞힌다). 뺀 수를 신고한다.

### SE 와 문턱
🔴 **결론이 걸린 수에 SE 를 붙인다**(티처 #96 C3 — 957 이 여기서 걸렸다).
- 군집 부트스트랩 400회 · 군집 열 = **개체**(팔 B) · **격자**(팔 A) · 씨앗 7.
- 재표집마다 **고정된 `P₁`·`P₊` 를 그대로 다시 채점**해 `Δρ_within` 을 다시 낸다(모형은 안 다시 적합).
- `T = max(0.00353, 2·SE_boot)` · 🔴 **어느 쪽이 이겼는지 산출물에 적는다.**
- 판정 `verdict(Δ, T)`: `Δ > T` → **가(든다)** · `Δ < −T` → **다(뺀다)** · 아니면 **나(못 가른다)**.
