## §2 🔴🔴🔴 1순위 — **시간 방향 유보**(여덟 사이클째 미룬 것)

### 2-1 설계 (측정 전에 못박는다)

- **시간 축**: base 행의 `언제`(`sao941`+`sao959`, 2015-09-30 ~ 2026-05-11 · 2,363 행).
- **절단**: `언제` 의 **20/40/60/80 분위** 넷 → 시간 블록 **0~4** 다섯.
- **원점 넷** `k = 1,2,3,4` (rolling origin · expanding window):
  - 학습 = **블록 `< k` 의 base 행** + **`언제` 가 절단 `k` 보다 «앞선» hplt 행**.
  - 유보 = **블록 `k`**. 🔴 **학습의 어떤 행도 유보의 어떤 행보다 뒤일 수 없다.**
- **유보 전량** = 블록 1~4 합집합. **게이트** = 그 합집합에서 도메인당 유보 행 `≥ 20`(`alpha977.MIN_HO`).
- **예산** `N_B = 1800`(`alpha977.N_B` 를 **이름으로** 인용) · **α = 0.95**(`alpha977.ALPHA_BASE`).
- **λ** = `alpha977.U_REG` 둘(`10^0` · `10^3`) · **겹 씨앗 다섯** = `alpha977.SEEDS`(뽑기 차례만 흔든다).
- **자 여섯** = `ruler979.Rulers6` 의 정의 그대로. 🔴 **가중은 «시간 방향 유보»의 `n_d` 로 다시 짓는다.**
  982 는 **자를 새로 만들지 않는다.**

### 2-2 배선 검사 W (변이체 대조를 붙인다 — 안 떨어지면 구성상 참인 검사다)

- **W1** 원점마다 `max(학습 시각) < min(유보 시각)` 이다. 🔴 **일부러 미래를 흘린 변이체에서 떨어질 것.**
- **W2** 원점마다 학습·유보의 **개체 교집합**을 센다(수를 싣는다 — 0 이라 «주장»하지 않는다).
- **W3** hplt 학습 행도 절단보다 앞이다.
- **W4** 유보 지문(`y` sha256 · 마스크 sha256)이 주행 시작·끝에서 같다.

### 2-3 등록 팔 둘

- **D 팔** — `v2.2` 의 채택 검사: **학습 라벨 파괴 `D1~D4`**(`D4` = 학습 라벨 «전량» 파괴).
  🔴 **`v2.2` 는 이 팔로 정본 자를 고른다.** 시간 방향 유보에서 그대로 돌린다.
- **M 팔** — 혼합: **`㉯ 대조`** 대 **`㉮ 층화(유보 목표)`**. 981 §2 의 팔을 시간 방향으로 옮긴 것.

**짝 SE** = 학습 붓스트랩(개체 묶음) 복제 **200**, 복제마다 겹 씨앗 다섯의 Δ 를 평균한 뒤 그 평균의 SD.
🔴 **점추정과 SE 의 벌 수를 같게 한다**(D 팔은 둘 다 25 벌 · M 팔은 둘 다 5 벌).

### 2-4 🔴🔴🔴 「자가 갈리나」 판정 규칙 — **측정 전에 못박는다**

시간 방향 유보에서 자 여섯이 아래 셋 중 **하나라도** 서로 다른 답을 내면 **「갈린다」**:

- **ⓐ 부호** — 등록 팔의 `Δ` 부호가 자에 따라 다르다.
- **ⓑ 관문** — `|Δ| ≥ 2·짝SE` 통과 여부가 자에 따라 다르다.
- **ⓒ 선택** — `pick981.pick()`(`v2.2` 기계 실행 · 체제 B)이 시간 방향 `D4` 입력에서 고르는
  정본 자가 **개체 묶음 판(981)의 `R_pool 묶음` 과 다르다.**

**정량 보조**(판정에 안 쓰고 같이 싣는다): **분기비 ≔ (자 여섯 Δ 의 최대−최소) / (자 여섯 짝SE 의 중앙값)**.

🔴🔴 **셋 다 같고 분기비가 모든 팔·λ 에서 `1` 미만이면 — 자 논의를 «닫는다».**
🔴 **어느 쪽이 나오든 그대로 적는다.** 「갈렸다」가 나오길 바라서 팔을 더 만들지 않는다.

🔴 **구조 사실을 미리 적는다**(측정이 아니다): 자 여섯은 전부 `n_d` 의 함수다 —
`R_eq ∝ n_d^0` · `R_z·R_z* ∝ (n_d−1)^0.5` · `R_pool ∝ n_d` · `R_iv·R_iv* ∝ (n_d−1)`.
**서로 다른 지수는 셋뿐이다.** 「자 전쟁 L1 0.004」는 지수 1 짜리 셋 사이의 이동이었다.

## §3 🔴🔴 2순위 — **이득 소멸의 기전을 검정력부터 재고 다시 묻는다**

입력은 **이미 있는** `runners/out981_decomp.json` 이다(새 측정이 필요한 곳만 다시 돈다).

### 3-1 🔴 MDE 를 «먼저» 싣는다

- 칸마다 **`MDE = 2 · 짝SE`** 를 낸다. `u=3` 첫 칸은 `2 × 0.025307 = 0.050614` 이고
  이는 그 칸 `㉮` 이득(`0.17956`)의 **28.2%** 다. 🔴 **「넘는 칸 0 개」는 「수렴이 죽었다」가 아니라
  「수렴이 28% 이상은 아니다」다.**
- 🔴🔴 **「복제를 늘리면 MDE 가 줄어드는가」를 «주장하지 않고 잰다»** — 짝SE 는 «학습 붓스트랩
  Δ 의 SD» 이지 「평균의 SE」가 아니므로 복제 증가로 안 줄어들 것이다. **첫 칸(`N_B=450` · `u=3`)을
  복제 800 으로 다시 돌려** `짝SE(200)` 대 `짝SE(800)` 을 싣는다.
- 그리고 **검정력이 있는 자 셋**으로 위약 팔을 다시 판정한다(칸별 관문 대신 **격자 전체**를 본다):
  ① 7 칸 **부호검정**(이항 양측 p) ② **스피어만(㉱ 이득, 대조 혼합 SD)** 의 **순열 p**(`7! = 5040` 전수)
  ③ **칸 가중 z** = `Σ Δ_i/se_i² ÷ √(Σ 1/se_i²)`.

### 3-2 🔴 물음을 바꾼다 — **목표 이동 팔 `㉮ − ㉱`**

`㉮ − ㉯` 는 「목표 이동 + 혼합 수렴」이고 `㉱ − ㉯` 는 「혼합 수렴만」이다.
→ 🔴 **`㉮ − ㉱` 가 목표 이동 팔이다.** `u=3` 첫 칸에서 `0.298050 − 0.131171 = 0.166879`.
981 은 **이 이름을 한 번도 안 불렀다.**

**첫 후보 = 대조 팔의 포화.** `u=3` 대조 ρ 가 `0.118490 → 0.364713` 으로 오른다.
- **오라클 여유** ≔ (격자에서 대조 팔이 도달한 최대 ρ) − (그 칸의 대조 ρ).
- 잰다: **스피어만(`㉮−㉱`, 오라클 여유)** · **`㉮` 팔이 오르는 폭 대 `㉯` 팔이 오르는 폭** ·
  🔴 **예산 절약 배수** = 「`㉮` 가 예산 `N` 에서 낸 ρ 를 `㉯` 가 내려면 필요한 예산 ÷ `N`」
  (격자 위 **log-선형 보간** · 격자 밖은 「모른다」로 적고 외삽 안 한다).

### 3-3 🔴 헤드라인을 고쳐 적는다

981 의 헤드라인 「층화 이득은 목표–자 **정렬도**의 단조 함수」는 **안 선다**:

- **자 여섯 전부가 자기 정렬도와 무관하게 같은 차례**(`T1>T4>T2>T3>T5`)를 낸다.

→ 🔴 **후보 축 둘을 «자 여섯 각각에서» 견준다**: **㉠ 목표–자 정렬도** 대
**㉡ 유보 지배 도메인(세계애니)으로 옮긴 학습 행 수**(`934/478/171/76/12` · 대조 `70`).
**자별로 두 스피어만을 나란히 싣고, 이긴 축을 헤드라인으로 쓴다.**

### 3-4 `T5` 는 곡선의 끝점이 아니다

`T5 역유보` 는 **조작이 둘**이다 — ① 지배 도메인을 **12 행**으로 굶긴다 ②
