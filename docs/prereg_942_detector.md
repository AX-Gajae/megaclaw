## 무엇을 고치나

### 일 A — `runners/out941_sao.py:67` 의 o 검출기

```python
ov = bool(o.get("daily")) or tot.get("visitors") is not None \
     or tot.get("sales_krw") is not None
```

`outcome.totals.*` 를 강제한다. 그런데 저장소에는 **적어도 세 가지 스키마**가 있다
(첫 파일 한 장씩 실측):

|---|---|---|
| 팝업(A) | `records` · `records_incomplete` · `records_thinbak` | `outcome.daily` · `outcome.totals` |
| 시장(B) | `market_records` | 🔴 `totals` 키 **없음** — 평평한 `visitors_total` · `sales_krw` |
| 아이돌(C) | `idol_records` | 🔴 `outcome` 키 **자체가 없음** — 평평한 `chodong` · `chart_peak` · `mv_24h` |

🔴 **「내가 아는 스키마」로 시작하지 않는다**(티처 #81 자가 적발 · 조항 60):
**먼저 `data/` 아래 레코드성 디렉터리 전부의 키 분포를 전수 집계해 파일로 떨군다.**
그 표를 보고 나서 검출기를 짠다. 새 러너 `runners/out942_stock.py`.
🔴 941 산출물(`runners/out941_*.json` · `data/ingest/sao941/`)은 **동결물 — 안 건드린다.**

### 일 B — `ingest/robots941.py:90-99` 의 대조기

```python
pat = d.split("*")[0]
if pat and path.startswith(pat): ...
```

첫 `*` 에서 자르고 접두사 비교한다 → `/*?*EventId=201357` · `/*.swf$` 가 전부 `/` 로
축약돼 **모든 경로에 걸린다**. `Allow` 는 파싱해 놓고 대조에 **안 쓴다**.
RFC 9309 로 다시 짠다: `*` 와일드카드 · `$` 끝 앵커 · **Allow/Disallow 최장일치**
(길이 동률이면 Allow 승). 새 러너 `runners/out942_robots.py`.
🔴 **새로 크롤하지 않는다** — `data/ingest/robots941/` 에 받아 둔 파일만 읽는다.

## 무엇이면 「내 수리가 틀렸다」인가

1. **고친 검출기가 A 계열(팝업)의 수를 바꾸면** — 팝업 레코드는 `outcome.totals` 를
   실제로 가지므로 옛 검출기와 **같은 157** 이 나와야 한다. 달라지면 내가 뭔가를
   깨뜨린 것이다.
2. **A5 ≠ (A 계열 수) + (B 계열 A4)** 이면 분모를 섞은 것이다.
3. **각 표의 「합 == 분모」가 거짓**이면 무효.
4. **B: RFC 대조기를 옛 규칙 집합에 물렸을 때, `Disallow: /` 하나만 있는 호스트의
   판정이 뒤집히면** 구현이 틀린 것이다(그 경우는 어느 구현으로도 막힘이어야 한다).
5. **B: 내가 짠 대조기가 941 의 대조기와 「모든 호스트에서」 같은 답을 내면** 고친 게
   아니다(적어도 aladin 하나는 뒤집혀야 한다).
6. 🔴 **두 번째 경로로 세지 않으면 무효** — 러너가 낸 수를 `python3` 한 줄짜리
   독립 계수(다른 코드·다른 순회)로 다시 세서 나란히 신고한다.

## 배선 검사 (측정 전에 한다)

- 🔴 **고친 함수가 정말 그 산출물에 닿는가**: 노트 940 이 `comparability(..., rel_thr=)`
  기본값이 import 시점에 동결돼 「상수만 바꾸고 판정은 불변」인 채 「고쳤다」고 적었다.
  942 의 새 러너는 **기본 인자에 문턱·경로를 안 넣는다**(모듈 상수는 호출부에서 읽는다).
- 옛 검출기와 새 검출기를 **같은 러너 안에서 같은 파일 순회로 둘 다** 돌려
  **행 단위로 나란히** 낸다(같은 명령·같은 입력 — 조항 59: 종료 코드 0 은 성공 신호가 아니다).
- robots 도 같다: **옛 `hits()` 와 새 `rfc9309()` 를 같은 16파일에 둘 다** 물려
  호스트별로 나란히 낸다.
- 입력 파일의 **sha256** 을 산출물에 적는다.
