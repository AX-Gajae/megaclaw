## 2. 🔴 「이벤트」의 조작적 정의 — 세고 나서 못 바꾼다

**이벤트 한 행 = 다섯 칸이 모두 차는 것.**

| 칸 | 이름 | 조작적 기준 |
|---|---|---|
| **가** | **개체 id** | 저장소 안에서 그 개체를 다시 찾을 수 있는 키(제목 · `record_id` · 영상 id · `engagement_id`) |
| **나** | **도메인** | 12도메인 중 하나, 또는 「채점 도메인 아님」 딱지 |
| **다** | **시각** | 그 일이 **일어난** 날짜/시각(`t_occur`). 🔴 아래 §3 의 시간 게이트를 통과해야 한다 |
| **라** | **무슨 일** | 이벤트 종류 이름(§4 의 고정 목록에서만) |
| **마** | **값 전/후** | 같은 개체·같은 열의 **직전 관측값**과 **직후 관측값**이 **둘 다** 있다 |

### 🔴 후보 슬롯의 4분할 — 두 이진 깃발의 곱 (배타·전수)

| 갈래 | 시각(다) | 값 전/후(마) |
|---|---|---|
| **5칸 완전** | O | O |
| **4칸(시각 O · 값 전후 X)** | O | X |
| **3칸(시각 X · 값 O)** | X | O |
| **≤2칸(시각도 값 전후도 X)** | X | X |

🔴 **넷의 합 == 후보 슬롯 전체** 를 `assert` 로 건다. 소스마다 따로, 그리고 전체로.

| 딱지 | 소스 | 슬롯 하나 = | 슬롯 수 공식 |

## 3. 🔴 시간 게이트 — 두 시각을 **다른 칸**에 적는다 (906·907 이 걸린 자리)

이벤트 행마다 **셋**을 적는다.

| 칸 | 뜻 | 없으면 |
|---|---|---|
| `t_occur` | 그 일이 **일어난** 시각 | 시각 없음 → 4분할의 아래 두 갈래로 간다 |
| `t_observe` | **우리 저장소가 그것을 처음 알 수 있었던** 시각 (파일의 수집 스탬프 · 스냅숏 시각 · 그것도 없으면 파일 mtime) | `null` 로 적고 `관측시각_출처="없다"` |
| `lag_days` | `t_observe - t_occur` | `null` |

**깃발**:
- `사후_동일시각`: `t_observe` 를 **독립적으로 못 얻어서 `t_occur` 로 대신 채운 경우** → `true`. 🔴 이 행은 **시간 게이트 불통과**로 딱지를 달고, ③(다음 이벤트 예측)의 전향 가능 집합에서 **뺀다**.
- `lag_days < 0` 인 행은 **오류**로 세고 산출물에 전량 싣는다(관측이 발생보다 앞설 수 없다).
- 🔴 `ingest/doc_select.is_pre_open()` 은 **부르지 않는다**(날짜를 못 읽으면 통과시키는 경로다 — 906·907 이 걸린 자리). 날짜 파싱 실패는 **통과가 아니라 `null`** 로 적고 따로 센다.

### 🔴 「물질적 변화」의 문턱 — 미리 고정

`스크린수`·`상영횟수` 는 매일 잔물결이 있다. 두 판을 **둘 다** 낸다:
- **원(raw)**: `Δ ≠ 0` 이면 이벤트
- **물질(material)**: `|Δ| ≥ 5` **그리고** `|Δ| / max(직전값, 1) ≥ 0.10`

🔴 **간격 분포·전이 표·덮음·selectivity 의 헤드라인은 「물질」 판이다.** 원 판은 참고로만 낸다. (문턱은 값을 보기 전에 정했다.)

## 6. 판정 규칙 — ③(다음 이벤트 예측)의 자

🔴 **판 ρ 를 쓰지 않는다.** 이 팔의 자는 둘이다.

### 6.1 간격 예측 대 기후값

- **표본**: 5칸 완전 이벤트 중 **시간 게이트를 통과한**(`사후_동일시각=false`) 행에서, 같은 (개체, 종류) 의 **연속 이벤트 간격** `gap = t_{k+1} - t_k` (일).
- **기후값 기준선 (규약 43 · 노트 792)**: *「아무 조건 없이 **그 도메인의** 전체 간격 중앙값을 늘 말한다」*.
- **조건부 예측**: *「그 **(도메인, 종류)** 의 간격 중앙값을 말한다」*.
- **자**: 절대오차 중앙값(MedAE)과 평균절대오차(MAE). **둘 다 낸다.**
- 🔴 **분할**: 개체 단위 홀드아웃(개체 id 해시로 70/30). 중앙값은 **학습 쪽에서만** 뽑는다. 평가는 홀드아웃 쪽에서만.
- 🔴 **잡음 단위는 개체다**(노트 897·899 — 씨앗이 아니라 군집). 구간은 **개체 군집 부트스트랩** `lab/pairboot.py` 의 `cluster_boot`(BCa)로 낸다(규약 47). **못 부르면 폴백 사유를 명기**하고 순 percentile 을 쓴다.
- **판정**: 홀드아웃 MAE 개선의 **BCa 95% 구간이 0 을 안 물면** 「이긴다」. 물면 **「판정 불능」**(「진다」가 아니다).

### 6.2 구간 덮음

- **구간**: (도메인, 종류) 별 학습 쪽 간격의 **10분위~90분위**. **명목 덮음 0.80**.
- **실측 덮음**: 홀드아웃 간격 중 그 구간에 드는 비율.
- **두 층으로 낸다**(노트 792 형): **도메인 구간**(도메인만 조건)과 **종류 구간**((도메인, 종류) 조건).
- 🔴 **덮음이 명목에서 벗어나면 벗어난 방향과 크기를 적는다.** 「좋다/나쁘다」로 안 적는다.

### 6.3 🔴 라벨 순열 selectivity (반드시 돌린다)

- **귀무**: 이벤트 시각이 자료와 무관하다.
- **섞는 법**: 같은 개체 안에서 `t_occur` 을 무작위 재배정(개체별 시각 다중집합은 보존, 종류-시각 짝만 깬다). **1,000회.**
- **통계량**: 종류→종류 전이 표의 **총변동거리**(실측 표 대 주변곱 표).
- **판정**: 순열 분포에서의 p 값. 🔴 **p ≥ 0.05 면 전이 표를 산출물에 「자료와 무관」 딱지를 달아 싣는다.**

### 6.4 🔴 첫 양수 금지 (노트 133)

간격 예측이 기후값을 이기면 **그대로 채택하지 않는다.** 최소 다음 셋을 같이 낸다:
1. **음성 대조** — 종류 라벨을 무작위로 섞은 「가짜 조건부」가 기후값을 이기나 (이기면 이득은 조건이 아니라 분할 자유도에서 온 것이다)
2. **누설 점검** — 예측에 쓰인 중앙값이 홀드아웃 개체를 포함하지 않았나 (`assert` 로 건다)
3. **도메인별 분해** — 이득이 한 도메인(영화)에서만 오나

## 9. 판정문의 꼴 (미리 고정)

**③ 에 대해서** 셋 중 하나로 끝난다.

1. **「간격 예측이 기후값을 이긴다 — 개선 X (BCa 95% [lo, hi], 0 을 안 문다) · 분모 <홀드아웃 간격 수>」** + §6.4 의 셋을 같이 적는다
2. **「판정 불능 — 구간이 0 을 문다」**
3. **「못 잰다 — <결핍물> 이 없어서다」** (조항 59 · 901 §6 의 꼴)

**④·⑤ 에 대해서**는 **뒤집으려 하지 않는다.** 다음 꼴로만 적는다:

> **「④(⑤)를 0 에서 올리려면 <무엇>이 <몇> 행 더 필요하다 — 지금 이 표에는 <수>(<딱지>) 뿐이다.」**

🔴 **「없다」가 아니라 「이 표에는 없다」로 적는다**(조항 59 · 조항 60).
