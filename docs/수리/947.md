## 2. 🔴 바늘을 넓히기 **전에** 물은 것 — 「내 새 바늘도 못 보는 자리는?」

946 의 자는 **같은 파일에서 정의된 래퍼**만 봤다. 주 세션이 티처 #86 을 검증할 때 쓴
바늘은 「리스트 첫 원소 = `'git'`」이라 래퍼를 통째로 못 보고 **9 를 5 로 셌다.**
그래서 이 사이클은 넓히기 전에 갈래를 먼저 세었다:

| 갈래 | 무엇 | 946 이 봤나 |
|---|---|---|
| ① | argv 리터럴 `["git", …]` | ✅ |
| ② | 래퍼 호출 — 같은 파일 **및 import 한 남의 모듈** | 같은 파일만 |
| ③ | f-string / `%` 조립 | ❌ |
| ④ | 셸 문자열 `run("git …", shell=True)` · `os.system` | ❌ |
| ⑤ | **변수로 조립한 argv** `args = [...]` → `args += [...]` → `_git(args)` | ❌ |

🔴 **⑤ 는 바늘을 다 짜고 나서 발견했다.** 티처가 지목한 `fiveprime902.py:147` 이
정확히 그 꼴이라, ①②③④ 만으로는 **그 자리를 여전히 못 봤다.**
「바늘을 넓혔다」가 **또 좁을 뻔했다** — 이 사이클에서 가장 값나가는 한 걸음이다.

## 9. 🔴 이 사이클이 자기에게 걸린 것 (조항 59 · 두 번)

1. **러너가 `import` 에서 죽었는데 종료코드만 보고 「3 절이 실패했다」로 읽었다.**

   그때 읽은 JSON 은 **직전 실행의 것**이었다. **「돌았다」와 「났다」는 둘이다.**
   → 수리: 러너가 **시작할 때 옛 산출물을 지운다**(`OUT.unlink()`).
2. **탐색 러너에서 JSON 키 셋을 전부 `"그 목록"` 으로 써서 둘이 덮어써졌다** —
   티처 #86 을 검증할 때 주 세션이 당한 그 병을 **같은 날 다시** 냈다. 고쳤다.
