## 4. M1 — 「러너가 찍는다」가 **낡은 판을 찍고 있었다** (티처 #89 M1)

949 는 *"노트의 수를 러너가 산출물에서 읽어 찍는다"* 고 `runners/note949_gen.py` 를 만들었고
**손 전사는 정말 0** 이었다. 🔴 **그런데 입력 `runners/exp949_harm.json` 이 `e4c63bc64` 에서
107줄 고쳐졌는데 `.md` 를 다시 안 찍었다.**

다시 찍으니 **바뀐 줄은 딱 하나**(통합 diff 로는 `-`/`+` 둘):

```
- … 넓은 자 `{"쟀다": 7, "못 돌렸다": 4, "분모 0": 0}`
+ … 넓은 자 `{"쟀다": 4, "못 돌렸다": 4, "분모 0": 0, "🔴 자가 못 잰다(-z …)": 3}`
```

🔴 **하필 그 7 은 탐색 노트(`docs/탐색/949.md`)가 스스로 철회한 수다** — 넓힌 자가
새로 닿은 셋은 「쟀다」가 아니라 「못 잰다」였다.

### 🔴 「다시 찍었다」로 끝내지 않았다 — **대조를 박았다**

- `runners/note950_gen.py` 가 **입력 목록을 AST 로 뽑고**(`note949_gen` 의 `J("…")` 리터럴 —
  손으로 베끼면 그 목록이 또 낡는다) 입력 **6** 개 · 생산기 **2** 개 · 문서 **1** 개의
  **sha256 을 `runners/out950_docstamp.json` 에 박는다**
- ⑤′ 에 절 **`7 문서 대조`** 를 신설 — 그 도장 파일을 **읽고**, 기록된 sha 를 **꺼내어**,
  **지금 파일에서 다시 계산해 견준다**. `CHECK_CRITERIA` 셋을 그대로 채운다

🔴 **이것이 949 가 정의한 「대조」의 첫 자기 적용이다.** 949 는 「도장은 아무것도 안 막는다」를
증명해 놓고 **자기 문서에는 도장조차 안 박았다** — 그래서 낡음을 아무도 못 잡았다.

⚠ **한계**: 이 대조는 **낡음만** 잡는다(§0-2).
