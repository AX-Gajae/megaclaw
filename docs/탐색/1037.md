### 0-마. 회수 사슬 — 「없다」·「못 봤다」·「못 읽었다」를 셋으로 센다 (조항 59)

각 단계의 통과/실패/재시도를 **세어서 적는다**. 빈 응답·0바이트·HTTP 200 껍데기는 성공 아님.

1. **S1 좌표**: parquet 에 f·o·s 있음 → 실측 26,364/26,364
2. **S2 경로**: 매니페스트에서 파일명 → 전체 경로 매칭
3. **S3 Range**: `curl -r o-(o+s-1)` → HTTP **206** 이고 받은 바이트 == 요청 바이트
4. **S4 gunzip**: 종료 0 이고 산출 ≥ rs×0.5
5. **S5 WARC**: `WARC-Type: response` 레코드 파싱 · HTTP 헤더 뒤 본문 확보
6. **S6 발행일**: 아래 사슬이 온전한 날짜를 냄
7. 실패 사유별 계수: 경로없음 / 4xx / 5xx / 타임아웃 / 바이트불일치 / gunzip실패 / 비-response / 본문없음 / 날짜없음 / 날짜불온전

재시도: 각 요청 최대 **3회**(0.5s·2s 지수 백오프). 동시 **12**. 예의: 요청 간 호스트 전역
간격 없음 대신 동시성 상한으로 억제 — Common Crawl 은 공공 자원이다.

| 순위 | 이름 | 신뢰 | 무엇 |
|---|---|---|---|
| ① | `jsonld` | 0.95 | JSON-LD `"datePublished"` |
| ② | `og` | 0.90 | `article:published_time` (property/content 양순서) |
| ③ | `htmlmeta` | 0.85 | `<meta name\|property\|itemprop = date·pubdate·publishdate·publish_date·datePublished·article.published>` |
| ④ | `time` | 0.75 | `<time datetime=…>` |
| ⑤ | `url` | 0.70 | URL 경로 `/YYYY/MM/DD/` · `YYYYMMDD` · `?date=` |
| ⑥ | `body` | 0.60 | 본문 마커(`입력·등록·승인·작성·게재·송고·기사입력·발행`) + 날짜 |
| ⑦ | — | — | 실패 = `null` = **못 읽었다** |

**충돌 규칙**
- 순위 높은 것이 이긴다. 같은 순위 안에 값이 여럿이면 **가장 이른 날짜**를 택한다
  (수정일·재게시일이 뒤에 붙으므로).
- **온전성**: `1991 ≤ 연 ≤ 2026` 이고 `발행일 ≤ 크롤시각 + 2일`. 어기면 그 후보를 버리고
  다음 순위로 내려간다(전체를 버리지 않는다).
- 채택값과 **다른 순위의 최상위 후보**가 7일 초과 어긋나면 「충돌」로 세어 적는다.
  값은 상위 것을 쓴다.
- 부수 산출: 기존 HPLT 본문 사슬(v1)이 낸 값과 WARC HTML 값의 일치율 —
  v1 사슬의 «외부 검증»이 된다(등록된 부수 관심사, 판정에는 안 쓴다).
