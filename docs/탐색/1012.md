## §1. 🔴 MDE 칸 (신설 이행 — 외부 심사 발의 · 티처 #144 병행 심사 중 → 형식 «자발 게재»)

- **주대비의 2×클러스터SE 예상치(1005 실측 재사용 · sha 인용)**: out1005(`cd3a6ce8c4f4841a`)
  「Δ·SE 표」 전체 칸 — Δ전체(4B−0.5B · 짝지은 씨앗 · 같은 val 70 개체 클러스터 붓스트랩
  B=10,000)의 SE^cl **0.00928** → **2×SE^cl 예상 = 0.01856**. J5_전체(같은 out1005 정본) =
  **0.0079**.
- **이 실험이 검출 가능한 최소 효과(MDE · 사전)**: 문턱형이 `max(J5_전체, 2×SE^cl)` 이므로
  **MDE ≈ +0.01856**(전체 MdAPE 눈금 · 실현 문턱은 [11012,4] 실측 — 이번 비교는 같은
  임베더·짝지은 씨앗이라 두 팔 예측 상관이 4B/0.5B 비교보다 높아 실현 SE 는 이보다 작을
  개연 — 관대 쪽 예상임을 자백하고 실현값을 out 에 게재).
- **예상 효과(연역 계수 규격)**: 점 예상은 연역 불가(등록 시점 실측 0). **상계 = 절제 이득
  전부가 타이밍일 때 +0.0270**(없음 0.0839 − 0.5B 0.0569 · out1005). 상계/MDE = 1.45 —
  **예상 효과 상계가 MDE 를 넘으므로 «판정 게이트»로 등록한다**(측정 사이클 강등 아님).
- **🔴 검출력 자백**: 타이밍 몫 s 의 검출 하한 = MDE/0.0270 ≈ **0.69**. s < 0.69 인 «부분
  타이밍»은 비악화(ⓐ)로 나온다 — 그래서 ⓐ 판정어는 반드시 「이 MDE 눈금 한정」 낙인 + Δ ± SE
  원값 병기로 적는다(귀무 수용이 아니라 «상한 진술»). ⓑ(유의 악화)는 낙인 불요(검출이므로).
