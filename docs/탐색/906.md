## 왜 이 통로를 골랐나

`docs/아키텍처.md` §10 이 지적한 대로 **900번대 노트가 전부 자급자족**이었다.
906 이 부딪힌 문제는 이 저장소만의 문제가 아니다 —
**「라벨 y 가 특징 x 의 재명명인가」를 재려는데, x 의 조합이 거의 유일하면 조건부
엔트로피가 정의상 0 이 되어 답이 자명해진다.** 906 은 이 벽을 **복잡도 통제(트리 깊이) +
LODO** 로 넘었다. 남들은 어떻게 넘었는지 본다.

## 찾은 것 3가지

### 1. Hewitt & Liang (2019) — control task · selectivity

**문제 진술이 906 과 같다**: 프로브(=라벨을 특징에서 맞히는 분류기)의 정확도가 높아도
그것이 「표현 안에 정보가 있어서」인지 「프로브가 외운 것」인지 구별이 안 된다.

**처방**: 같은 입력에 **무작위로 붙인 라벨**(control task)을 만들어 같은 프로브를 돌리고,
`selectivity = 진짜 과제 정확도 − control 과제 정확도` 를 본다.
프로브가 외우는 힘이 세면 control 도 잘 맞히므로 selectivity 가 0 으로 죽는다.

🔴 **906 과의 대응**: 906 의 「5-튜플 암기 상한」이 정확히 control 의 자리를 맡는다 —
암기 오류 0 이라는 값이 *"이 특징 집합은 무엇이든 외울 수 있다"*를 보이는 수다.
🔴 **다만 906 은 무작위 라벨 대조를 안 돌렸다.** selectivity 를 실제로 계산한 적이 없다.

### 2. Voita & Titov (2020) — MDL probing

**control task 의 약점을 지적한다**: control 은 과제마다 **사람이 손으로 만들어야** 하고,
프로브 크기를 손으로 제한해야 차이가 보인다(=하이퍼파라미터 탐색이 결과를 바꾼다).

**처방**: 정확도 대신 **최소 기술 길이(MDL)** 를 잰다 —
「특징이 주어졌을 때 라벨을 적는 데 드는 비트 수」이고,
**프로브의 복잡도까지 그 비트 안에 포함**되므로 별도의 control 이 필요 없다.
online coding / variational coding 두 가지 추정법을 준다.

🔴 **906 과의 대응**: 906 의 「깊이 사다리 + LODO」는 **복잡도를 손으로 통제한 것**이라
Voita & Titov 가 지적한 바로 그 약점(손 탐색)을 갖는다.
**MDL 을 쓰면 깊이를 고를 필요가 없다.** 이것이 이 탐색의 제일 큰 수확이다.

- 논문: <https://aclanthology.org/2020.emnlp-main.14/>
- 설명 글: <https://lena-voita.github.io/posts/mdl_probes.html>
- 코드: <https://github.com/lena-voita/description-length-probing>

### 3. Label-Descriptive Patterns (Hedderich et al. 계열)

이진 특징과 라벨이 있을 때 **라벨 분할을 설명하는 패턴 집합**을 MDL 로 고른다.
분류기의 **오차를 패턴으로 설명**하는 데 쓴다.

🔴 **906 과의 대응**: 906 의 **잔여 22짝**을 「무엇이 그것들을 다르게 만드나」로 설명하려면
이 꼴이 맞는 도구다. 906 은 도메인 분해와 접두사 관찰까지만 하고 **패턴을 안 뽑았다**.

- <https://arxiv.org/pdf/2110.09599>
- MDL 원리 일반: <https://en.wikipedia.org/wiki/Minimum_description_length>

## 다음 사이클의 후보 (🔴 이번 사이클 결론이 아니다)

1. **무작위 라벨 control 을 돌려 selectivity 를 낸다.** 906 의 암기 상한을 수 하나로 바꾼다.
2. **MDL(online coding)로 「등급의 기술 길이」를 다시 잰다.** 깊이를 손으로 고르는 자리를 없앤다.
   그러면 「0.362 비트」가 **복잡도 비용까지 포함한 수**로 바뀐다.
3. **잔여 22짝에 label-descriptive pattern 을 돌린다.** 열 이름의 뜻을 사람이 안 적어도
   패턴이 나올 수 있다 — ⓪-나 가 「사전이 없다」고 적은 자리의 **우회로**다.
