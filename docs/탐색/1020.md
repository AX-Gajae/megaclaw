## §1. 세계 물음

이지 천장 그 자체는 아니다 — 이 한계를 §8 에 정직 병기). 이걸 재면 ⓐ 「모든 결과 예측」의 가능 범위에

## §3. 흩어짐 자 — 사전 고정

각 층(S0·S1·S2·S3·D × 전량/A·B · clean 은 S0 만)에 대해:
- **게재**: n_쌍 · n_그룹 · mean(d)(표류 관찰) · **SD(d)** · **median|d|** · MAD(|d−median d|) ·
  **×배 눈금 = exp(median|d|)**(「같은 IP 반복인데 U 가 중앙 ×?배 갈린다」).
- **개별 사건 σ 환산**(그룹 내 iid·대칭 가정 명기): σ̂_SD = SD(d)/√2 ·
  σ̂_med = median|d|/(√2·0.674490)(정규 상수 명기 — 로버스트 정본, SD 판은 참고 병기).
- **불확실성**: **IP 그룹 클러스터 붓스트랩 B=10,000 · seed=1020**(재표집 단위 = 키 그룹) —
  median|d|·SD(d) 각각의 SE(붓스트랩 표본 표준편차). n_쌍 < 5 인 층은 SE 대신 「표본 부족」 낙인.
- **유사 vs 비유사**: S2(유사) 대 D(비유사)의 median|d| 차이 + 같은 붓스트랩에서의 차이 SE —
  «조건이 설명하는 몫의 상한» 관찰(격자 조건이 흩어짐을 줄이는가).

## §4. 천장 환산 — 환산식 사전 명기

- **m_ε = median|d| / √2** — 완전한 조건부 중앙값 모형이 조건을 다 알아도 남는 log 오차의 중앙값
  (쌍 차 d = ε_i − ε_j 의 iid 분해 — √2 는 정규 근사).
- **MdAPE-급 하한**: 정본 = **경험 대칭화** median{ |1 − e^(−s·d/√2)| : 전 쌍, s∈{+1,−1} } ·
  참고 = 폐형 근사 e^(m_ε) − 1.
- **자 A(핀볼 평균·5분위 {.05,.25,.5,.75,.95}) 눈금 하한**: ⓐ 정규 근사 = **0.248140 × σ̂**
  (상수 = mean_τ φ(Φ⁻¹(τ)) — 완전 모형의 기대 핀볼) · ⓑ 경험 = 대칭화 ε̂ 풀 {±d/√2} 의 경험
  분위수에 대한 경험 핀볼 평균. σ̂ 는 σ̂_med 정본 · σ̂_SD 참고.
- 🔴 **눈금 정직 신고**: 이 천장은 «일평균 방문자 U(자연로그)» 예측의 천장이다. 자 A 0.07242 ·
  집계 MdAPE 5.7% · 웹툰 MdAPE 23.5% 는 «위키 관심 log1p 곡선» 눈금 — 표는 나란히 놓되 환산
  주장이 아니라 **관찰**이다(관심↔방문자 환산은 미측정).
