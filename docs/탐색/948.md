### 왜 「우연」인가 — 심어서 확인 (분모 12)

| 심은 꼴 | 잡나 |
|---|---|
| 가 저장소 관용구 그대로 `["git","-C",str(ROOT),"status","--porcelain"]` | ✅ (경로가 지워져서) |
| 타 `["git","-C","/x","status","--porcelain"]` (경로 플래그 있음) | ✅ (「🔴 하위명령을 못 읽었다」 갈래로) |
| 🔴 나 **같은 것을 f-string 으로** `["git","-C",f"{ROOT}","status"]` | ❌ |
| 🔴 다 `["git","-C","/x/y","ls-files"]` | ❌ |
| 🔴 라 `["git","-C",".","status"]` | ❌ |
| 🔴 마 `run("/usr/bin/git status --porcelain", shell=True)` | ❌ (자리 자체를 못 봄) |
| 🔴 바 `run(f"{GIT} status --porcelain", shell=True)` | ❌ (자리 자체를 못 봄) |
| 🔴 사 `run(" git status --porcelain", shell=True)` (앞 공백) | ❌ (자리 자체를 못 봄) |
| 🔴 아 `["/usr/bin/git","status","--porcelain"]` | ❌ (`c[0]=="git"` 이 아님) |
| 🔴 자 `["git","--git-dir","/x/.git","ls-files"]` | ❌ |
| 🔴 차 `["git","--work-tree","/x","status"]` | ❌ |
| 🔴 카 `args = ["-C","/x","status"]` → `_g(args)` (갈래 ⑤) | ❌ |

**12 중 10 이 빠져나간다.** 🔴 특히 **「나」가 핵심 침입 경로**다 — `f"{ROOT}"` 는
`str(ROOT)` 와 뜻이 같은, 이 저장소가 다른 곳에서 이미 쓰는 평범한 표기다.
`_str_of` 가 f-string 엔 `None` 대신 **`"\x00"` 자리표시를 내므로 원소가 안 지워지고,
그러면 위의 「우연」이 깨져 `-C` 뒤의 `\x00` 가 하위명령 자리를 먹는다.
**42 자리 중 하나를 `str(...)` 에서 f-string 으로 바꿔 쓰는 순간 그 자리는 분모 밖으로 나간다.**

3. **분모는 `.py` + 지역 브랜치 끝점 69 뿐이다.** 원격 브랜치·과거 커밋 내부·`.sh`·
   서브에이전트 프롬프트(저장소 밖)는 **안 훑었다** — 브랜치 전량 커밋 순회는 이 환경에서
   2분 안에 안 끝나 포기했다(`timeout` 명령도 없다). 🔴 **0 은 「안 걸렸다」이지 「못 걸린다」가 아니다.**
4. **유령의 의도를 모른다.** 저장소 안에 근거가 0 이라 「초병이 아니다」는 **부재 논증**이다.
   947 을 쓴 세션에 물어야 확정된다.
5. **차집합 개수를 안 실었다**(조항 62 를 부를 일이 없게). 절 「가」는 두 갈래의
   **분할**(0 + 42 = 42)이고, 절 「라」의 자 B 차는 **양방향 [0, 0]** 을 같이 적었다.
6. **고쳐 보지 않았다.** 「가+나」를 같이 고치면 7/7 이 된다는 것은 **모의 함수로** 잰 것이고
   `lab/gitcall.py` 는 **한 글자도 안 건드렸다**(주 세션이 고치는 중이라).
