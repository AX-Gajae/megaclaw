- 🔴 **정직 신고 ①**: 「혼란 전부 관측」은 검증 불가 — **민감도(E-value 류)** 병기:
  d = 조정 평균 효과 / SD_위약 → RR ≈ exp(0.91·d)(VanderWeele 표준화 평균차 근사) →
  **E = RR + √(RR(RR−1))** — 「미관측 혼란이 처치·결과 양쪽과 이 RR 이상 결합해야 효과가 0 으로
  뒤집힌다」의 수. 산식·해석 문장 함께 게재.
- 🔴 **정직 신고 ②(인과 화법 규율)**: 팝업 개최는 무작위 배정이 아니다 — 본 사이클의 모든 효과
