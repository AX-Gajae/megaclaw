## §3. 합성통제 (명세 L3-1 · 사전 고정)

- **공여 풀**(처치 건별): 같은 도메인 wiki_daily 행 중 ⓐ `키`가 원장 record_id 아님 ⓑ `문서`가
  원장 해소 문서 집합(238 페이지) 밖 ⓒ `문서` ≠ 처치 문서 ⓓ 같은 두 창을 85/86 커버.
  후보 > 25 면 사전 창 log1p 피어슨 상관 상위 **K=25**(동률 키 사전순). 후보 < 5 = 「공여 부족」(R3 탈락).
- **적합**: min_w ‖Xw − y‖² · w ≥ 0 · Σw = 1(볼록 — 외삽 금지). X,y = 사전 창 90일 log1p.
  Frank-Wolfe 500회 · 초기 균등 · argmin 동률은 낮은 인덱스(키 사전순 행렬). 결정론.
- **품질 관문(사전 명기)**: RMSE_pre ≤ 0.30 ∨ RMSE_pre ≤ 0.75×SD(y_pre). 미달 = 「적합 불가」
  (R4 탈락 — 분모에서 제외 «신고»). 위약에도 같은 관문(비대칭 금지).
- **효과**: log 정본 = mean_{사후 91}(log1p 실제 − Xw) · 원 눈금 증분 = Σ_{사후 91}(실제 − expm1(Xw)).
- **누수 관문**: 가중치 적합 입력 = 사전 창뿐. 건별 `assert_no_leak`(입력 = 사전 창 관측일 ·
  as_of = T0) — 사전 창이 T0 를 넘는 곡선 창 **0** 검사 · 스탬프 집계 게재(전 건 통과 수 · 최소 여유일 ·
  대표 스탬프 1). 공여의 «사후 창» 관측은 반사실 구성 그 자체다(처치 결과의 누수가 아님 — 방법 선언).

- 🔴 **정직 신고 ①**: 「혼란 전부 관측」은 검증 불가 — **민감도(E-value 류)** 병기:
  d = 조정 평균 효과 / SD_위약 → RR ≈ exp(0.91·d)(VanderWeele 표준화 평균차 근사) →
  **E = RR + √(RR(RR−1))** — 「미관측 혼란이 처치·결과 양쪽과 이 RR 이상 결합해야 효과가 0 으로
  뒤집힌다」의 수. 산식·해석 문장 함께 게재.
- 🔴 **정직 신고 ②(인과 화법 규율)**: 팝업 개최는 무작위 배정이 아니다 — 본 사이클의 모든 효과
