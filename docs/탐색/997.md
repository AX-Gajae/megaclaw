### 4-나. 🔴 **셋 다 「텍스트 몸통」이 아니다** — FineWeb2 를 «그 자리»에 넣는다는 말의 뜻

- `fieldmodel` 과 `grid915` 는 **입력이 (개체 × 시간) 실수 격자**다. 웹 문서는 이 자리에 **꼴이 안 맞는다** — 넣으려면 문서를 먼저 **(개체 × 시간) 요약으로 접어야** 한다(996 §3-나 의 ①~⑥).
- `ssl909` 만 텍스트를 «본다». 그런데 텍스트가 들어가는 자리는 **`state/ssl909.py:128 attach_text`** 이고, 거기서 하는 일은
  `state/ssl909.py:145-146` `HashingVectorizer(analyzer="char_wb", ngram_range=(3,4), n_features=2**18, alternate_sign=False, norm=None)`
  → `:148` `TfidfTransformer` → `:151` `TruncatedSVD(n_components=kk)` → **k=64 열의 블록으로 축 행렬에 붙인다**.
