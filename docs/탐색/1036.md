# 1036 — 텍스트 채널: 표적을 곡선에서 «사건»으로 바꾸고 본문을 넣었다

> 🔴 **이 노트는 사후 기록이다.** 1036 은 주행 당시 저장소에 문서·러너·원장을 **하나도 남기지
> 않았다** — 산출물(`wm_harvest/foundation/textfix1036/`)만 있었다. 1037 티처가 「1036 재현
> 실패 · 저장소에 흔적 전무」로 정확히 잡아냈다. **규약 위반이고, 이 문서와 `runners/*1036*.py`
> 가 그 빚을 갚는 것이다.** 사전등록도 대화 안에서만 이뤄졌다(커밋 없음) — 그러므로 아래 판정은
> **사전등록된 판이 아니라 「관찰」 등급**으로 읽어야 한다.

## §1 왜 했나

사용자 지시: *「단순히 90일 곡선을 맞추려고 수치적으로 접근하지 마라. 수치는 인과의 결과고
중요한 건 인과와 어떤 일이 발생할지다.」*

그래서 표적을 **91일 곡선 핀볼**에서 **이산 사건 예측**으로 바꿨다.

- **사건 정의**(성능 보기 «전» 고정): 뒤 91일 안에 조회수가 **앞 90일 중앙값의 3배 이상**
  되는 날이 있는가. 기저율 **25.7%** · 도메인별 9.7~43.7%.
- **지표**: AUC · P@10%(상위 10%로 찍은 것 중 실제 급등 비율).

## §2 입력 병목을 고쳤다

기존 텍스트 임베딩이 보던 문자열은 **메타데이터 111자**였다:
`"cc22 · ohmynews.com · com · 일론 머스크 · … · f646598f… · ko"`

HPLT parquet 464개를 훑어 **본문 26,364/26,364 전량 회수**(중앙 2,102자 · 빈 것 0 · 142초).
같은 인코더(Qwen2.5-0.5B)로 **96토큰 → 512토큰** 재임베딩(6,564 문서 · MPS · 596초).
행↔문서 매핑은 `triples.py` 자구 그대로 재현해 **10,654/10,654 일치** 확인.

## §3 판정 (10겹 CV · 문서 분할 · 문서 클러스터 붓스트랩 485)

| 팔 | AUC | P@10% | 배수 |
|---|---|---|---|
| ⓐ 곡선만 | 0.5994 | 0.4610 | 1.79× |
| ⓑ 메타데이터 96토큰 | 0.6060 | 0.4254 | 1.65× |
| ⓒ 실제 본문 512토큰 | 0.5992 | 0.3953 | 1.54× |

셋 다 **AUC CI95 가 0.5 를 배제**(사건 예측 자체는 우연보다 낫다).
**셋 사이는 전부 못 갈랐다** — ⓒ−ⓑ Δ−0.0064 CI[−0.0488,+0.0359] · MDE **0.0427 AUC**.

**예측이 반증됐다**: 「본문이 안 닿는 게 병목」은 이 자로 안 섰다.

## §4 🔴 진짜 원인 진단 — 시각 어긋남

`a_액션.언제` 가 **크롤 시각**이라 문서가 상태창과 어긋나 있다.

```

  🔴 상태창(앞 90일) «밖»에서 발행된 것 76.6%
```

2022년 9월 상태에 2020년 기사를 붙여 놓고 2022~23년 급등을 맞히라고 물은 셈이다.

**⚠ 1037 이 이 진단을 더 큰 표본에서 확증했다 — 그리고 더 나쁘다**:

## §5 이어진 시도 둘 (사후 · 관찰)

- **정규화**: 원시 임베딩의 무작위 두 문서 코사인이 **0.9643**(평균벡터 크기 0.9819)이었다.
  평균+상위8 주성분 제거로 0.0001 까지 내렸다. **검색은 눈에 띄게 고쳐졌다**(유사도에 동적
  범위가 생김: 0.994~1.000 → 1.000~0.524). 🔴 **그러나 예측은 안 나아졌다** —
  분류기가 이미 차원별 표준화를 하고 있어 선형 프로브엔 anisotropy 가 해가 아니었다.
- **오염**: 개체명이 본문에 **0회 20.2% · 1회 46.9% · 2회 이상 32.9%**.
  도메인별 편차 극심(웹툰 46.1% ↔ **게임 3.5%**). 2회 이상만 남기면 검색 리프트가
  오히려 하락(2.89× → 2.52×) — **동음이의어**(웹툰 「인피니티」 ↔ 자동차 인피니티)를
  언급 횟수로 못 가른다.
