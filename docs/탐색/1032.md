### 2-1. 전거 v3 수집 (무료 위키 API · 결정론 · 로컬 캐시)

대상 = 생존 배정행에 실제로 나타나는 개체만 — **패널 키 493 · raw 이름 158**(정찰 실측).

| 호출 | 목적 | 규격 |
|---|---|---|
| **A1 `prop=redirects`** | 개체 X 의 **참 별칭**(넓힘) | ko(+en 위키 표제어인 개체는 en) · titles 50개씩 묶음 · `rdlimit=max` · 이름공간 0 |
| **A2 `prop=langlinks`** | ko↔en 표기(넓힘 — 1024 §9-5 로마자 미측정 처방) | titles 50개씩 · `lllang=ko\|en` · `llprop=url` |
| **A3 `list=allpages&apprefix=v`** | v 로 «시작하는» 표제어(막음 후보) | 변형 v 마다 1회 · `aplimit=500` · ns 0 · `apfilterredir=all` |
| **A4 `list=search&srsearch=intitle:"v"`** | v 를 «포함하는» 표제어(막음 후보) | 변형 v 마다 1회 · `srlimit=50` · ns 0 |

**막음 사전 BLOCK(k)** = A3∪A4 로 얻은 표제어 T 중 **(i) v ⊊ T**(v 가 T 의 진부분 문자열)
**(ii) T 가 k 의 표제어로 리다이렉트되지 «않는다»**(A1 의 리다이렉트 목록에 T 없음 ∧ T ≠ k 표제어)
**(iii) |T| − |v| ≥ 1**. 즉 **「이름을 품은 별개 표제어」**. 리다이렉트인 T 는 막음이 아니라
**별칭**으로 편입한다(같은 개체다).
**넓힘 사전 ALIAS(k)** = names1024 변형 ∪ A1 리다이렉트 ∪ A2 langlink 표기. 이름 관문은
1024 §1 항등(strip·NFC·L≥2·숫자만 제외) + 🔴 **BAN_COMMON(1024 러너 상수) 재적용**.

### 2-2. 정밀 규칙 (ⓑ · 사전 고정 · 인자는 §2-3 격자에서 개발셋으로 «선택»)

행 r 의 개체 출현 위치를 zone 에서 **재정위**한다(ALIAS(k) 의 각 변형을 NFC·casefold 부분열
탐색 · 날짜 스팬 s 에 가장 가까운 출현). 재정위 실패 = **차단**(계수 게재 · 「쟀는데 못 찾았다」
칸 — 조항 59).

| 규칙 | 겨냥 | 정의(러너와 일자일자 대응) |
|---|---|---|
| **B1 어절 경계** | 합성어 파묻힘 | 한글 포함 변형: 매칭 «직전» 문자가 한글 음절이면 차단(1024 검사 A 의 «플래그 → 차단» 승격). 라틴 전용 변형: 양끝 이웃이 `[A-Za-z0-9]` 이면 차단 · L≤4 는 원문 대소문자 정확 일치 요구(1024 §2-2 항등) |
| **B2 부분열 차단(막음 사전)** | **IP 확장판** | 매칭 위치 p 를 덮는 BLOCK(k) 표제어 출현이 zone 에 있으면 차단. 탐색창 = `zone[p−Lmax : p+len(v)+Lmax]`(Lmax = BLOCK(k) 최장 길이) |
