## ① 무엇을 했나

948 의 `census` 는 날 것 호출 자리마다 **실해**(같은 인자를 날 것과 정본으로 둘 다 돌려
낸 차)를 실었는데, 재현 대상 판정이

```python
if body[0] not in ("ls-files", "ls-tree", "status", "grep"):
    return {"🔴 못 돌렸다": ...}
```

였다. **argv 의 첫 낱말**만 본다. 그래서 하위명령이 `log`·`show`·`diff` 면 **무조건**
「못 돌렸다」였다. 티처 #88 의 처방: **읽힌 하위명령**으로 판정하고 `log`·`show` 를 넣어
전수를 채워라.

`_run_both(vec, wide=True)` 를 만들어(기본값은 좁은 쪽 그대로 — 판정 레인 산출물에
탐색 수치가 섞이지 않게) 오늘 트리의 날 것 자리를 전부 다시 돌렸다.

## ② 무엇이 나왔나 — 🔴 **넓혔더니 「새로 잰 것」이 하나도 없다**

| 갈래 | 948 의 좁은 자 | 949 의 넓은 자 |
|---|---|---|
| 쟀다 | 4 | **4** |
| 못 돌렸다 | 7 | **4** |
| 🔴 자가 못 잰다(`-z` 가 기록 구분자를 바꾼다) | 0 | **3** |
| 분모 0 | 0 | 0 |

**넓힌 자가 새로 닿은 자리는 셋인데, 셋 다 「쟀다」가 아니라 「못 잰다」다.**

🔴 **자기 적발**: `git log --name-only` 계열에서 `-z` 는 「이름 구분자」가 아니라
**「커밋 기록 구분자」**다. 그래서 정본 쪽이 출력 전체를 **한 덩어리(1)** 로 낸다.
그 자리의 「날것 − 정본 = 54,880」 같은 수는 **실해가 아니라 자의 결함**이다.
그대로 실었으면 **「탐색이 분모를 11 자리 전부 채웠다」로 읽혔을 것**이고,
그것은 947 이 「전수」를 세면서 자기를 못 본 그 병의 다른 판이다.

**날것 − 정본 > 0 이 실제로 확인된 자리 넷**: `out942_robots.py:293` ·
`out942_stock.py:385` · `out943b_d2time.py:164`(**218**) · `out945_colcensus.py:59`(1).
🔴 **218 은 티처 #88 M6 이 이미 잰 수다** — 재현이지 발견이 아니다.

## ④ 못 한 것 (「없다」가 아니다 · 조항 59)

1. **고치기 전 트리에서는 안 쟀다** — 오늘 트리 하나뿐이다.
2. 🔴 **`인자` 칸이 실제 argv 가 아니다**(티처 #88 M6). 자 A 는 **상수만** 본다 —
   `str(ROOT)`·변수로 조립된 인자는 **조용히 빠진다**. 그러므로 이 재현은
   **「자 A 가 본 argv」의 재현**이지 **「그 자리가 실제로 돌린 명령」의 재현이 아니다.**
   ⚠ 이것은 **수리 산출물의 하자**이므로 규칙 1 에 걸리지 않는다 —
   판정 노트 §9 의 M6 칸에도 적었다(티처 #88 m5).
3. **「못 돌렸다」 4 자리**(`out945_verify.py:71` · `out946_quotefix.py:258·317·365` —
   전부 `rc 128`)는 **여전히 「모른다」**다. **「무해」가 아니다.**
4. **`log` 계열의 실해를 재는 옳은 자**(기록을 `\x01` 로 끊고 이름만 비교)는 **안 만들었다.**
   그것이 이 팔의 다음 후보다.
