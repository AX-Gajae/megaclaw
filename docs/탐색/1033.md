- **추출**: 씨앗 **1033**. `sha256("1033|rid_L|rid_R")` 오름차순으로 정렬(정답과 독립인 결정적

  (회전 1 순서는 씨앗 동전이고 **정답과 독립**이므로 편향 없는 동전과 동치).
  **「3차 미실시」 수를 계수**하고 그 항목을 제외한 재계산을 민감도로 병기한다.
  🔴 1031 실측 기준 예상 필요량: ⓑⓒ 일치율 0.787 → 230×2×0.213 ≈ 98 · ⓐ 일치율 0.383 →
  40×0.617 ≈ 25 → **≈123 ≤ 130**. 그래도 모자랄 수 있으므로 위 대체 규칙을 «먼저» 고정한다.
- 더미(영 대조)는 양쪽이 글자 단위로 동일하므로 **3차 판독 대상이 아니다**(1회 판독만).

## §7. 판정 — 자 · MDE · 해석 문언 (7-나 4 · 부칙 6)

### 7-1. 자와 부호 서명 (v5.3 게이트 부호 서명 규격)

- **자 = 쌍 비교 정확도**(이산 · 소표본 자).
- 🔴 **부호 서명**: 정확도는 **높을수록 좋다**. 주대비 **Δ = acc(ⓒ) − acc(ⓑ)** 이고
  **Δ < 0 이면 「정독이 해롭다」 쪽**이다. 부호를 뒤집어 읽는 순간 이 사이클은 무효다.
- **주대비는 하나**: **ⓒ − ⓑ · 주표본 전량 · McNemar 정확검정 양측 α=0.05**(1031 산식 인용 —
  `b`=ⓒ만 맞음 · `c`=ⓑ만 맞음 · `n_d = b+c` · 이항 정확검정).
- **병기 의무**: **IP그룹 클러스터 붓스트랩**(B=2,000 · 씨앗 1033 · 재표집 단위 = IP그룹 ·
  **양쪽 그룹이 모두 뽑힌 쌍만** 센다 — 1030 §9-자 규칙 승계)으로 Δacc 의 클러스터 SE 를 낸다.

### 7-2. 🔴 MDE 를 «먼저» — 그리고 목표 0.06 은 이 예산에서 도달 불가다

- **산식**(1031 §7 인용): `Δacc_MDE = 2.80158·√n_d / n` (양측 α=0.05 · 검정력 0.80).
- **불일치쌍 비율 사전값** = 1031 A층 ⓒ/ⓑ 실측 `n_d/n = 13/47 = 0.2766`
  (출처 `runners/out1031_scored.json` sha256 `b90d1f33a449c662…` — 조항 66).
- **등록 n=230 에서의 예상 MDE** = `2.80158·√(0.2766×230)/230` ≈ **0.0971**.

  | n | 예상 n_d (0.2766) | 예상 MDE |
  |---:|---:|---:|
  | 47 (1031) | 13 | 0.2149 |
  | 150 | 41 | 0.1203 |
  | **230 (등록)** | **64** | **0.0971** |
  | 604 | 167 | 0.0600 |

- 🔴 **정직 신고 — 팔 지시의 목표 「MDE ≤ 0.06」은 이 자·이 예산에서 도달 불가다.**
  강제 이진 선택 + McNemar 로 0.06 을 치려면 **n ≈ 604쌍**이 필요하고, 그것은
  `604 × 2팔 × 2회전 = 2,416` 호출 + 3차 판독 — **상한 1,150 의 2배가 넘는다**. 목표를 몰래
  낮추는 대신 **못 미치는 것을 수로 먼저 적는다**: 이 사이클이 사는 해상도는 **≈0.10**이고,
  이것은 1031(0.2149) 대비 **2.2배 개선**이지 「작은 이득」의 검출력이 아니다.
- **겨냥 효과 = 0.10**(정확도 점). 출처: ⓐ 1030 §10-1 에서 «관측 조건»이 무조건 대비 걷은 몫이
  6.04%p 였고 정독은 그 위에 얹는 정보다 — 같은 자릿수 위쪽을 겨냥으로 잡는다 ⓑ 1031 실측
  Δ=+0.0213 은 겨냥이 아니라 **해상도 밖의 잡음**이었다(MDE 0.2149).
- 🔴 **부칙 6 과의 관계 — 사전 고정**: 본 사이클의 주대비는 **[해석] 레인 대비이지 [판정] 레인
  게이트가 아니다**(7-가). 그래서 ㉮(MDE 를 수로 «먼저»)는 지키고, ㉯의 **[판정] 금지**는
  적용 대상이 아니다. 러너는 `assert_mde` 를 **진단으로** 호출해 결과(통과/미달)를 게재하되
  **예외로 중단하지 않는다**(중단 대신 게재 — 이 사이클은 처음부터 판정 게이트에 서지 않는다).
  ㉱ 규격은 지킨다: **null 은 「효과 없음」이 아니라 「MDE(수) 미만」으로 적는다.**

### 7-4. 🔴 해석 문언 — 실측 전 확정 (골대 이동 금지)

세 갈래를 «먼저» 적는다. §8 은 이 중 하나를 **한 글자도 안 늘리고** 발효시킨다.

1. **ⓒ 가 유의 우세**(McNemar 양측 p < 0.05 ∧ Δ > 0) →
   > 「**정독이 조건 밖 내부 상태를 잡는다 — 비수치 경로 확증.** 관측 조건이 맞춰진 짝에서
   > 정독이 조건만보다 더 맞혔다.」
2. **무의미 ∧ 실측 MDE > 0.06** →
   > 「**이 자료·이 판독기·이 해상도에서는 못 가른다**(Δ 는 실측 MDE(수) 미만). 다른 자료·다른
   > 판독·더 큰 n 의 여지는 존속한다. **「세계가 막는다」로 번역하는 것을 금한다.**」
3. **무의미 ∧ 실측 MDE ≤ 0.06** →
   > 「**정독의 이득은 이 자료에서 MDE(수) 미만이다**(상한 실측). 「효과 없음」이 아니다.」

🔴 **인과 화법 금지**(7-나 5). 판독의 `reason` 은 **서사**다. 링크가 ⓐ시간 순서 기계 검사
ⓑ근거 문서 sha ⓒ**대조 검사** 셋을 다 통과해야 「인과 후보」다.

### 7-5. 인과 체인 v0 (7-다 · 선택 · 판독기 호출 0)

ⓒ 가 **이중 판독 일치로 맞힌** 짝 중 앞에서부터 **K=10** 건에 대해 7-다 규격 링크
(`{선행 사건, 후행 결과, 시간차, 근거 문서 sha, 기제 문장, 반증 조건}`)를 산출한다.
🔴 **대조 검사는 이 사이클에서 안 한다 — 다음 사이클 몫으로 명시한다.** 따라서
**확증 링크 비율 = 0 / K** 이고 링크는 전부 **「미검」·「서사」**다. 「인과 후보」는 0개다.
