## §1 왜 했나

1039 가 남긴 결론: *「세 시각 처리 전부에서 ⓑ 가 .51~.57 → 시각이 아니라 «표현»이 병목」*.
그리고 1036~1039 의 시도가 **전부 「문서 한 편 → 벡터 하나 → 평균풀」** 이었다.
사용자가 처음부터 지적한 형태다 — *「문서 하나를 임베딩하는 걸로는 내재 상태를 못 담는다」*.

그래서 **표현 축 하나만** 바꿨다:

```
s_disc(e,t,τ) = Σ_{d∋e, time(d)≤t} w(t−time(d))·v_d / Σ w      w(Δ)=2^(−Δ/τ)
τ 격자 {30,90,180,365} 사전 고정 · 정본 τ=90 «미리» 지정 (§L1-3 규약)
```

## §3 🔴 「가중이 안 먹혔나」를 확인했다 (조항 59 — 빈 것을 부정으로 읽지 마라)

τ 를 12배 바꿔도 AUC 가 안 움직여서, 가중 자체가 퇴화했는지 검사했다.

```
개체 안 문서 시각의 «폭»: 중앙 1,939일 (25% 412 · 75% 2,149)
개체 안 서로 다른 날짜: 중앙 10개
가중 «유효 문서수»: τ=30 → 9.3 · τ=90 → 15.0 · τ=365 → 28.1
```

**가중은 제대로 작동했다**(유효 문서수가 3배 차이 난다). 그런데도 AUC 가 안 움직인다 →
**문서 벡터를 9개로 합치든 28개로 합치든 이 표적에 대한 신호가 없다.**

## §4 누적 판정 — 텍스트 채널

1036~1040 이 시험한 설정:

```
임베더 5   메타96 · 본문512 · ft-v1 · ft-v2 · Qwen3-Embedding-4B
시각   3   크롤 · 재부착 · 발행일창

풀링   5   단일 · 집합 τ{30,90,180,365}
```

**텍스트 단독 AUC 가 전 조합에서 0.49~0.57.** 곡선 0.6307 을 한 번도 못 넘었다.

🔴 **범위를 좁혀 적는다**: 「텍스트가 무용하다」가 아니라
**「이 말뭉치(HPLT ko 매칭분)의 문서 표현은, 이 표적(위키 91일 3배 급등)에 대해,
곡선을 못 넘는다」**이다. 다른 표적(매출·방문자·사건 발생)이나 다른 말뭉치는 안 봤다.

**교란 후보로 남는 것**(1036 §5 실측):
개체명이 본문에 0회 **20.2%** · 1회 46.9% · 2회 이상 32.9% · 동음이의어는 언급 수로 못 거른다.
즉 문서의 **67%가 그 개체 얘기가 아닐 수 있다.** 이 오염을 걷어낸 판은 **아직 안 쟀다**.

## §5 그래서 파운데이션 층을 어디에 둘 것인가

곡선(ⓐ37 0.6307)이 **이 실험실에서 유일하게 서는 표현**이다. 그러므로 파운데이션 모델은
**텍스트 인코더가 아니라 «궤적 인코더»** 여야 한다 — 자료가 그렇게 말한다.

재료는 있다: **위키 일별 패널 991 개체 × 4,060일**(2015-07 ~ 2026-08). 지금까지 이 패널은
**행 10,654 의 (s,o) 창을 잘라내는 데만** 쓰였고, 패널 «전체»로 자기지도 학습을 한 적이 없다.

다음 사이클: 궤적 파운데이션 모델(마스킹/예보 목적 자기지도) → h_e(t) → 결정층(1038 하네스).
