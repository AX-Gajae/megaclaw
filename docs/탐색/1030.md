## §3. 조건 사다리 — 특징 목록 «고정» (결과 보고 고르면 무효 · 조항 79·999 전례)

누적 사다리 L1 ⊂ L2 ⊂ L3a ⊂ L3b ⊂ L4. **L0 = 무조건**(개체·유형도 안 쓴 잔차).

### 3-가. B층 특징 (전 특징이 t0 «이전»만 쓴다 — leak 스탬프 전수 §4-라)

| 층 | 블록 | 열 |
|---|---|---|
| L1 | 개체·유형 | 개체키 원핫(train 개체) + 미지개체 지시자 · 정규유형 원핫(9) |
| L2 | 관측 조건 | 도메인 원핫(8) · 사건 연도 원핫(2015~2026) |
| L3a | 🔴 내부 상태(원장·담론) | ① `comp30_type`=ln1p(#원장 사건 same 정규유형, t0′∈[t0−30,t0)) ② `comp30_all`=ln1p(#원장 전 사건, 같은 창) ③ `hist90`=ln1p(#same 개체키, [t0−90,t0)) ④ `hist365`=ln1p(#same 개체키, [t0−365,t0)) ⑤ `hist365_type`=ln1p(#same 개체키 ∧ same 유형, [t0−365,t0)) ⑥ `gap_prev`=ln1p(t0 − 직전 same 개체키 사건일) + 결측지시자 ⑦ `lead`=ln1p(t0 − 최초pub_time) ⑧ `sov90`(격자 마지막 as_of<t0 · τ=90) + 결측지시자 ⑨ `logW90`=ln1p(W_ent_90) (⑧과 같은 지시자) |
| L3b | 🔴 내부 상태(패널 사전) | ⑩ `base_mu`=기준선 log1p 평균 ⑪ `base_sd`=기준선 log1p SD ⑫ `base_slope`=기준선 log1p OLS 기울기×30 ⑬ `runup7`=mean(r_d, d∈[−7,−1]) ⑭ `pre30`=mean(r_d, d∈[−30,−8]) |
| L4 | 관찰(그 밖) | 신뢰층 원핫(E1/E2모호/E2미해소/E3) · ln1p(문서수) · ln1p(행수) · conf_max · 예고 원핫 |

🔴🔴 **기계적 결합 사전 신고(등록 시점)**: R = mean(log1p v over [0,14]) − `base_mu` 이므로
`base_mu` 는 R 안에 계수 −1 로 들어간다 — **L3b 의 몫 일부는 평균회귀의 «기계» 몫이다**.
그래서 **판정 게이트를 둘로 쪼갠다**: G1 = L3b(전 내부 상태) · **G2 = L3a(기계 결합 없는
부분집합)**. 해석은 §6 분기표가 두 결과의 «조합»으로 고정한다. ⑬⑭ 도 잔차 눈금이라 같은
결합을 일부 갖는다 — 그래서 L3a 에 안 넣는다.

### 3-다. 자 (설명 몫)

- **Var(잔차_Lk)** = 홀드아웃 «검정» 집합에서의 가중 잔차 분산(가중 = 개체 등가중).
- **설명 몫 A_k = 1 − Var(잔차_Lk) / Var(잔차_L1)** — 분모는 **L1**(사전등록 정의 그대로).
  L0 은 같은 식으로 계산해 게재하되 음수가 정상이다(L1 이 이미 더 걷었으므로).

  불확실성은 안 담긴다 — §6 한계로 신고).
- **|Δ| 중앙값 병기**: 각 층 잔차의 median|e| 와 그 클러스터 SE 도 나란히 게재(로버스트 눈).

## §4. 홀드아웃·추정기 — 사전 고정 (과적합 방어)

- **H-T (시간 전방 · 개체 공유) — 🔴 정본 판정 레인**: 컷 = 사건 t0 의 70분위
  (정찰 실측 = ordinal 738042 = **2021-09-09**). train = t0 < 컷(2,526) · test = t0 ≥ 컷
  (1,086 · **개체 55**). 「같은 개체가 시간이 지나 다시 사건을 낼 때, 그 사이 달라진 내부
  상태가 결과 차이를 설명하는가」 — 사용자 명제의 «같은 팝업처럼 보여도 앞단이 다르다»에
  1:1 대응하는 물음이다.
- **H-E (개체 분리 ∧ 시간 전방) — [관찰]**: 보류 개체 =
  `sha256("1030|"+개체키)` 앞 8자리 hex mod 10 ≥ 7. train = 비보류 ∧ t0<컷(1,801 · 38개체) ·
  test = 보류 ∧ t0≥컷(345 · **개체 18**). 나머지 1,466 행은 버린다(사전 고지). 🔴 개체 분리
  홀드아웃에서 **개체 고정효과는 원리상 전이 불가**하므로 이 레인의 L1 = **유형 원핫만**.
- **A층 — [관찰]**: LOGO(그룹 하나 빼기) 교차검증 — 각 IP 그룹을 한 번씩 test 로 두고 나머지
  31 그룹으로 적합. 「개체 분리」는 만족하나 「시간 전방」은 아니다(n=47 에서 둘 다 걸면 test
  ≈ 10쌍) — **사전 자백**.
- **추정기(사전 고정)**: 능형회귀(ridge · 정규방정식 · numpy) · train 평균/표준편차로 표준화
  (표준편차 0 인 열은 버리고 계수) · 목표는 train 가중평균 중심화 · 절편 없음 ·
  α ∈ {0.01, 0.1, 1, 10, 100, 1000} 을 **train 안에서만** 개체-그룹 5겹 CV(씨앗 1030)로 층마다
  하나씩 고른다. 🔴 고른 α 는 **위약에서 재사용**(위약마다 CV 재실행 금지 — 계산 대칭성보다
  «판정 전 고정»이 우선).
- **결측 처리(조항 59)**: 결측 = train 중앙값 대입 + **결측 지시자 열 동반**. 0 대입 금지 ·

### 5-다. 위약(MDE 의 원천) — 사전 고정

- **위약 = 특징 열 순열**: 층 k 의 설명 몫 A_k 에 대응하는 위약은 **L1 «이후»에 더해진 열

  train/test 분할은 그대로 두고 순열은 «전 표본»에서 한 번 한다. 순열 뒤 **같은 α·같은 절차**로
  재적합 → A_k^(b). **B_pl = 1,000 · 씨앗 = 1030 + b**(쌍둥이 = 2030 + b · 지터 전용).

- **0-중심 게이트(부호 서명 — 양쪽)**: 위약 설명 몫 분포의 **중앙값**이 0 에서 멀면
