## 7. 🔴 이 사이클이 반증한 전제 하나

**지시서의 전제**: *「크롤 금지가 원천 지평을 좁혀 왔다 → 풀면 새 원천이 열린다」*.

**실측**: 오늘 받은 셋 중 **크롤 금지에 걸렸던 것은 0개다.**

| 원천 | 옛 규약(*"공식 API · 공식 다운로드 폼 · 파일 배포뿐"*)에 걸렸나 | **실제로 막고 있던 것** |
|---|---|---|
| 위키 일별 조회수 | ❌ **안 걸렸다** — 위키미디어 **공식 REST API** | 🔴 `ingest/wiki_views.py` 가 스스로 적은 규약 — *"창은 시작일 이전 90일이다. **시작일 당일과 이후는 한 칸도 안 본다**"*. 누출을 막으려던 규약이 **③「언제 터질지」의 재료를 원천에서 지웠다** |
| Steam 리뷰 본문 | ❌ **안 걸렸다** — Steamworks 문서에 있는 **공식 스토어 엔드포인트** | 🔴 ① `docs/수집계획.md` 후보 16개에 **댓글·여론이 0건** ② 노트 896 의 「크롤은 중복」 — 그런데 896 이 잰 것은 **용량 대용값**이고 **본문은 안 재 봤다** |
| robots 지도 | ❌ **안 걸렸다** | 🔴 **아무도 안 셌다** |

🔴 **그러므로 20사이클째 원천이 안 는 이유는 「금지 조항」이 아니라 「자」였다.**
판 ρ 가 0점을 매기는 것은 후보 목록에 아예 안 올랐다 — `docs/방향.md` §1(가)가 진단한 그대로다.
**금지를 푼 것은 필요했지만 충분하지 않았고, 실제로 문을 연 것은 자를 바꾼 쪽이다.**
