## §1. 자 (채점 규격)

- **평가 개체**: val 70 개체의 «최초 관측» 행. 곡선(S)은 **숨긴다** — 텍스트·도메인만 사용
  (콜드스타트 가장). 동률 «언제»는 앞 행(파일 순서)으로 결정적.
- **표적**: Y = 최초 관측일 포함 앞 90일 누적 조회수 = `sum(O[0:90])` (원 눈금).
- **방법 M (참조군 가중)**: 같은 도메인 train 개체 최초 행 임베딩과 코사인 → top-K(K=12) →
  w = max(cos, 0)(전부 0 이면 균등) → **가중 분위수**(역CDF 계단 · 결정적) q10/q25/q50/q75/q90.
  점예측 = q50.
- **기준선 B1 (기후값)**: 같은 도메인 train 전 개체 Y 의 무가중 중앙값(점) · q10~q90(구간).
- **기준선 B2 (참조군 무가중 평균)**: 같은 top-12 의 산술 평균(점만 · 관찰).
- **채점**: 개체별 APE = |점예측 − Y| / max(Y, 1) → **MdAPE**(중앙값) · **80% 구간 실측
  덮개율**(q10~q90 이 Y 를 덮는 비율 · 표적 0.80) · 불확실성은 **개체(=군집: 최초 행이
  개체당 1행이므로 개체 붓스트랩이 곧 군집 붓스트랩) 짝지은 붓스트랩** B=10,000 ·
  seed [1007, 0].

## §2. 주대비 — «하나» (조항 79)

**G1**: Δ = MdAPE_M − MdAPE_B1 (풀드 70 · 짝지은 개체 붓스트랩 SE).
**채택(참조군 정본) ⇔ Δ < −2×SE_Δ.**
- 도메인별 Δ_d 는 **조각 표(관찰)** 로만 게재(점추정·SE·t·동부호 수 — 조항 79 형식). 웹툰
  조각은 이름으로 관찰. K ∈ {8, 20} · B2 · 덮개율도 관찰 — 판정에 안 들어온다(조항 68 —
  탐색 격자와 판정 격자 분리).

## §3. 게이트 부호 서명 (v5.3)

1. **악화 방향 한 줄**: G1 은 Δ 가 **+ 쪽**일 때 떨어져야 한다 — 물리량 문장: 「Δ > 0 은
   참조군 점예측의 절대 상대 오차 중앙값이 기후값보다 큰 것, 즉 예측이 실측 90일 누적에서
   **더 멀어진** 것이다 — 그 쪽이 악화다」. 반대쪽 극단(참조군 압승)은 관찰 칸에 그대로 적는다.
2. **방향 탐침 — 측정 «전»**: 러너가 자료 적재 «전에» 합성 문턱 t=1 로 게이트 함수를 검사 —
   악화 극값(+2t)에서 **거짓** · 개선 극값(−2t)에서 **참**. 어긋나면 **측정 없이 중단**하고
   사유를 out 에 적는다.
3. **자료 탐침 — 측정 «후»**: 실측 문턱(2·SE)으로 ㉰(악화 극값에서 참인 게이트 수) ·
   ㉱(개선 극값에서 거짓인 게이트 수) 계수 — 둘 다 0 이어야 하고 수로 게재. SE ≤ 0 이면
   「미판정(퇴화 문턱)」.
4. **여유 게재**: 여유 = 문턱(−2×SE) − Δ · **여유 > 0 ⇔ 통과** · 비반올림 유효 6자리로 적는다.
