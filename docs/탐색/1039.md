### 2-다. 🔴 하한 게이트 — 회수율 % 를 «폐기»하고 행·클러스터 한 줄로

1037 §5-2 가 스스로 신고한 자 결함을 이행한다: **대리 문턱(회수율 %)을 없애고
하류가 실제로 요구하는 것(재부착 가능 «행»·클러스터)만 남긴다.**

**검정력 계산** — 앵커는 §1-아 가 이 사이클에 실측한 정본 자의 값이다.

```
앵커:  Δ대결 SE = 0.0262  at  K = 485 위키문서 클러스터  →  MDE(2SE) = 0.0524
척도:  SE ∝ 1/√K         →  MDE(K) = 0.0524 · √(485/K)
```

이 물음이 성립하려면 자가 무엇을 볼 수 있어야 하는가:
현 Δ대결 = **−0.1097**. 「텍스트가 곡선을 이긴다」가 되려면 Δ 가 0 위로 와야 하고,
그 **이동폭이 0.1097** 이다. 자가 그 이동폭조차 못 재면 물음이 원리상 성립하지 않는다.
이동이 완전하지 않아도(**80%**만 와도) 보이게 잡는다 → 목표 **MDE ≤ 0.0875**.

```
K ≥ 485 × (0.0524 / 0.0875)²  =  485 × 0.3586  =  174 위키문서
```

- **G-B1** (ㄱ) 팔의 위키문서 클러스터 **K ≥ 174**
- **G-B2** (ㄱ) 팔의 행 **≥ 3,000** — 1037 이 등록·통과시킨 하한을 그대로 승계(자 불변)

**「사전등록 게이트에서 멈췄다 — 안 쟀다」**이고, 모든 팔은 **[관찰]** 로만 적는다.
「효과 없다」로 번역 금지.

### 2-라. 성공 조건 (연언 · (ㄱ) 팔)

1. **주판정**: Δ대결 = AUC(ⓑ) − AUC(ⓐ) 의 위키문서 클러스터 붓스트랩 **CI95 하한 > 0**
2. **보조**: Δ대결(ㄱ) − Δ대결(ㄴ) ≥ (ㄱ)의 실측 MDE
