## §2. 장(場) 정의 — L1-1·2·3·4 사상 (사전 고정)

- **망각 가중(L1-3)**: w(Δ) = 2^(−Δ/τ) · Δ = (as_of − published_at).days ≥ 1(자격:
  published_at < as_of — leak_guard 가 매 호출 강제). 🔴 τ 격자 **{30, 90, 180, 365} 사전
  고정 · 정본 τ = 90 사전 지정**. 뒤집힘 지점(τ 에 따라 결론 순서가 바뀌는 곳) 게재 의무.
- **s_disc(e, t, τ)** = Σ w·emb / Σ w — 임베딩 있는 개체 문서만(n_emb 병기). 문서 0 이면
  값 «없음»(0 벡터 저장 금지 — 특징 단계에서 0 벡터 + `has_disc=0` 지시자 동반 · 조항 59 형).
- **s_bg(t, τ)**: 배경 풀 동일 산식.
- **SoV(e, t, τ)** = W_ent / (W_ent + W_bg) · W = Σw(전 매칭 문서 — 크롤 스케줄을 비율이
  나눠 준다 · L1-2). 분모 0 이면 null + 지시자.
- **API(산출물 계약 — L3 백도어·해저드가 임포트)**: `pretrain/discourse_field.py` 의
  `DiscourseField.load(store)` → `.s_disc(entity, as_of, tau)` · `.sov(entity, as_of, tau)` ·
  `.s_bg(as_of, tau)` — **매 호출 leak_guard 내장**(선택 문서 전수를 `assert_no_leak` 에
  통과시킨 뒤에만 평균 — 스탬프 반환).

## §4. 🔴 MDE «먼저» (부칙 6 — 실제 ⓑⓒ «전»에 레인을 정한다)

순서(러너가 이 순서를 강제한다 — 실제 ⓑⓒ 는 ⑦ 통과/미달 기록 «후»에만 계산):

2. V 사다리 실측(§3) → y = log1p(u_daily_visitors) · **SD_cl(y)** = 이름 클러스터 평균들의
   SD(ddof=1).
3. **ⓐ 팔 주행**(곡선만 — 담론 무접촉이라 게이트 정보 누출 없음 · 사전 명기).
4. **위약 = MDE(1018 §4 전례의 예측판)**: 이름 클러스터의 «담론 문서 묶음»을 클러스터 간
   순열 σ 로 재배정(레코드는 자기 T0 로 σ(이름) 묶음에서 특징 계산) — 시드 7019 로 P=20 ·
   시드 8019 로 P=20 → 각 순열에서 ⓑ(τ=90) 주행 → **Δ_perm = MAE_ⓐ − MAE_ⓑσ** 40개.
5. SD_perm = SD(Δ_perm 합동 40 · ddof=1) · **J = |SD_시드7019 − SD_시드8019| / √2**(1018 미러).
6. **MDE_사전 = 2 × max(SD_perm, J)** (`mde_of`).
7. **겨냥 효과 = 0.15 × SD_cl(y)** — 출처: 사전 추정치. 근거 ⓐ 자 C(정책 가치)가 팔리려면
   예측 오차 개선이 결과 산포의 한 자릿수 % 로는 결정 순위를 못 움직인다는 설계 요구
   ⓑ 1018 전례(겨냥/SD_위약 = 0.83)보다 보수적으로 낮게 잡는다(담론은 곡선 «위에» 얹는
   증분 채널이라 큰 효과를 사전 주장할 근거가 없다).
   → `assert_mde(MDE_사전, 겨냥, 위약 파일 sha256/16)` — **MdeUnderpowered 면 검증 게이트
   전체 [측정] 강등 등록**(사전 명기 · ㉱ 화법) · 통과면 [판정] 레인. 어느 쪽이든 ⓑⓒ 실측은
   그대로 돌린다(강등 시 수는 관찰로만 게재).
