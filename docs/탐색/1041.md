## §3 하류 판정 — 판정 대비 둘을 «미리» 지정했다

### §3-가 P2 — 🔴 오염은 텍스트 실패의 원인이 «아니었다»

전체 판에서 텍스트를 곡선에 더하면 **유의하게 나빠진다**(−0.0343 · CI95 0 배제).
오염을 걷어내면 해로움은 사라지지만(CI 0 포함) **도움이 되지도 않는다**.
1040 §6 이 「남은 유일한 텍스트 반증 경로」로 지목한 것이었고, **닫혔다**.

### §3-나 P1 — 파운데이션은 «안 섰다». 다만 부호가 일관되다

네 레인 전부 **양수**이고 오염을 걷을수록 **커진다**(+0.0089 → +0.0100 → +0.0239 → +0.0351).
그러나 CI95 가 전부 0 을 포함한다. K=249 에서 MDE(2SE) ≈ 0.037 인데 효과가 +0.0239 다.
🔴 **「증분이 없다」가 아니라 「이 분모로는 못 봤다」**(조항 59).

### §3-다 [관찰] 자기지도 표현이 손으로 짠 특징보다 «견고»하다

오염을 걷을수록 곡선 기준선이 무너진다(0.6307 → 0.5979 → 0.5714 → 0.5484). 반면 h64 는
거의 안 흔들린다(0.6043 → 0.5915 → 0.5945 → 0.5745). 그래서 **깨끗한 부분표본에서는
h64 단독이 곡선 특징보다 높다**(≥2회 .5945 대 .5714 · ≥3회 .5745 대 .5484).

🔴 [관찰] 등급이다 — 이 대비는 사전등록에 없었고, 부분표본이 달라 **AUC 를 레인 간에 잇지 않는다**
(기저율은 .257~.273 로 비슷하나 분모가 다르다 · 조항 60).

## §4 안 주장하는 것

- **인과 아님.**
- **P1 은 안 섰다.** 「파운데이션이 증분을 준다」고 적으면 안 된다. 부호 일관성은 [관찰]이다.
- **h64 우위(§3-다)는 사전등록 밖**이며 레인 간 AUC 비교가 아니다.
- 궤적 인코더의 val L1 19.1% 개선은 **자기지도 목적**에서의 값이지 하류 성능이 아니다.
- 표적은 여전히 «위키 91일 3배 급등» 하나다. 방문자·매출에는 안 꽂아 봤다.

## §5 남은 것

1. 🔴 **P1 의 분모** — K=249 에서 MDE 0.037. 효과가 +0.024 라면 **K≈600 이 필요**하다.
   패널에는 창 보유 개체가 2,912 있다. `(s,o)` 창을 **패널 전체로 확장**하면 K 를 키울 수 있다.
   그게 P1 을 세울 유일한 경로다.
2. **h 를 하네스(1038)에 꽂기** — 방문자 표적에서도 같은 것을 묻는다. 다만 1038 은 n=104 라
   더 좁다.
3. **텍스트 채널은 닫는다** — 1036~1041 이 열여섯 설정 + 오염 제거까지 시험했고 전부 못 넘었다.
   재개하려면 **다른 표적**이거나 **다른 말뭉치**여야 한다.
