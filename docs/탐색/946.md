## 1. 무엇을 했나

티처 #85 의 구조 진단이 물음이다:

> ① 이 저장소가 세계를 재는 방식은 거의 전부 **「문자열 키 집합의 차집합」**이다
> ② **키 공간은 항상 남이 만들고** 거의 모든 외부 키 공간은 **인코딩이 둘 이상**이다
> ③ 🔴 차집합 개수는 **자기 실패와 구별되지 않는 유일한 출력 타입**이다

그래서 **게이트 생산자 40** 각각을 AST 로 훑어 세 축을 셌다.
명부는 손으로 안 적었다 — `runners/out945_fiveprime.json:2 게이트/게이트 생산자` 에서 **읽었다**
(945 가 `git grep -lF -e '"통과":'` 로 뽑은 목록).

| 축 | 무엇을 찾나 |
|---|---|
| **가 · 외부 키 원천** | git argv · 파일시스템 훑기(`glob`/`rglob`/`iterdir`/`listdir`/`walk`/`scandir`) · `json.load(s)` · `np.load`/`.files` · `os.environ`/`sys.argv` |
| **나 · 집합 셈** | `in`/`not in` · `-` `&` `\|` `^` · `.difference(`/`.issubset(`/`.intersection(`/… |
| **다 · 두 번째 인코딩 방어** | `-z` · `quotePath` · `octal_unescape` · `fsdecode/fsencode` · `unicodedata`/`NFC`/`NFD` · `casefold`/`lower` · `strip`/`replace` · `deep=` · 별칭표 |

### 🔴 이 자의 비대칭 — 먼저 적는다

**「방어 없음」은 셀 수 있고 「방어 있음」은 상한이다.** 정적 표지가 *그 키 경로에* 걸려
있는지는 이 자로 원리상 못 본다. 그러므로 아래 ⑤ 는 **하한**이고,
**「⑤ 밖은 안전하다」는 문장을 이 자로 쓸 수 없다**(조항 59).

## 3. 못 한 것

- **동적 경로를 안 봤다** — 키가 함수 인자로 건너오면 이 자는 못 따라간다.
- 🔴 **「방어가 그 키에 걸렸나」를 안 쟀다.** 정적 표지의 **존재**만 봤다.
- **게이트 생산자 40 밖은 안 봤다** — 저장소 `.py` 는 그보다 훨씬 많다.
- 🔴 **심은 키를 각 생산자에 실제로 주입해 보지 않았다.** 그건 판정 레인의 일이고
  이 팔은 지도만 그린다. **주입 없이는 「본다/못 본다」를 말할 수 없다**(조항 59).
- **인코딩이 둘 이상인지를 원천별로 실측하지 않았다** — git 만 실측했다(215).
  npz·JSON 깊이·도메인 필드명은 **가설**이다.
