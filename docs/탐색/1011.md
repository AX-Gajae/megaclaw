## §1. 자 — 쌍둥이 정의(등록 대상)와 채점 규격

**작품 동일성(쌍둥이) 정의 — 정의 «자체»가 등록 대상(#142 ⑥-1 ㉮)**. val 개체 v 와 같은
도메인 train 개체 t 에 대해:

> **쌍둥이(v, t) ⇔ ㉮ 곡선 동일성** — v·t 의 «최초 관측» 행 181일 연결 곡선(S 90칸 + O
> 91칸 · 원 눈금)이 **전 칸 비트 일치**(`np.array_equal`) — 같은 작품이면 같은 위키 곡선
> (#142 ⑥-1 이 지정한 근거 · 검증 가능·결정적)
> **∨ ㉯ 임베딩 cos(v, t) ≥ τ = 0.9999** — «후보» 자(텍스트 재식별 신호 · #142 명기:
> cos 임계는 정의가 아니라 후보 — 그래서 ㉮ 와의 합집합으로만 쓴다)

- 적용: **풀 쪽 제거**(val 70 유지 · B1 무변 — #142 재구성 레시피·twin1007_supp 미러).
  진짜 신작은 정의상 풀에 쌍둥이가 없으므로, 쌍둥이-제외 풀이 배포 모집단(«진짜 신작»)의
  대리다 — 눈금(MdAPE·덮개율·SE)은 이 모집단 위에서 정의된다(과업 지시).
- 민감도는 관찰만: 성분 절제(㉮만·㉯만) · τ ∈ {0.999, 0.9995} · K ∈ {8, 20} — 점만 게재 ·
  **격자 모양 주장 금지**(조항 68 · #142 ⑥-1 ㉱).
- 채점(1007 §1 자구 미러): 평가 = val 70 최초 관측 행(곡선 숨김 — 필터만 곡선을 본다:
  누수가 아니라 누수 «적발»이 목적인 위생 연산이고, 예측 M′ 은 여전히 텍스트·도메인만 쓴다) ·
  표적 Y = 관측 정렬 90일 누적 `sum(O[0:90])` (원 눈금) · M′ = 쌍둥이-제외 풀 코사인
  top-K(K=12) `w=max(cos,0)` 가중 분위수(역CDF 계단 · q50 점 · q10~q90 구간) · B1 =
  도메인 기후값(무가중 · **무변**) · APE = |점−Y|/max(Y,1) → MdAPE · 80% 덮개율 관찰.

## §2. 주대비 — «하나» (조항 79)

**G1′**: Δ′ = MdAPE_M′ − MdAPE_B1 (풀드 70 · 짝지은 개체(=군집: 개체당 최초 행 1행)
붓스트랩 **B=10,000 · seed [1011, 0]** — 🔴 새 seed 스트림 · 1007 의 [1007,0]·[1007,1]
재사용 금지).
**복권(참조군 정본) ⇔ Δ′ < −2×SE′.** 문턱 = −2×SE′ (사전 명기 — 1007 G1 규격 미러) ·
SE′ ≤ 0 이면 「미판정(퇴화 문턱)」.
- **순열 p (보조 눈금 — 판정 밖 · 관찰)**: 개체 안 (APE_M′, APE_B1) 라벨 부호 뒤집기
  **B=10,000 · seed [1011, 1]** · 통계량 = 중앙값 차 · **단측(개선 방향 Δ′≤관측)** ·
  p = (1 + #{T_b ≤ Δ′}) / (B+1). 판정은 SE 문턱 «하나»다 — p 는 같은 주대비의 두 번째
  눈금으로 게재만 한다.
- 도메인별 Δ′_d 조각 표(점·SE(B=2,000 · seed [1011,2])·t·동부호 수)는 관찰(조항 79 형식 ·
  n<30 전부).

## §3. 게이트 부호 서명 (v5.3)

1. **악화 방향 한 줄**: G1′ 은 Δ′ 가 **+ 쪽**일 때 떨어져야 한다 — 물리량 문장: 「Δ′ > 0 은
   쌍둥이-제외 참조군 점예측의 절대 상대 오차 중앙값이 기후값보다 큰 것, 즉 예측이 실측
   90일 누적에서 **더 멀어진** 것이다 — 그 쪽이 악화다」. 반대 극단(참조군 압승)은 관찰 칸.
2. **방향 탐침 — 측정 «전»**: 자료 적재 전에 합성 문턱 t=1 로 게이트 함수 검사 — 악화
   극값(+2t) **거짓** · 개선 극값(−2t) **참**. 어긋나면 측정 없이 중단 + 사유 out 게재.
3. **자료 탐침 — 측정 «후»**: 실측 문턱(2·SE′)으로 ㉰(악화 극값에서 참)·㉱(개선 극값에서
   거짓) 계수 — 둘 다 0 이어야 하고 수로 게재. SE′ ≤ 0 → 「미판정(퇴화 문턱)」.
4. **여유 게재**: 여유 = 문턱(−2×SE′) − Δ′ · **여유 > 0 ⇔ 통과** · 비반올림 유효 6자리
   (부호 규약은 1007 §3 미러 — 게재 자리마다 «>0 ⇔ 통과»를 명기해 반올림·부호 오독 봉쇄).
