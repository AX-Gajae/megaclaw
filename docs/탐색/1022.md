## §1. 훈련쌍 생성 (사전 고정)

- **격자**: 쌍 = (개체 e, 절단 t). t = **매월 1일**(개체 곡선 범위 안 전부). 자격 =
  [t−90, t+90] **181일 완비**(패널 날짜 집합에 전 일 존재 — 결측 채움 없음 · 「완비 칸만」).
- **입력 곡선**: S = log1p(조회수[t−90, t−1]) (90) · base = mean(S) · Sc = S − base.
- **표적**: R = log1p(조회수[t, t+90]) − base (91) — 현행 잔차 눈금 미러.
- **조건**: dom 원핫 11(패널 파일명 사전순 — 게임·도서·만화·모바일·세계애니·시장팝업·아이돌·
  애니·웹툰·팝업·펀딩) · sin/cos(2π·doy(t)/365) · (year(t)−2013)/10 · base — 전부
  `transition.py` SAO 미러.
- **문서(개체별 · 결정론)**: sao973 셀(meta.jsonl 행)의 문서id(텍스트 안 32-hex — 사전 검증
  10,654/10,654) ← 발행일 = v1(쌍id 첫 행 사상) ∪ v2(문서id) · **pub > crawl 이면 오탐 제외**
  (1015 §7 미러 · 계수 게재) · 개체 안 문서id 중복 접힘(계수 게재) · published_at 오름차순 정렬.
  쌍 (e,t) 의 문서 집합 = **published_at < t**(엄격 — 같은 날 = 누수 · L0-3)인 접두사.
  무문서 쌍은 has_disc=0 지시자로 선다(분모 조건 아님 — 1019 §3 미러 · 조항 59).
- **분할(개체 분리 + 시간 전방 — 이중)**: 개체 val = `md5(개체)[:8]%10 == 0` ∨
  `data/lab/val_ext_roster.json` 명부(`triples.py` 미러 — 챔피언과 같은 규칙 · 현재 명부 실측 0).
  **T_split = 2025-01-01**. train = 개체 train ∧ t < T_split · val = 개체 val ∧ t ≥ T_split ·
  나머지 두 사분면 **폐기**(계수 게재 · 어느 팔도 안 본다).
- **분모 사다리(게재 의무)**: 패널 개체 → 격자 쌍 전체 → train/val/폐기 → 문서 있는 쌍
  (pre-t ≥1 · 덮개율) → leak 스탬프 집계. **목표 ≥100,000 쌍**(사전 추정: 격자 ~243k ·
  train ~174k · val ~5.0k) — 못 미치면 실측대로 게재하고 진행.
- **훈련쌍/에폭 상한(예산)**: 쌍 상한 없음(격자가 유한) · 학습은 **고정 3,000 스텝 × 배치 256**
  (팔·씨앗마다 — 에폭 환산 ~4.4, 상한 5 에폭 이내) — 조기 종료·검증 엿보기 없음(결정론 스케줄).

## §2. 팔 셋 (사전 고정 · 짝지은 씨앗 K=4 = {0,1,2,3})

공통 몸통(현행 축소판 — `Transition` 미러 · hidden 512→**128** · 2 은닉층):
`[Sc(90) · cond(15) · 팔별 추가] → Linear(128)·GELU → Linear(128)·GELU → Linear(91×5)` ·
분위수 꼬임 방지 softplus 간격(q50 중심 — 현행 그대로) · 손실 = `pinball` 산식 항등(91×5 ·
잔차 눈금) · Adam lr 1e-3 · 배치 표집 `default_rng([씨앗, step])`(챔피언 미러 — 씨앗 같으면
팔 간 배치 색인 동일 = 짝지음) · torch 초기화 시드 = 씨앗 · threads 4 · CPU.

- **ⓐ 곡선만(대조)**: 추가 0 차원.
- **ⓑ 곡선 + 고정 s_disc(1019 규격)**: 추가 12 = [has_disc · log1p n_pre · log1p W(τ90) ·
  log1p Δt_last(무문서→0)] + **PCA8**(s_disc(e,t,τ90) = Σ 2^(−Δ/90)·emb / Σw · Δ=(t−pub).days≥1 ·
  무문서→0 벡터). PCA 는 **train 쌍의 유문서 s_disc 에서만 적합**(중심화+상위 8 성분 ·
  np.linalg.svd 결정론). 추가 특징 z 표준화는 train 통계.
- **ⓒ 곡선 + 학습 인코더(시험)**: 추가 34 = [has_disc · log1p n_pre] + **상태 벡터 32** —
  문서 시퀀스(최근 **N=16** 개 · pub 오름차순 · 토큰 = 선형사영32(emb896) ⊕ [log1p(Δt)/10 ·
  2^(−Δt/90)]) → **GRU(hidden 32 · 1층)** 마지막 은닉 상태. 무문서→0 벡터. 인코더는 몸통과
  끝-끝 합동 학습(같은 핀볼 손실).
- **파라미터 상한**: 팔당 **≤300,000**(실측 게재 — 사전 계산 ⓐ~89k · ⓑ~90k · ⓒ~129k).
- ⓑ↔ⓒ 의 유일 차이 = 문서 취합 함수(고정 감쇠 평균 ↔ 학습 시퀀스 인코더) — C4 짝 규격.
  (ⓑ 의 PCA8 도 «학습»이지만 비지도 선형 사영이다 — 「표적을 보고 배운 취합」은 ⓒ 뿐.)

## §3. 자·채점 (사전 고정)

- **pp(쌍)** = 그 쌍 (91×5) 핀볼 전 셀 평균(잔차 눈금 · `transition.pinball` 항등 —
  자기시험 ㉠) · 씨앗 4 평균 → pp̄_팔(쌍). 팔 평균 = val 쌍 평균.
- **주대비(하나)**: **Δ_주 = pp̄_ⓑ − pp̄_ⓒ** (+ = ⓒ 개선 · 낮을수록 좋은 자의 차).
- **SE^cl**: 개체(키) 클러스터 붓스트랩 **B=10,000 · 시드 1022** — d(쌍)=pp̄_ⓑ−pp̄_ⓒ 의
  클러스터 재추출 평균 SD. **J_실측** = SD(Δ_씨앗 4개 · ddof=1)/√4.
- **덮개율**: cov(팔) = val (쌍×91일) 중 실측 R 이 [q05,q95] 안인 비율(쌍 평균 → 전체 평균 ·
  씨앗 평균) · Δ_cov = cov_ⓒ − cov_ⓑ · SE^cl_cov·J_cov 동형.
- **관찰**: Δ_ca = pp̄_ⓐ − pp̄_ⓒ ± SE^cl(동형 붓스트랩) · Δ_ba = pp̄_ⓐ − pp̄_ⓑ 병기 ·
  도메인별 3팔 pp 표(SE^cl 병기 — 조항 68: 2SE 못 넘는 칸으로 모양 주장 안 한다) ·
  유문서 쌍 부분집합의 Δ_주(관찰 — 사후 부분군 판정 금지) · q50 MAE 3팔.
- **앵커(눈금 확인 · 관찰)**: ⓐ val q50-MAE(잔차 log)를 배포 `transition/report.json`
  (등록 sha `6dfb0a4ff2935de0` · 부칙 4 `assert_epoch` 로 여는-시점 실측 대조)의 0.2076 과
  견줘 비율 [0.4, 2.5] 기대 — 밖이면 «눈금 결함 조사» 신고(판정 아님 · 게재 의무).
  (분포가 다르다: 배포 val 은 크롤 앵커 셀 · 본 팔은 월 격자 — 「급 재현」 = 자릿수 확인.)

5. **MDE_사전 = `mde_of`(SE_사전, J_사전)** = 2×max( max_{6쌍} SE^cl_위약, SD(Δ_위약 6 · ddof=1) ).

## §5. 게이트 (사전 고정 · [판정] 레인일 때)

- **㉠ 주대비(판정 게이트 — 하나)**: 통과 = **Δ_주 > MDE_실측 = 2×max(SE^cl, J_실측)**.
  **부호 서명(악화 방향 한 줄)**: 「Δ_주 가 − 쪽(학습 인코더 ⓒ 가 고정 감쇠 ⓑ 보다 미래 곡선
  분위수 예측 핀볼을 «늘림») 이거나 MDE 이하이면, 학습된 문서-시퀀스 압축은 고정 감쇠 평균 위의
  증분 상태 정보로서 **검출 실패**다 — 내재 상태 엔진 v0 은 s_disc 를 못 이긴 것이고 L4 몸통
  후보에서 물러난다」. 반대쪽 극단(ⓒ 대개선)은 §3 관찰 칸이 담는다. 여유 = Δ_주 − MDE_실측
  비반올림 게재.
- **㉢ 덮개율 비악화(보조 게이트 — 「성공」의 필요조건일 뿐 단독 성공 불가)**: 통과 =
  **Δ_cov ≥ −MDE_cov_실측**(= 2×max(SE^cl_cov, J_cov)). 부호 서명: 「Δ_cov 가 − 쪽으로 MDE_cov
