## §2. announced_at 추출 사슬 — 사전 고정

**정의**: announced_at = 개입(팝업)이 공개 발표된 시각의 «상한 증거»(그 날짜 이전에 발표가 존재했음을 보이는 가장 이른 공개 출처 시각). 🔴 개최일 대체 «금지»(명세 L0-2 · 조항 59 형) — 실패 = null = «못 읽었다».

**후보 생성 (시장층)** — 훑는 필드는 아래 «전부», 우선순위 아님(후보 풀 합집합):
- **사슬 ① 출처 게재일 필드**: `outcome.visitors_source_date` · `outcome.sales_source_date` · 최상위 `outcome_source_date` · `outcome.alt_figures[].source_date` · `additional_sources[].date` (모두 `YYYY-MM-DD` 파싱).
- **사슬 ② 기사 URL 날짜**: `outcome.visitors_source_url` · `outcome.sales_source_url` · 최상위 `outcome_source_url` · `outcome.alt_figures[].source_url` · `additional_sources[].url`. 정규식: (a) 경로의 `20\d{2}[/\-.]\d{1,2}[/\-.]\d{1,2}` (b) 숫자 연속열 길이 8·12·14 의 앞 8자리를 `YYYYMMDD` 로 시도(CMS 기사 ID 관행) — 달 01–12 · 일 01–31 검증, 연도 2015–2027 밖 기각. 길이 10(유닉스 초) 등 다른 길이는 안 쓴다.
- **사슬 ③ 본문 날짜형**: `visitors_source_quote` · `sales_source_quote` · `counting_basis_note` · `notes` 의 `20\d{2}[.년/\-]\s?\d{1,2}[.월/\-]\s?\d{1,2}일?` (연도 포함 완전 날짜만 — «지난 3일» 류 상대 표현 불채택).

**채택 관문 (전 후보 공통)**: 개최일(opened_at, D1d 의 일 단위 from)이 있어야 판정 가능. 후보 c 는 **c < opened_at**(엄격 — 개최 당일·이후 게재는 발표 증거가 아니라 보도) ∧ **opened_at − 730일 ≤ c**(개연 창 — 2년 초과 선행은 오파싱 취급·기각 계수 게재). announced_at = 유효 후보의 **min**. 채택 시 출처(사슬 번호·필드명)를 원장에 기록.

**내부층**: 공개 발표 출처 필드가 스키마에 없다(docs 는 Drive URI — 게재일 아님 · 파일명 날짜 스탬프는 «문서 시각»이지 «발표 시각»이 아니다 — 크롤일 대체 금지와 같은 유형). → **내부층 announced_at 은 전건 null(`no_public_source`)로 사전 고정**. 본문 텍스트 날짜형(사슬 ③ 상당)이 관문을 통과하는 건수는 «후보 계수»로만 병기(채택하지 않는다 — 내부 문서 서술이지 공개 발표가 아님).
