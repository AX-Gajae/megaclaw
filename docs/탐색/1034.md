## §6. 판정 — 자 · MDE «먼저» · 부호 서명 · 해석 문언 (7-나 4 · 부칙 6)

### 6-1. 자와 부호 서명

- 🔴 **부호 서명**: 정확도는 **높을수록 좋다**. 주대비 **Δ_D = acc(ⓓ) − acc(ⓑ)** 이고
  **Δ_D < 0 이면 「위약 «발췌 형식» 자체가 해롭다」 쪽**이다.
  🔴 **「위약 발췌가 ⓒ 만큼 해로우면 (B) — 형식/파이프가 범인이다.」**
  부호를 뒤집어 읽는 순간 이 사이클은 무효다.
- **주대비는 하나**: **ⓓ − ⓑ · 층 ㉮ 96쌍 전량 · McNemar 정확검정 양측 α=0.05**(1033 산식 인용 —
  `b`=ⓓ만 맞음 · `c`=ⓑ만 맞음 · `n_d = b+c` · 이항 정확검정).
- **병기 의무**: **IP그룹 클러스터 붓스트랩**(B=2,000 · 씨앗 **1033** · 재표집 단위 = IP그룹 ·

  **SE 와 백분위 95% CI** 를 낸다. 부차 대비 **ⓒ−ⓑ**(인용·재계산)와 **ⓒ−ⓓ**(차의 차 = 「내용 몫」)도
  같은 방식으로 낸다.

### 6-2. 🔴 MDE 를 «먼저» (수로)

- **산식**(1031→1033 인용): `Δacc_MDE = 2.80158·√n_d / n` (양측 α=0.05 · 검정력 0.80).
- **불일치쌍 비율 사전값** = **1033 층 ㉮ ⓒ/ⓑ 실측 `n_d/n = 24/96 = 0.2500`**
  (출처 `runners/out1033_scored.json` sha256 `44ad42cc4991e20d…` — 조항 66).
- **등록 n=96 에서의 예상 MDE** = `2.80158·√(0.25×96)/96` = **0.1430**
  — 1033 층 ㉮ 의 **실측 MDE 0.1430 과 같은 수**다(같은 n·같은 n_d).

  | n | 예상 n_d (0.25) | 예상 MDE |
  |---:|---:|---:|
  | **96 (등록 · 1033 층 ㉮ 전량)** | **24** | **0.1430** |
  | 216 (1033 주표본) | 54 | 0.0953 |
  | 604 | 151 | 0.0570 |

- 🔴 **정직 신고 — 해상도는 1033 층 ㉮ 와 «같다», 더 좋아지지 않는다.** n 은 96 으로 못 박혀 있고
  (표본을 «그대로 인용»하는 것이 이 설계의 핵심이므로 늘릴 수 없다), 0.1430 보다 **작은** 차는
  원리상 못 가른다(조항 78 — 「원리상 못 떨어지는 입력」 신고). 그래도 이 설계가 사는 것은
  **크기**가 아니라 **대조**다: ⓒ 가 낸 −0.1458 은 MDE 위에 있고, ⓓ 가 그 근처면 (B) · 0 근처면 (A) 다.
- **부칙 6 과의 관계**: 본 사이클의 주대비는 **[해석] 레인 대비이지 [판정] 레인 게이트가 아니다**
  (7-가). ㉮(MDE 를 수로 «먼저»)는 지키고 ㉯의 [판정] 금지는 적용 대상이 아니다. `assert_mde` 는
  **진단으로** 호출해 통과/미달을 게재하되 **중단하지 않는다**. ㉱ 규격은 지킨다:
  **null 은 「효과 없음」이 아니라 「MDE(수) 미만」으로 적는다.**

### 6-3. 🔴 해석 문언 — 실측 «전» 확정 · 기계 판정 (골대 이동 금지)

기호: `Δ_D = acc(ⓓ)−acc(ⓑ)` · `Δ_C = acc(ⓒ)−acc(ⓑ)` · `CI = ⓒ−ⓓ 의 클러스터 붓스트랩 95% CI`.
셋은 **상호 배타**이고 러너가 기계로 고른다. §8 은 이 중 하나를 **한 글자도 안 늘리고** 발효시킨다.

1. **(B)** ⟺ `0 ∈ CI` **∧** `Δ_D < 0` **∧** `|Δ_D| ≥ 실측 MDE(ⓓ−ⓑ)` →
   > 🔴 「**형식/파이프가 범인 — 담론 «내용»의 유해성은 미확인 · 발췌 규칙 수리가 다음이다.**
   > 관련 없는 개체의 발췌를 같은 개수·같은 길이·같은 형식으로 줘도 정확도가 같은 크기로
   > 내려갔고, ⓒ 와 ⓓ 의 차는 0 과 구별되지 않는다. 1033 층 ㉮ 의 −0.1458 을 「담론이
   > 오도한다」로 읽는 것을 금한다.」
2. **(A)** ⟺ `|Δ_D| < 실측 MDE(ⓓ−ⓑ)` **∧** `0 ∉ CI` →
   > 🔴 「**이 자료의 담론 «내용»이 이 과업에서 오도한다**(귀속 파손 교란 병기 — 1028 낙인).
   > 위약 발췌는 해롭지 않은데 진짜 발췌만 해로웠고, ⓒ 와 ⓓ 의 차는 0 을 제외한다.
   > 🔴 그래도 «세계»에 대한 판정이 아니다 — 이 자료·이 판독기·이 발췌 규칙의 부호다.」
3. **그 밖 전부** →
   > 🔴 「**미판정** — (A)도 (B)도 사전 고정 조건을 채우지 못했다. 부칙 6 ㉱ 화법:
   > null 은 「효과 없음」이 아니라 「실측 MDE 미만」이다.」

🔴 **인과 화법 금지**(7-나 5) — 이 사이클도 판독의 `reason` 을 인과로 읽지 않는다.

### 6-4. [관찰] 칸 (다중비교 보정 없음 · 판정 게이트 아님 — 조항 79)

## §7. 과업 2 — 인과 체인 «대조 검사» 첫 집행 (7-다 · 지금까지 0/47·0/10 미실측)

### 7-1. 무엇을 재는가

제7장 7-다 는 「체인의 성적 = **확증 링크 비율**(반증 조건을 **실제로 실측해** 통과한 링크 수 /
전체)」이라고 적고 있는데, **1031·1033 둘 다 대조 검사를 안 돌려 0/47·0/10 이었다.**
이 사이클이 **최초로 실물을 낸다.**

- **대상**: 1033 이 낸 링크 **K=10** (`runners/out1033_chain.json` sha256 `df2e119900202874…` — 인용).
- **각 링크의 반증 조건**(1033 등록 문면 그대로):
  > 「같은 장소유형·같은 무료입장·기간비≤1.5·연도차≤1 인 유사 개체 K개 중 **t0 이전 담론이
  > «없던» 쪽이 이긴 비율**이 **0.5 와 다르지 않으면** 이 링크는 반증된다」

### 7-2. 대조군 구성 — 1030 §10-3 동결 틀 (조항 67)

- **동결 함수 `variance1030c.matched_cross_ip`**(sha256 `b428e3afe7be6ea1…`)를 **임포트해 돌리고**,
  행 인덱스가 필요해 같은 술어를 다시 돌린 뒤 **n_쌍 735 · 관여 IP그룹 135** 항등을 요구한다.
  어긋나면 **측정 없이 중단**.
- **링크 L 의 대조군** = 링크가 지목한 **이긴 쪽 개체 W** 와 정합하면서(다른 IP · 같은 장소유형 ·
  같은 무료입장 · 기간비 ≤1.5 · 연도차 ≤1) **t0 이전 담론이 «0건»** 인 상대 **전부**.
  그 수를 **K′** 이라 한다(동률 d=0 짝은 제외 — 1033 승계).
- **결과 판정**: 각 대조쌍에서 「무담론 쪽이 이겼는가」(y 비교) → 비율을 **0.5 에 대해 이항 정확검정
  양측 α=0.05**.

### 7-3. 🔴 링크 판정 — 사전 고정 (다섯 갈래 · 상호 배타)

| 판정 | 조건 | 뜻 |
|---|---|---|
| **확증(통과)** | `K′ ≥ 6` ∧ `p < 0.05` ∧ `비율 < 0.5` | 무담론 쪽이 유의하게 «덜» 이겼다 — 링크가 살아남았다 |
| **반증** | `K′ ≥ 6` ∧ `p ≥ 0.05` | 등록 문면 그대로 — 0.5 와 다르지 않다 |
| **역방향반증** | `K′ ≥ 6` ∧ `p < 0.05` ∧ `비율 > 0.5` | 무담론 쪽이 «더» 이겼다 — 링크 방향과 반대 |
| **미검(검정력 0)** | `0 < K′ < 6` | 🔴 **이항 양측 α=0.05 가 «원리상» 유의를 못 내는 n 이다**(조항 78) |
| **형식 미달(분모 0)** | `K′ = 0` | 반증 조건이 이 링크에 대해 **실측 불가능**하다(조항 59) |

- **확증 링크 비율 = 확증 / 10** (분모 병기) · **미검은 별도 계수** · **형식 미달은 체인 규격의
  자기 검사**로 따로 적는다.
- 🔴 **검정력 정직 신고 «먼저»**: `|p−0.5| = 0.25` 를 검정력 0.80 으로 잡으려면 **K′ ≈ 29** 가
  필요하다(정규 근사). K′ 이 그보다 작은 링크의 「반증」은 **「반증됐다」가 아니라
  「이 검정이 못 가른다」**에 가깝다 — 링크마다 `검정력_충분(K′ ≥ 29)` 칸을 **의무 게재**한다.
- **[관찰] 두 칸 병기**: ⓐ 링크 합산(개체 공유로 독립 아님) ⓑ 🔴 **모집단 판** — 727 유효 짝 중
  «정확히 한쪽만» t0 이전 담론이 있는 **비대칭 짝 전량**에서 같은 비율을 낸다. 링크별 K′ 이 작은
  것을 보완하는 큰-n 대조다.
- 🔴 **등급 [관찰] · 판정 승격 금지(사전 명기)** — K=10 은 소표본이고, 링크 선택은 1033 이 「ⓒ 가
  이중 판독 일치로 맞힌 앞 10건」으로 뽑은 것이라 **결과 조건부**다(사전 무작위 표집이 아니다).
