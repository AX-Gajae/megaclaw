### 4-가. 법과 그 조건

```
SE_clu(d, n) = sqrt( (τ² + σ²/n̄) / d )      t = μ̂·√d / √(τ² + σ²/n̄)
```

도메인을 «하나» 더 넣어 |t| 가 오르려면 |μ̂'|/|μ̂| ≥ (τ̂'/τ̂)/√(d'/d) 여야 한다. 새 도메인의 유보 행이 적으면 그 칸의 표본 잡음 σ̂/√n 이 τ̂ 에 «통째로» 얹혀 τ̂'/τ̂ 가 √(d'/d) 보다 빨리 큰다.

| | 수 | 어디서 |
|---|---:|---|
| `τ̂` (§B2 적합의 절편) | **0.236911** | `out995_power.json` §B2 적합 |
| `σ̂` (§B2 적합의 기울기) | **1.58286** | 같은 적합 |
| §B2 적합 `R²` | 0.939691 | 같은 적합 |
| 🔴🔴🔴 **문턱 `n* = σ̂²/τ̂²`** | 🔴 **44.639 행** | 위 두 수에서 |

🔴 **뜻**: 새로 넣는 도메인의 유보 행이 `n*` 보다 적으면 그 도메인은 «신호»가 아니라 «잡음»을 가져온다 — `d` 가 `√` 로 버는 것보다 `τ̂` 가 더 큰다.
