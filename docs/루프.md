## 🔴 v3 가 고치는 것 — 이 루프는 검증은 세계 최고이고 탐색은 0 이다

**직전 23사이클의 방향이 어디서 왔는지 세어 봤다:**

| 출처 | 건수 |
|---|---|
| 티처 처방 | 8 |
| 직전 노트의 '미결/남은 것' | 10 |

즉 **루프는 남이 준 물음을 훌륭하게 판정하는 기계**였다. 자율주행이 아니다 —
티처와 사용자를 떼면 **멈추거나, 자기 꼬리(미결 목록)를 문다.**

**증거 하나**: `ingest/link_audit.py:4` 는 「격자 생활인구」를 원한다고 **코드 주석에 적어 두고**

**v3 가 넣는 것은 단계 ⓪ 하나와 팬아웃 자리 하나다.** 그 둘이 「자율주행 셋」을 담는다:
**자를 뗄 것인가 · 원천 지평 · 탐색 팔**. 그리고 ⑧ 에 물음 하나를 더한다 —
**"이게 옳은 물음이었나."**

## ⓪ 🔴 방향 설계 — 자율주행 셋 ← v3 신설

**①(cycle_open) 보다 먼저 한다.** 열린 이슈를 보기 전에 봐야 **이슈 목록에 갇히지 않는다.**
셋을 **각각 한 문장으로 적고 원장에 남긴다**. *"해당 없음"* 도 적는다 — 안 적으면 안 물은 것과
구분이 안 된다(조항 59).

### ⓪-가 · 자를 뗄 것인가

> **지금의 자(판 ρ · 문턱 0.00353 · 12도메인 유보 3,775)가 이번 물음을 잴 수 있는가?**

사용자 규약: *"지표가 방법을 가두면 지표를 뗀다."*

- **판이 못 재는 물음**은 판으로 재지 마라. 897 이 실제로 그 벽에 부딪혔다 —
  잡음의 단위가 **씨앗이 아니라 날짜 군집 540** 이라 판 유보에선 대부분의 아키텍처 디테일이
  **원리상 판정 불능**이다(`docs/아키텍처.md` §3 n-power 표).
- 🔴 **자를 뗄 때는 「무엇으로 대신 재는지」를 같이 적는다.** 안 적으면 자를 뗀 게 아니라
  **판정을 포기한 것**이다.
- ⚠ 자를 떼는 것은 **문턱을 낮추는 것이 아니다.** 문턱 0.00353 은 팔 차이에서 나오므로
  판 수준값이 바뀌어도 안 움직인다 — **떼는 대상은 자 전체이지 문턱 하나가 아니다.**

### ⓪-나 · 원천 지평 — 🔴 **가진 것 말고 없는 것을 본다**

> **이번 물음에 필요한 원천 중, 저장소에 아직 없는 것은 무엇이고 세상에 있는가?**

루프가 20사이클 넘게 **`data/ingest/` 에 이미 있는 것만** 갈았다. 그래서 문장이 늘 같은
자리에서 끝났다 — *"자료가 얇다"*.

- **코드가 원하는데 없는 원천을 먼저 센다**: `grep -rn "격자\|생활인구\|없다\|원천 없음" ingest/ lab/ state/`
- **그 원천이 세상에 있는지 확인한다** — 공개 포털 · 다운로드 · API.
  🔴 **광역 크롤은 금지다. 다운로드는 크롤이 아니다.** 파일로 받는 경로를 우선한다
- 🔴 **유료 API 금지**는 그대로. 무료 경로만
- 없으면 **"확인했고 없다"** 고 적는다 — 그게 조항 59 가 요구하는 형태다.
  *"안 찾아봤다"* 와 *"찾았는데 없다"* 는 다른 문장이다

**지금 열린 후보**: KOSTAT 빅데이터 포털(격자 생활인구 계열) — 정보전이장 `g(x,t)` 의
시군구 261 해상도를 **격자로 내리는** 유일한 알려진 경로.

### ⓪-다 · 탐색 팔 — 🔴 **판정이 아니라 지도를 그리는 자리**

> **이번 사이클에 「틀려도 되는」 팔을 하나 둔다.**

- 사전등록 · 문턱 · 판정 **없다.** 산출물은 **판정문이 아니라 지도**다
  (뭐가 있나 · 크기가 어느 정도인가 · 잴 만한가)
- 🔴 **탐색 팔의 결과는 그 사이클의 결론에 절대 안 들어간다.** 다음 사이클의 **후보**가 될 뿐이다.
  들어가면 그게 바로 **사후 부분집합**이다(티처 #60 M2 가 걸린 병)
- 후보 세 갈래를 돌아가며 쓴다:
  1. **문헌 통로** — `docs/아키텍처.md` §10 이 지적한 대로 **900노트가 전부 자급자족**이었다.
     남이 이미 푼 것을 다시 풀지 마라
  2. **아키텍처 사다리 한 칸**(`docs/아키텍처.md` L0~L8) — 단, **n-power 표를 먼저 보고**
     `효과 / (씨앗SD/√K) < 2` 면 **안 잰다**
  3. **원천 한 개 실물 확인** — ⓪-나 에서 찾은 것을 실제로 받아 **행수·열·결측만** 센다

## ② 팬아웃 편성 — 🔴 이 단계가 v1 에 없었다

옛 지시서: *"겹쳐 돌리면 같은 파일을 두 에이전트가 만진다"* → 그래서 **한 번에 하나만**
돌렸고 사이클의 대부분이 대기였다.

**정정: 그 문장은 파일이 겹칠 때만 참이다. 겹치지 않으면 겹쳐 돌려야 한다.**

### 표준 편성

| 자리 | 무엇 | 파일 집합 |
|---|---|---|
| **본 사이클** ×1 | 다음 노트 하나를 끝까지 (사전등록→배선검사→측정→판정→논문→PR) | 새로 만드는 `runners/*<번호>*` · `runners/out<번호>_*` · 새 논문 스텝 · 원장 **추가만** |
| **수리** ×N | 티처의 치명/중대 하나씩 | 각자 **다른 서브트리** — `ingest/` · `paper/` · 특정 `runners/` 파일 |
| 🔴 **탐색** ×1 | ⓪-다 의 팔. **판정 없음** | `docs/탐색/<사이클>.md` 하나 · 저장소 코드 **읽기만** |
| **주 세션** | 이슈·카드·커밋 취합·머지 | 카드(저장소 밖) · git |

🔴 **탐색 팔은 파일 하나만 쓴다.** 그래서 다른 팔과 **절대** 안 겹치고, 겹칠 걱정 없이
매 사이클 상시로 띄울 수 있다. 그게 이 자리를 상설로 만드는 이유다 —
**탐색은 여유 있을 때 하는 게 아니라 자리가 정해져 있어서 하는 것이다.**

### 🔴 팬아웃 규칙 — 안 지키면 정말로 충돌한다

1. **각 에이전트에게 허용/금지 파일 목록을 명시적으로 준다.** *"알아서 조심해라"* 는 안 통한다.
2. **`git add -A` 금지.** 남의 미완성 편집을 쓸어 담는다.
3. **`git commit` 은 본 사이클 에이전트 하나만.** 수리 담당들은 **파일만 고치고 끝낸다** —
   커밋은 주 세션이 모아서 한다. 한 워킹트리에서 둘이 커밋하면 서로를 삼킨다.
4. **`git checkout` · `git stash` · `git reset` 은 전원 금지.** 남의 작업을 날린다.
5. 읽기만 하는 산출물도 **"지금 남이 고치고 있다"** 고 알려 주고, **읽은 값을 자기 산출물에
   복사**시킨다(중간에 바뀔 수 있다).
6. 파일이 **정말** 겹치면 `isolation: "worktree"`. 비싸니 정말 겹칠 때만.

### 프롬프트에 반드시 넣을 것

- **"인계 카드부터 읽어라"** — 대화 요약을 길게 넘기지 않는다. 누적 맥락이 오염원이다
- 허용/금지 파일 목록
- **자 정본**(판 ρ · 문턱) · **규약 47** · **노트 133** · **조항 59·60**
- 제약: BQ/GCP 읽기 전용 · `/Users/ax/.openclaw` 읽기만 · 🔴 **유료 API 금지** ·
  긴 측정은 **파이프 금지**(`| head` 가 SIGPIPE 로 죽이는데 종료코드 0 — 파일로 받아라)
- **반환값 형식** — 무엇을 담아 돌아올지 미리 못 박는다

## ⑤ 취합

수리 담당들이 끝나면 주 세션이 **각자의 파일만 명시적으로** `git add` 해서 커밋한다.
커밋 메시지는 **인용 heredoc → `-F`**:

```bash
cat > /tmp/cm.txt <<'EOF'
제목

본문 — 백틱을 써도 안전하다
EOF
git commit -F /tmp/cm.txt
```

🔴 `<<'EOF'` 의 **따옴표가 핵심**이다. 없으면 백틱이 명령치환되어 **본문이 사라진다**.

## ⑤′ 🔴 취합 검사 ← v3.1 신설 (티처 #62 C3 처방 · **실해를 낸 뒤에 넣는다**)

> **팔 수가 문제가 아니라 「닫는 순서」가 문제였다.**
> 노트 899 에서 취합 커밋이 세 파일의 **키 이름을 바꾸고 소비자 둘을 안 고쳤다.**
> 그리고 **아무도 다시 안 돌렸다** — 그 결과 🔴 **「되살렸다」고 보고한 러너가
> 죽은 채로 PR 에 올라갔다**(`wire898.py:191` · `out899a_gates.py:256` 둘 다 `KeyError`).
> `.899a` 재현본은 그 커밋 **이전** 코드로 만든 것이라 성공했고,
> **커밋된 코드는 한 번도 안 돌았다.**

**⑤ 취합 뒤, ⑥⑦ 로 가기 전에 반드시:**

1. 🔴 **취합이 만진 파일의 「소비자」를 한 번 더 돌려라.**
   내가 고친 파일이 아니라 **그 파일을 읽는 파일**이다. 키 이름 하나만 바꿔도 끊긴다
2. **게이트 전량 재실행** — `dead_numbers()` · `paper_dead()` ·
   그 사이클이 세운 집행자(있다면)
3. 🔴 **산출물의 `git HEAD` 스탬프가 오늘 HEAD 인지 확인**하라.
   899 의 `out899a_gates.json` 은 **HEAD−2 시점**인 채로 커밋됐고 **오늘 돌리면 통과 false** 다
4. **종료 코드 0 을 성공으로 읽지 마라**(조항 59). 산출물을 열어 값을 봐라

⚠ **이 자리가 없으면 팬아웃이 클수록 손해가 커진다** — 여섯 팔이 각자 옳게 고쳐도
취합이 그 사이를 끊으면 아무도 안 본다.

```bash

gh pr merge <N> --merge --body-file /tmp/mg.txt     # 🔴 --squash 금지
```

**왜 `--squash` 가 금지인가** — 둘이다:
1. 저장소의 **절반이 부정 결과이고 그게 자산**이다. 뭉개면 그 절반이 사라진다

   *"모집단 좁힘이 사후냐"* 를 **분 단위로** 판정한 근거가 커밋 타임스탬프였다
   (사전등록 17:05:03 대 측정 17:06~17:20). 스쿼시하면 그 증거가 없어진다

🔴 **`gh pr merge` 의 종료 코드 0 을 성공으로 읽지 마라**(조항 59). `is-ancestor` 로 확인한다.

⚠ **에이전트가 돌고 있으면 로컬 브랜치를 옮기지 마라.** 원격에서만 머지한다 —
