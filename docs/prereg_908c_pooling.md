### 2.1 원장이 적어 둔 병

  티처 #53 C2 의 정정본을 전제로 쓴다(890 의 철회문이 아니라).

### 2.2 🔴 오늘 코드를 읽어서 새로 찾은 것 — **고정 가중은 채점 쪽이 아니라 학습 쪽에 있다**

`lab/forms.py:916` 챔피언 `F18_bagboost` 는 **이미 도메인 학습 가중을 갖고 있다**:

```
TRAINW = {"웹툰":711,"애니":606,"펀딩":529,"모바일":441,"세계애니":300,
          "만화":258,"게임":180,"도서":163,"시장팝업":126,"팝업":65,"아이돌":51}
TRAINW_CLIP = (0.2, 1.0)          # 🔴 줄이는 쪽으로만 자른다
```

**손으로 적은 11칸 표다. `영화`가 없다.** `:651` 이 `self.TRAINW.get(d, 0)` 을 쓰므로
없는 도메인은 `se=0` → `w=0` → **clip 하한 0.2**. 오늘 실측한 실효 학습 가중:

```
게임 1.0 · 도서 1.0 · 만화 0.2533 · 모바일 1.0 · 세계애니 0.6282 · 시장팝업 1.0
아이돌 1.0 · 애니 1.0 · 🔴 영화 0.2 · 웹툰 1.0 · 팝업 1.0 · 펀딩 1.0
```

**영화는 판 가중 3위(0.10755 · 채점 406행)인데 학습 행 481개가 5배로 깎여 있다.**
그 이유는 측정이 아니라 **표에 이름이 없어서**다. 노트 514 가 이 표를 채택할 때 판은
**11도메인**이었고(원장: *"0.0045 는 3,369행(11도메인) 값인데 분모는 3,775"*),
영화는 12번째로 들어왔다. **표가 은퇴한 줄 아무도 몰랐다.**

부수 실측(조항 60 — 분모가 다르다): 표의 `웹툰 711` 은 **유보 전행**이고 오늘 판이
쓰는 채점 가중은 **650**(라벨 있는 유보행)이다. 나머지 열 칸은 채점 가중과 일치한다.
**한 표 안에 두 분모가 섞여 있다.**

👉 그래서 이 팔의 자리는 정확히 여기다. **손으로 적은 고정 도메인 가중**을 §1 의
방법들로 **배우게 하고**, 우리 자로 잰다.

### 2.3 🔴 자를 바꾸지 않는다

판의 채점 가중(행 수 비례)은 **안 만진다**. 노트 890 사전등록이 거시판을 기각한
이유가 *"더 둔한 자를 아이돌이 보이니까 들이는 것은 자를 결과에 맞춰 고르는 죄"*
였다. **이 팔은 모형을 바꾸고 자는 그대로 둔다.** 자를 바꿔 이기는 팔은 여기 없다.

### 2.4 저장소에 이미 있는 것 — 새 것처럼 팔지 않는다

`lab/forms.py:1191 PerDomShrink`(`F10_pershrink`)가 **이미 부분 풀링**이다(도메인마다
자기/남의 배합비 `w_d` 를 학습 기간 안쪽 분할로 정한다). A4 는 그것과 **다른 층**이다:

이 차이를 산출물에 적고, F10 자체는 이 사이클에서 재지 않는다(팔 예산 밖).

## 3. 팔 — 여섯 + 위약

전부 챔피언 `F18_bagboost`(깊이 12 · lr 0.10 · 자루 32 · SPEC_K=1 · TRAINR=8.0)에서
**한 곳만** 바꾼다. 구현은 `lab/mixture908.py` 의 `Mixture(CLS)` 한 클래스 · `POOL_MODE`
하나로 가른다.

|---|---|---|---|
| **A0 챔피언** | — | 아무것도 안 바꾼다(`POOL_MODE="off"`). **비트 동일 배선 검사의 기준** | — |
| **A1 표 갱신**(대조군) | 학습 가중 | `TRAINW` 를 **오늘 유보 행 수 12칸**으로 다시 읽는다. clip 그대로 (0.2,1.0) | 없음 — **문헌이 아니라 대조군**이다(§3.1) |
| **A2 불확실도 가중** | 학습 가중 | w_d ∝ 1/σ̂_d² · σ̂_d = **학습 내부 검증** 잔차 SD | ㄱ Kendall+18 |

### 3.1 🔴 A1 이 왜 필수인가 — 이 팔의 제일 큰 교락

§2.2 를 고치면 영화 학습 가중이 0.2→1.0 이 된다. **A2~A5 는 전부 그것을 부수적으로
같이 고친다.** A1 없이 A2 가 이기면 *"불확실도 가중이 이겼다"* 가 아니라
*"영화를 5배로 되살린 게 이겼다"* 일 수 있다. **A1 은 그 교락을 혼자 분리하는 팔이다.**
판정할 때 A2~A5 는 **A0 대비**와 **A1 대비**를 둘 다 적는다.

### 3.2 누출 방어 — 구조로 막는다

- A2~A5 의 모든 학습(σ̂ · q · κ · λ)은 `Formulation.fit(train)` **안**에서만 돈다.
  `fit` 이 받는 `Data` 는 하네스가 `yr < T` 로 이미 자른 것이다(`lab/harness.py:305`).
  **유보 행은 그 객체 안에 존재하지 않는다** → 누출이 원리상 불가능하다.
- 그래도 **코드로 단언한다**: `fit` 진입 시 `max(train.yr[d]) < 2025.0` (전 도메인).
- 내부 검증 분할: 학습 안에서 다시 시간으로 가른다 —
  **안쪽 학습 `yr < 2024.0` · 안쪽 검증 `2024.0 ≤ yr < 2025.0`**. 검증행 20 미만인
  도메인은 **가중을 안 배운다**(중립 1.0 / λ=0). 이 규칙을 미리 못박는다.
- 🔴 **A1 만 예외다**: 유보의 **행 수**를 센다(라벨 y 는 안 본다). 챔피언 `TRAINW` 가
  하던 그대로다(노트 514: *"유보 행 수만 쓰고 라벨은 안 본다 — 채점 목적함수의
  정의다"*). **이것조차 누출로 보는 독자를 위해** A1 은 판정에서 뺄 수 있게 따로 적고,
  A2~A5 는 **유보를 한 비트도 안 본다**고 산출물에 명시한다.
