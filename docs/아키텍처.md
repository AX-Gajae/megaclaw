# 아키텍처 설계 규율 — **디테일이 곧 아키텍처다**

> **2026-08-10 사용자 지시.** 저장소에 박는다 — 절차가 붙여넣는 지시서에만 있으면
> 개정이 반영 안 된다(`docs/루프.md` 머리말과 같은 이유).
>
> *"작은 디테일이 중요해. 포지셔널 임베딩도 RoPE 로 할 수도 있고, 트랜스포머도
> residual connection 이란 기법을 썼고, 멀티헤드 어텐션으로 쪼개기도 하고, layer norm
> 이란 기법도 있고 — 이런 조금의 발상의 전환을 **latent space 내에서 계속 디테일을
> 챙겨 나가며** 창의적인 생각을 발화시킬 수 있는 아키텍처를 **루프 내에서 구현**할 수
> 있어야 하는 거야. 단순히 큰 틀도 중요하지만 정말 작은 디테일과 **어떻게 레이어와
> 정규화, 활성함수를 구성할지, FFN 으로 할지, 시간 복잡도는 괜찮은지, KV cache 는 쓸 수
> 있는지** 정말 많은 고민이 필요한 거야."*

---

## 0. 왜 이 문서가 따로 필요한가

이 실험실의 규율(사전등록 → 배선 검사 → 측정 → 판정 · 널 실측 · 채택 문턱)은
**「축 하나를 1열로 주입하고 판 ρ 를 본다」** 는 실험 모양에 맞춰 자랐다.
노트 745·754·884·892·896 이 전부 그 모양이다.

**아키텍처 실험은 모양이 다르다.**

| | 1열 주입 | 아키텍처 |
|---|---|---|
| 팔의 수 | 진짜 1 + 널 3 | **디테일마다 하나** — 쉽게 20팔이 넘는다 |
| 자유도 | 열 하나 | 층 수 · 폭 · 헤드 수 · 정규화 위치 · 활성 · PE · 드롭아웃 · lr · 스텝 |
| 잡음 | 씨앗 + 행 짝 | **씨앗 + 초기화 + 데이터 순서 + 조기 종료 지점** |
| 위험 | 사후 선택 | 🔴 **사후 선택 × 20** — 「제일 좋은 팔」이 거의 항상 잡음이다 |

🔴 **그래서 아키텍처는 규율을 느슨하게 할 자리가 아니라 더 조여야 할 자리다.**
노트 735 가 그것을 이미 보여줬다 — **걸음 60 에서 씨앗 넷의 유보 R² 가
+0.0791 · −0.5041 · −0.0613 · +0.0661** 이었고 **씨앗 SD 0.2735 가 노트 703 이 보고한
효과(⚠ **0.134 는 죽은 값** — 60걸음·씨앗 0 이고 노트 735 가 **+0.1200**(검증으로 걸음을
고른 뒤의 진짜 유보 R² · 씨앗 4 평균)으로 정정했다)의 **두 배**였다.
노트 703 이 본 것은 **넷 중 가장 좋은 씨앗**이었다.

🔴 **이 문단이 그 자체로 사례다.** 주 세션이 이 문서를 쓰면서 `0.134` 를 표지 없이 인용했고
`dead_numbers()` 가 **통과 false** 를 냈다(2026-08-10 · 이슈 #112 담당이 발견). **아키텍처를
논하는 문서가 첫 문단에서 죽은 숫자를 인용했다** — 규율은 남에게만 거는 것이 아니다.

## 1. 사다리 — 큰 틀부터 재고 디테일로 내려간다

**한 번에 하나씩 바꾼다.** 아래 순서를 지킨다. 위 칸이 안 서면 아래 칸은 못 잰다.

```
L0  기준선          지속성 베끼기 · 선형 · 현행 프로크루스테스 --- 이걸 못 이기면 끝
L1  합류 방식        늦은 합류 / concat / 게이팅 / 어텐션      ← 큰 틀
L2  깊이·폭          층 수 · d_model · 파라미터 예산
L3  주의(attention)  헤드 수 · head_dim · 인과 마스크 유무
L4  정규화           LN / RMSNorm · pre-LN / post-LN / sandwich
L5  잔차             residual 유무 · 스케일 · DeepNorm/ReZero
L6  위치             없음 / 학습형 / 사인 / RoPE / ALiBi
L7  FFN              유무 · 확장비 · 활성(GELU/SwiGLU/ReLU²) · gated 여부
L8  학습             lr 일정 · warmup · 드롭아웃 · weight decay · 조기 종료
```

🔴 **L1 이 널을 못 넘으면 L2~L8 은 안 잰다.** *"디테일을 더 챙기면 될 것"* 은
**측정이 아니라 희망**이다. 그리고 이 실험실에는 그 희망으로 두 사이클을 태운 기록이 있다
(노트 745~749 — 재현하지 않은 이상값을 두 사이클 동안 설명하려 했다).

## 2. 🔴 n 이 디테일을 허락하는지 먼저 세라 (조항 60)

**이게 제일 자주 틀리는 자리다.** 디테일마다 필요한 표본이 다르다.

| 자리 | 실측 n | 무엇을 잴 수 있나 |
|---|---|---|
| **장 학습 과제** | **관측 143,892** · 유보 창 552 (노트 735) | **여기서만 L3~L8 을 잰다.** 유일하게 n 이 받쳐 준다 |
| 판 유보 | 3,775행 · 12도메인 | L0~L1 까지. 그 아래는 잡음에 묻힌다 |
| 세계애니(896 ㄴ 팔) | **300** | 🔴 **아무 디테일도 못 잰다.** 티처 #59 M3 |
| 팝업 개입 짝 | 채점 풀 IP 68 · **2회 이상 7** | 🔴 못 잰다 |

**규칙**: 디테일 팔을 열기 전에 **그 자리의 n 과 씨앗 SD 를 먼저 재고**,
`효과 예상 / (씨앗 SD / √씨앗수)` 가 **2 를 못 넘으면 그 디테일은 이 자료로 못 잰다** 고
적고 **안 잰다**. 재고 나서 *"잡음이었다"* 로 적는 것은 계산으로 미리 알 수 있던 낭비다.

🔴 **RoPE vs 학습형 PE 같은 것은 서열 길이와 n 이 둘 다 커야 갈린다.**
이 저장소에서 그 조건을 만족하는 곳은 **장 인코더 하나**다.

  🔴 아키텍처 자(유보 R² · AUC · 개입 오차)에는 **못 쓴다.**

## 4. 🔴 비용을 사전등록한다 — 시간 복잡도·메모리·KV cache

**정확도만 적고 비용을 안 적으면 그 아키텍처는 못 쓴다.** 팔마다 함께 적는다:

- **파라미터 수** · **한 스텝 FLOPs**(대략) · **peak memory**
- **시간 복잡도** — 서열 길이 `L` 에 대해 `O(L²·d)`(전 주의) 인가 `O(L·d)` 인가.
  🔴 장은 **시군구 261 × 일별**이고 `lookback` 이 있다 — `L` 이 자라면 제곱이 문다
- **KV cache 가 되는가** — 인과 마스크가 있고 추론이 자기회귀일 때만 의미가 있다.
  🔴 **양방향 인코더에는 KV cache 가 없다.** 쓰겠다고 적기 전에 **구조가 그걸 허락하는지**
  부터 적어라(조항 59 의 형태 — 「쓸 수 있다」와 「안 써 봤다」와 「구조상 불가」는 셋이다)
- **벽시계** — 이 실험실은 노트북에서 돈다. **팔 하나가 10분을 넘으면 사다리를 줄여라**

## 5. 디테일별 — 무엇을 왜 재는가 (후보와 함정)

**위치(L6)**
- 없음 / 학습형 / 사인 / **RoPE** / ALiBi. RoPE 는 상대 위치를 회전으로 넣어 외삽이 낫다
- 🔴 함정: **장 축은 「날짜」다.** 위치가 곧 시간이면 **PE 가 날짜 대리변수**가 될 수 있다 —
  노트 745 가 정확히 그 병으로 죽었다(도메인 안 |축↔날짜| 중앙 0.309). **PE 를 넣기 전에
  「이 PE 가 라벨의 날짜를 새로 흘리지 않는가」를 재라**

**정규화(L4)**
- **pre-LN** 이 학습은 안정적이고 **post-LN** 이 최종 성능이 나은 경우가 있다 · **RMSNorm** 은 싸다
- 🔴 함정: 정규화는 **스케일을 지운다.** 장의 신호가 「수준」이 아니라 「산포」였다는 기록이 있다
  (노트 747 — 전국 평균이 구성상 0 이라 **수준이 아니라 산포**를 썼다). **어느 통계를 지우는지**
  적어라

**잔차(L5)**
- residual 은 **깊이를 가능하게 한 것**이지 장식이 아니다. ReZero/DeepNorm 은 초기 스케일 처방
- 🔴 함정: 층이 2~3 이면 residual 유무가 **안 갈릴 수 있다.** 그때는 「못 잰다」로 적는다

**주의(L3)**
- 멀티헤드는 **부분공간을 쪼개 서로 다른 관계를 보게** 한다. `d_model` 고정에 헤드만 늘리면
  `head_dim` 이 준다 — **둘을 같이 적어라**
- 🔴 함정: 우리 두 갈래(텍스트·장)는 **길이가 다르다.** 크로스 어텐션이면 **누가 query 인가**가
  설계 결정이다 — 개입→변화면 **event 가 query, 장이 key/value** 가 자연스럽다.
  **반대도 재고 근거를 적어라**

**FFN(L7)**
- 확장비 4배가 관례 · **SwiGLU** 는 게이팅으로 표현력을 얻고 파라미터가 늘어난다
- 🔴 함정: **파라미터를 늘려 이긴 것은 아키텍처가 이긴 게 아니다.** 팔끼리 **파라미터 예산을
  맞추거나**, 못 맞추면 **파라미터 수를 표에 병기**하라

**활성**
- GELU / SiLU / ReLU². 대개 작은 차이 — **n 이 작으면 못 갈린다**(§2 를 먼저 세라)

## 6. 🔴 `L(g, event)` — 이 저장소의 진짜 빈칸

원장 5738행(사용자 지적 + 자기 진단):
> *"정보 전이장 `g(x,t)` 가 있고 event 와 반응해 그 지역의 정보 활성 `L(g, event)` 가 될
> 것이다. 장을 유체역학적으로 생각하자고 했는데 잘 하고 있나"* — **절반만 하고 있었다.**
> 방문자 축은 `L` 이 아니라 **`g(x, t₀⁻)` 를 한 점에서 읽은 것**이고 **상호작용항이 없다.**

**아키텍처 사다리의 L1 은 결국 `L` 의 꼴을 고르는 것이다:**

| 합류 | `L` 의 꼴 | 비용 |
|---|---|---|
| 늦은 합류 | `L = α·f(e) + β·h(g)` — **상호작용 없음** | 제일 쌈 · 기준선이 돼야 한다 |
| concat | `L = MLP([f(e); h(g)])` | 쌈 |
| **게이팅** | `L = f(e) ⊙ σ(W·h(g))` — **장이 사건 표현의 문을 연다** | 쌈 · 🔴 `L` 의 제일 단순한 참꼴 |
| 어텐션 | `L = Attn(q=f(e), kv=h(g))` — **어느 지역·시점의 장을 볼지 학습** | 비쌈 |
| 쌍선형 | `L = f(e)ᵀ W h(g)` | 중간 · 해석 가능 |

🔴 **게이팅부터 재라.** 늦은 합류(상호작용 0)와 게이팅(상호작용 1차)의 차이가
**「상호작용항이 있느냐」를 그대로 잰다.** 어텐션은 그 위다.

## 8. 하지 말 것

- 🔴 **사다리를 건너뛰고 디테일부터 만지지 마라.** L1 이 널을 못 넘으면 L6 은 의미가 없다
- 🔴 **여러 디테일을 한 번에 바꾸지 마라.** 어느 것이 효과인지 못 가른다
- 🔴 **씨앗 하나로 아키텍처를 고르지 마라.** 노트 735: 씨앗 SD 가 효과의 **두 배**였다
- 🔴 **「제일 좋은 팔」을 그대로 채택하지 마라**(노트 133). 20팔에서 최대는 거의 항상 잡음이다.
  통과해도 **제안**이고 확인 측정은 다음 사이클
- 🔴 **파라미터를 늘려 이긴 것을 아키텍처의 승리로 적지 마라**
- 🔴 **학습 손실이 내려가는 것을 성공으로 읽지 마라**(조항 59) — 노트 735 에서
  **손실은 내내 내려가는데 유보는 600걸음 이후 무너졌다**(−0.363 → −1.768)
- **유보를 보고 조기 종료 지점을 고르지 마라.** 노트 735 가 `pretrain` 을 그래서 고쳤다 —
  **학습구간 검증으로 최선 지점을 잡고 그 가중으로 되돌린다**

# 9. 🔴 디버깅이 아키텍처의 절반이다

> **2026-08-10 사용자 지시**: *"결국엔 **디버깅을 잘하고** 그거에 대한 아이디어 발전을
> **다른 논문들에서 적절하게 가지고 올 수 있어야** 하는 거지."*

이 실험실은 **측정 디버깅은 세계 수준**이다 — 배선 검사(sha256 비트 대조 · 주입 **뒤**
`Data` 를 열기) · 널 팔 짝 · **심어서 확인**(#109 가 죽은 숫자를 일부러 심어 잡히는지 봤다) ·
회계를 손으로 안 적기.

🔴 **그런데 그 규율이 NN 학습에는 한 번도 적용된 적이 없다.** 노트 735 가
씨앗 SD 0.2735 를 뒤늦게 발견한 것이 그 증거다.

## 9.1 학습 전 — 배선 검사의 NN 판본 (전부 1분 안에 돈다)

| 검사 | 무엇 | 실패하면 |
|---|---|---|
| **한 배치 과적합** | 8~32개 표본을 **손실 ~0 까지** 외울 수 있나 | 🔴 **못 외우면 배선이 끊겼다.** 그 아래는 다 무의미 |
| **모양·dtype 단언** | 층마다 `assert x.shape == (...)` · float32/64 섞임 | 조용한 브로드캐스팅이 축을 바꾼다 |
| **파라미터가 실제로 갱신되나** | 스텝 전후 `‖Δθ‖` 를 **층별로** | 0 인 층 = **죽은 가지**(887형의 NN 판본) |
| **기울기 노름** | 층별 `‖g‖` · NaN/Inf 검사 | 폭발·소실을 손실보다 먼저 본다 |
| **항등 붕괴** | 새 블록을 **항등으로 초기화**하고 기준선과 **비트 동일**한가 | 다르면 블록이 뭔가를 이미 하고 있다 |
| **입력 지우기** | 한 갈래를 0/셔플로 넣고 출력이 **바뀌나** | 🔴 **안 바뀌면 그 갈래는 안 닿았다** — 887 이 축 주입에서 겪은 그 병 |
| **라벨 순열** | 라벨을 섞고 학습 → 유보가 **널이어야 한다** | 널이 아니면 **누출**이다 |
| **결정성** | 같은 씨앗 두 번 → 비트 동일 | 아니면 재현이 안 되고 판정도 안 선다 |

🔴 **「입력 지우기」와 「항등 붕괴」가 이 실험실 배선 검사의 직역이다.** 반드시 넣어라.

## 9.2 학습 중 — 조항 59 의 NN 형태

**학습 손실이 내려가는 것은 작업의 성공이지 측정의 성공이 아니다.**
노트 735 실측: **손실은 내내 내려가는데 유보 R² 는 600걸음 이후 −0.363 → −1.768** 로 무너졌다.

기록할 것: 스텝별 `학습손실 · 검증손실 · ‖g‖ · lr · 유효 배치` ·
**씨앗별 곡선을 겹쳐 그려라**(하나만 보면 노트 703 처럼 최선 씨앗을 본다).

🔴 **조기 종료 지점을 유보로 고르지 마라.** `pretrain` 이 이미 고쳐 둔 방식 —
**학습구간 검증으로 최선 지점을 잡고 그 가중으로 되돌린다.**

## 9.3 실패하면 — **재현부터 하고 설명은 나중에**

🔴 **노트 745~749 의 교훈**: *"나는 **재현하지 않은 이상값**을 두 사이클 동안 설명하려 했다."*
0.0302 를 주어진 사실로 놓고 실험 둘을 태웠는데 **재현은 10분이었다.**

**순서**: ① 다시 돌려 재현하나 ② 재현되면 **하나씩 끄면서** 이분 탐색
③ 그래도 모르면 **「모른다」로 적는다** — *"못 찾았다"* 와 *"없다"* 는 다르다(조항 59).

# 10. 🔴 문헌 수확 — 이 저장소에 없는 통로

**실측**: 900노트를 **전부 자급자족**으로 돌았다. 외부 논문을 읽고 들여온 기록이 없다.
`paper/` 는 **우리가 쓴 것**이지 읽은 것이 아니다. 사용자 지적이 정확히 이 구멍이다.

## 10.1 루프에 넣는다 — ②' 문헌 수확 (선택 단계 · 아키텍처 사이클에만)

**아키텍처를 만지는 사이클에서는 팬아웃에 「문헌」 자리를 하나 더 둔다.**

- **묻는 것을 좁혀서 시킨다.** *"트랜스포머 최신 동향"* ❌ →
  *"두 갈래(길이가 다른 서열 + 격자 시계열)를 합류시키는 구조에서 어느 쪽을 query 로
  두는지, 그리고 n 이 10⁴ 규모일 때 어떤 정규화가 안정적인지"* ✅
- **가져올 때 반드시 셋을 적는다**: ① **출처**(제목·연도·링크) ② **원 논문이 잰 조건**
  (n · 서열 길이 · 도메인) ③ 🔴 **우리 조건과 무엇이 다른가**
- 🔴 **조항 60 의 문헌 판본**: **남의 n 으로 우리 결론을 말하지 마라.**
  n=10⁸ 에서 선 디테일이 n=10³ 에서 서지 않는다. **분모가 다르면 이어 붙이지 마라.**

## 10.2 들여온 것은 **주장이 아니라 후보**다

| 단계 | 무엇 |
|---|---|
| **인용** | 논문이 그렇게 말한다 — **우리 저장소의 사실이 아니다** |
| **후보** | 사다리(§1)의 한 팔로 등록 · 사전등록에 출처를 적는다 |
| **측정** | 우리 자·우리 널로 잰다 |
| **채택** | 노트 133 — **제안**까지. 확인은 다음 사이클 |

🔴 **인용을 근거로 판정하지 마라.** *"논문 X 가 RoPE 가 낫다고 했으니 RoPE 를 쓴다"* 는
**배선 없이 측정했다고 쓴 것**과 같은 병이다(티처가 매번 잡는 ③번 항목).
