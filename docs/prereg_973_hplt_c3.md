## 4. 개체 언급 자 (측정 전에 얼린다)

- 제목 정규화: 끝의 괄호 주석 제거(`노르웨이의 숲 (소설)` → `노르웨이의 숲`) · 공백 정규화 · 소문자화
- 자격: 정규화 제목 길이 **≥ 4**(한글 포함) / **≥ 6**(라틴만) — 짧은 일반어 배제
- 토큰: `[^0-9A-Za-z가-힣]+` 로 자른 **공백 토큰** · 제목은 **최대 5 토큰**(공백 5-gram · 954 결론)
- 조사 벗기기(얼린 목록): `이라는 라는 으로 에서 에게 부터 까지 은 는 이 가 을 를 의 에 와 과 도 로 만`
  — 토큰 길이가 조사보다 **2 이상 길 때만** 벗긴다
- 🔴 **일반어 의심 표시**: 이 주행의 **정제 통과 문서**를 분모로 문서빈도(DF)가 **1% 초과**인 제목은
  `일반어_의심 = true` 로 **행에 박는다**. 🔴 **행을 지우지 않는다 — 분모를 남기고 양쪽을 다 보고한다.**
