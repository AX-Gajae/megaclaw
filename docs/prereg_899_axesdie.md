## 2. 갈래 ㄱ — 유보에서 축이 죽는다 (서술 통계)

### 2.1 무엇을 세는가 (도메인 12 전량 · 씨앗 0)

채점 집합의 정의는 **판과 같게** 쓴다: `post = isfinite(yr) & (yr >= 2025)`,
그 안에서 `ok = isfinite(p) & isfinite(y)` (`lab/harness.py:_score_one`).

| 기호 | 정의 | 왜 |
|---|---|---|
| `n` | 채점행 수 | 판 가중의 분자 |
| `p36` | `len(d0.names[d])` — 그 도메인의 축 이름 수 | 티처가 「36」이라 부른 것. **내가 다시 센다** |
| `uniqA` | `A[hold]` 의 **고유 행** 수 | 티처의 「고유 특성행」 |
| `uniqAM` | `hstack(A,M)[hold]` 의 고유 행 수 | 마스크까지 봤을 때 |
| `uniqF` | 🔴 **모형이 실제로 보는 설계행렬** `forms.DirectPool._feat(A,M,names,order)` 의 고유 행 수 | 아래 2.2 |
| `nzA` | `A[hold]` 에서 고유값 ≥ 2 인 열 수 | 티처의 「비상수 열 / 36」 |
| `nzF` | 🔴 `_feat` 산출의 비상수 열 수 (값열/표시자열 따로) | **진짜 레버 수** |
| `uniq_y` | 라벨 고유값 수 | |
| `uniq_p` | 씨앗 0 예측 고유값 수 | 동률 블록 |

### 2.2 🔴 미리 적어 두는 예측 — `_feat` 는 도메인 축을 대부분 안 본다

코드를 읽고 **측정 전에** 적는다(`lab/forms.py:197 AXIS_MODE = "common"` ·
`lab/forms.py:200 axis_order` · `lab/loop.py:653` 의 티처 #52 C1 주석):

> `axis_order(mode="common")` 은 **12도메인이 전부 가진 축만** 돌려준다.
> `_feat` 는 그 목록으로만 돈다. 그러므로 도메인마다 다른 `p36` 은 **설계행렬에 안 닿는다**.
> 즉 「시장팝업의 레버가 넷」이라는 문장조차 **위쪽 한계**일 수 있고,
> 실제 레버는 **모든 도메인에서 같은 수**(공통 축 수 × 2 + 도메인 원핫)일 수 있다.

- **이 예측이 맞으면**: 축퇴의 원인 하나는 도메인 자료가 아니라 **정식화의 `common` 정책**이다.
  → 「축이 죽는다」의 최소 한 갈래는 **ⓑ 전처리**이고, 자료를 더 모아도 안 풀린다.
- **틀리면**(`order` 가 도메인별 축을 다 담고 있으면): 축퇴는 자료 쪽 문제다.
- **어느 쪽이든 적는다.** 예측을 적어 두는 이유는 사후에 유리한 쪽을 못 고르게 하기 위해서다.

### 2.3 🔴 왜 죽는지 — **세 갈래 배정 규칙**(측정 전에 못 박는다)

유보에서 **상수인 열** 하나하나를 다음 우선순위로 **정확히 한 갈래에** 넣는다.

| 갈래 | 판정식 | 뜻 |
|---|---|---|
| **ⓐ-0 축 없음** | 전 행에서 `M[:,j] == 0` **이고** `A[:,j] == 0.5` (중립 채움) | 그 도메인에 그 축이 **아예 없다**(`harness.load` 의 중립 대입) |
| **ⓐ 원천 무변이** | 전 행(학습+유보)에서 `A[:,j]` 고유값 ≤ 1 **이고** 원천 축 json 의 해당 필드도 고유값 ≤ 1 | 원천에 값이 하나뿐 |
| **ⓑ 전처리** | (`(d, 축) ∈ lab.fixaxes.BLOCK`) **또는** (원천 필드는 고유값 ≥ 2 인데 최종 `A`/`M` 이 상수) **또는** (`M` 전 행 0 인데 원천 값은 변한다) | 파이프라인이 죽였다 |
| **ⓒ 분할** | 최종 `A[:,j]` 가 **전 행에서는** 고유값 ≥ 2 인데 **유보에서만** 상수 | 유보 분할이 변이를 학습 쪽에 몰았다 |
| **모른다** | 위 넷 중 어디에도 안 들어가거나, 원천 필드를 **행 정렬로 못 붙였다**(W4 실패) | 🔴 **빈 것을 부정으로 읽지 않는다**(조항 59) |

- ⓑ 의 「원천 필드」는 `state/tri_domain.py:_from_axes_json` 이 읽는 `axes[a]`/`mask[a]` 를
  **같은 행 순서**로 다시 읽어서 쓴다(W4 가 지킨다).
- 🔴 배정은 **열 단위**이고, 도메인별로 **네 갈래 개수의 합 = 상수 열 수** 임을 코드가 assert 한다.
  안 맞으면 산출물에 `배정 불일치` 를 찍고 「모른다」로 올린다.

(`_from_axes_json` 의 `else` 갈래) — 하네스만 보면 **날짜를 잃는다.**
그래서 **원천 json 의 날짜 문자열을 다시 읽어** 일(日) 해상도로 군집을 만든다.

- 군집 키 = 날짜 문자열의 앞 10자(`YYYY-MM-DD`). 못 파싱하면 **그 행은 단독 군집**으로
  두고 `날짜 미상 행수` 를 따로 보고한다(🔴 미상을 0 으로 뭉개지 않는다 — 조항 59).
- 병기: **월(月) 군집**(`YYYY-MM`)도 같이 잰다. 일 군집이 거의 단독이면 월이 더 맞는 단위다.

### 3.2 ICC

도메인마다 유보 채점행에서 **잔차** `r_i = rank(y_i)/n − rank(p_i)/n` (씨앗 0 예측)을 만들고,
날짜 군집에 대한 **일원 변량효과 ICC** 를 ANOVA 로 잰다:

```
ICC = (MSB − MSW) / (MSB + (m0 − 1)·MSW),   m0 = (N − Σ m_k² / N) / (K − 1)
DEFF = 1 + (m̄ − 1)·ICC,                     m̄ = N / K
n_eff = N / DEFF
```

- **m̄ 와 m0 를 둘 다 인쇄한다.** 898 탐색이 걸린 병이 *"자기가 인용한 공식으로 검산 안 했다"* 였다.
- 🔴 **검산 의무**: 같은 잔차로 `DEFF_실측 = (SD_날짜군집부트 / SD_행부트)²` 를 재고
  **공식 DEFF 와 나란히 인쇄**한다. 둘이 2배 이상 갈리면 **「모른다」로 올린다.**
- 라벨 자체의 ICC 도 병기한다(잔차 ICC 와 뜻이 다르다).

### 3.3 🔴 ICC 가 0 에 가까우면 — **그것도 결과다**(조항 59)

미리 적는다:

| 결과 | 무엇을 뜻하나 | 무엇을 적나 |
|---|---|---|
| **ICC ≤ 0.01 (또는 음수)** | 같은 날짜의 행들이 잔차를 **공유하지 않는다**. 판의 「3,774 단독 군집 = 행 독립」 가정이 **이 자료에서는 해롭지 않다**. 897 의 「잡음 단위는 날짜」는 **그 분모(3,710행·11도메인·다른 과제)에서만** 참이고 판으로 옮겨오지 않는다(조항 60) | **「행 독립 가정은 유보 잔차에서 반증되지 않았다」** 로 적는다. 문턱 0.00353 은 **이 축으로는 안 움직인다** |
| **0.01 < ICC < 0.1** | 약하지만 있다. DEFF 가 m̄ 에 비례해 커진다 | 새 문턱 후보를 **병기만** 한다 |
| **ICC ≥ 0.1** | 유효 표본이 실질적으로 줄고 **문턱 0.0035242 가 낮게 서 있다** | 🔴 새 문턱 후보를 산출하고 **다음 사이클 ⓪ 의 1순위**로 이슈를 연다 |
| **군집이 거의 전부 단독**(m̄ < 1.2) | 날짜가 행을 안 묶는다 | ICC 를 **「잴 수 없다」** 로 적는다 — 0 이라고 적지 않는다 |

### 3.4 문턱 재산정 (이 사이클에서 값이 제일 큰 수)

`thresh891` 의 `R5 = 2·hypot(씨앗성분, 행짝성분)` 에서 **행짝성분만** 다시 뽑는다.

- 옛 행짝성분 **0.00146** 은 `NULL_K1(A−B)`·`NULL_K2(A−B)` 의 **행 단위** 재표집 SD 의 큰 쪽
  (아이돌만 프랜차이즈 군집)이다. 이것을 **날짜 군집 재표집**으로 바꾼다.
- 씨앗 성분 **0.00099** 는 씨앗 수준이라 **안 건드린다**(같은 값을 그대로 읽어 쓴다).
- `B = 10,000` · rng 씨앗 `8900` · `runners/out891_fits.npz` 예측 재사용(W5 가 정당화).
- 아이돌은 **둘 다** 낸다: (i) 날짜 군집 (ii) 프랜차이즈 ∪ 날짜(합집합 군집).
- 산출: `R5_날짜 = 2·hypot(0.00099, 새 행짝성분)` 과 `R5_날짜 / 0.00353` 배수.
- 🔴 **이 값으로 아무 팔도 판정하지 않는다.** 문턱 정본은 이 사이클에서 안 바꾼다(노트 133).
