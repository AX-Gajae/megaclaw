## §2 🔴🔴 규율 4 — 채택 크기와 오라클 천장을 나란히 적는다

`docs/목표.md` 규율 4(티처 #75 C3 이 신설): **「채택 크기 X · 이 자의 오라클 천장 Y · X/Y = Z」**.
**Z > 1 이면 그 사이클은 크기 관문을 원리상 못 넘는다.**

| | 값 | 출처 |
|---|---|---|
| **X** 채택 크기 | **1.0 일** | `docs/목표.md` ③ 행 — 🔴 **이 사이클이 고른 수가 아니다** |
| **Y** [달력제거]의 오라클 천장 | **0.328387590682075 일** | `runners/out933_oracle.json` (내가 직접 적합) |
| **Z = X/Y** | 🔴 **3.045182060390764** | |
| Z > 1 인가 | 🔴 **참** | |

오라클 = 조건 열(dow·quarter·b_prv·b_mag · `cal_off` 라 실제 12칸)로 **홀드아웃 답을 알고** 최적 적합한 팔.
층을 넷으로 낸다: ① 시험 팔의 칸 구조 **0.32839** · ② `prevmed` 실수값 347칸 **0.82161** ·
③ 격자 정체 2,277칸 **1.94386** · ④ 완전 오라클 12.18579.
🔴 **진짜 팔의 실측 0.32380 은 천장의 98.60%** — [둘 다] 판의 99.3% 와 같은 자리다. **이 팔은 이미 끝나 있다.**

🔴 **검증**: 같은 코드로 [둘 다] 판을 재면 티처 #75 C3 의 세 수가 나온다 —
Y=**0.21800893791004938**(티처 0.2180) · ② **0.7697822572977078**(0.7698) · ③ **1.3901112484548825**(1.3901).

### 🔴 그래서 **크기 판정은 측정 전에 정해진다**

**Z > 1 이므로 이 사이클의 크기 판정은 「이 자로는 원리상 못 넘는다」다.** 측정 결과와 무관하다.
🔴 이것을 **헤드라인에 적는다.** 유의성 판정은 그대로 낸다(§4).
🔴 그리고 이 문장을 **도피구로 쓰지 않는다** — 「그러니 크기는 안 재도 된다」가 아니라
**「이 문턱으로는 어떤 사이클도 ③ 을 못 움직인다 — 문턱이 아니라 조건 열을 바꿔야 한다」**이다.
여는 방향은 ③ 격자 정체(1.94386일)가 가리킨다.

## §3 🔴 검출력 — 경험분포로 낸다 (정규 근사 금지)

**절차**(측정 전에 박는다 · `state/calpanel933.empirical_power`):

1. **파일럿** 씨앗 901~920 (20뽑기 · **판정에 안 쓴다**)로 이 판 귀무의 **위치와 폭**만 잰다.
2. **모양**은 앞선 사이클의 경험분포에서 빌린다 — `runners/out928_draws.json` 의 **200뽑기**를 표준화한 것.
3. 표준화 거리 `D = (진짜 − 파일럿평균) / 파일럿SD` 를 그 경험분포에 대고 꼬리확률
   `q̂ = (1 + #{z ≥ D}) / (1 + 200)` 을 읽는다. **정규 분포를 한 번도 안 쓴다.**
4. B=200 에서 `p < 0.01` 은 **k=0** 과 동치이므로(1/201 = 0.004975 < 0.01 ≤ 2/201 = 0.00995)
   **검출력 = (1 − q̂)^200**.

🔴 **이 추정의 해상도 천장을 미리 적는다**: 모양 표본이 200개라 `q̂` 의 바닥이 **0.004975** 이고,
그래서 **검출력 추정값의 천장이 (1−0.004975)^200 = 0.3686** 이다.
**이것은 진짜 검출력의 천장이 아니라 추정 해상도의 천장이다** — 헷갈리면 928 의 자기적발 ①을 반복한다.
🔴 **빌려 온 모양이 [둘 다] 판의 것**이라는 게 이 계산의 전제이고, 그것이 이 절차의 약점이다.

🔴 **검출력은 관문이 아니다.** 수를 내고 **신고만** 한다 — 판정은 §4 를 무조건 적용한다.
**이유**: 검출력 관문을 두면 결과가 나쁠 때 「검출력이 모자랐다」로 빠져나가는 **도피구**가 된다.
티처 #75 가 이 사이클에 건 조건은 **「어느 쪽이든 이 사이클에서 끝난다」**이다.

- **②** [달력제거·경계강제] 200뽑기에서 **p < 0.01 인가**

| 결과 | 헤드라인 (🔴 **미리 써 둔다**) |

| **① 참 · ② 거짓** | 🔴 「928 의 헤드라인은 **분위 경계 하나의 이름**이었다. 옳은 문장은 **「순서는 표의 분위 경계를 반나절 움직인다 — 그것이 예측력인지는 이 자로 못 가른다」**」 |
| **① 거짓** | 🔴 「깨끗한 판에서는 **못 이긴다**. 928 의 p=0.004975 는 [둘 다] 판의 **정답 불일치**(진짜 첫 간격 중앙값 20.0 대 귀무 11.0)에 기댄 수였다」 |

같이 싣되, **채택 판정에 쓰지 않는다.**

**보조로 싣되 판정에 안 쓰는 것**(928 의 병을 반복하지 않으려고 미리 못 박는다):
z · 왜도 · 첨도 · 분위 — 🔴 **혼합분포의 요약이면 해석 불가**다. **경계 상태별로 갈라 센 표를 함께 싣고,
상태가 둘 이상이면 전체 z 는 「해석 불가」라고 적는다.**
