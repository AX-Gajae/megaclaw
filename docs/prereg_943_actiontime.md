## 1. 무엇이 틀렸다고 보는가

`runners/out942_stock.py:196-199` 의 `a_of()` 는 A·B 계열 1,054 에서
`intervention` dict 가 **비어 있지 않다**만 본다. **시점이 없다.**
같은 파일 `:308` 의 `d2_stock()` 은 a 를 **날짜**로 정의한다 —
**한 러너 안에 a 의 정의가 둘**이고, 노트도 원장도 못 알아챘다.

그래서 942 의 `a=1,328` 은 「액션이 있다」가 아니라 **「액션 칸이 있다」**이다.
`docs/목표.md:43` 이 못 박은 대로 출력 ③④⑤ 가 0 인 이유가 **이벤트가 놓인 시간축**인데,
그 시간축이 a 의 정의에 안 들어가 있다.

## 2. 무엇을 고치나

1. `a` 를 **「액션의 시점(날짜)이 있다」**로 재정의한다.
   - A 계열: `conditions.period.from`
   - B 계열: `conditions.period_from`
   - C 계열: `debut_date`
2. 🔴 **`period_*` 를 `s` 에서 빼내 `a` 로 옮긴다.** 그래야 `s` 가 처음으로
   「액션 **앞**」이라는 이름값을 갖는다.
3. 🔴 **`conditions` 의 열을 하나씩 「액션 앞에 알 수 있었나」로 판정한다.**
   세 통: **PRE**(앞) · **POST**(뒤) · 🔴 **모른다**.
   판정 규칙(측정 전에 못 박는다):
   - **PRE** = 저장소 안에 그 열을 만드는 코드가 있고 그 코드가 **액션 날짜 이전으로 자르는
     것이 원문에 보인다**, 또는 열이 액션 날짜·계획의 결정론적 함수다.
   - **POST** = 열의 값·출처가 **액션 시작 시점 이후에 관측된 것**이라고 스스로 말한다.
   - **모른다** = 둘 다 아니다. 🔴 **「없다」로 세지 않는다**(조항 59).
   942 는 이 잣대를 D2 엔 물리고 **D1 엔 안 물렸다**.
4. **새 러너**로 낸다(`runners/out943_axis.py`). 🔴 **942·941 산출물은 동결 — 안 덮어쓴다.**

## 4. 반증 조건 — 이 중 하나라도 걸리면 **내 수리가 틀렸다**

1. `a(시점)` 이 **1,231 이 아니다** → 계열 분해나 키 경로가 틀렸다. 그 자리에서 멈추고 신고한다.
2. **두 번째 경로**(`runners/out943_recount.py` — `out943_axis.py` 를 한 줄도 import 하지 않고
   따로 짠다)가 헤드라인 수 하나라도 다르게 낸다 → **무효**.
   🔴 **두 번째 경로의 코드를 커밋한다**(942 의 M1 재발 금지).
3. A 계열에 평평한 `period_from` 이 **1건이라도** 있거나 B 계열에 중첩 `period.from` 이
   **1건이라도** 있다 → 계열 판정이 틀렸다.
4. 같은 명령·같은 입력에서 **942 의 1,328 / 1,315 / 732 가 재현되지 않는다**
   → 고치기 전/후 비교가 성립하지 않는다. (942 의 `a_of`·`s_of` 를 **import 해서** 돌린다.)
5. `o`(942 검출기)가 **755 가 아니다** → 내가 o 를 건드렸다는 뜻이다.

## 5. 이 사이클이 지킬 절차 의무 (942 가 어긴 것들)

- ⑤′ 취합 검사를 **⑥ 앞에** 돌리고 산출물 `runners/out943_fiveprime.json` 을 남긴다.
- 스탬프는 **시작 시각 · 끝 시각 · 입력 sha256 · 코드 sha256** 넷.
  🔴 `git rev-parse HEAD` 는 **루프 v3.2 가 폐기했다**(`docs/루프.md:443-448`) — 안 쓴다.
- `sha()` 를 **실제로 호출**해서 입력 파일 sha256 을 산출물에 박는다(942 는 죽은 함수였다).
- 🔴 **출처를 지어내지 않는다.** 규격을 인용하면 원문을 열고, 못 열면 「내가 만든 것」이라 적는다.
- 내가 출력하는데 노트에 안 쓰는 수는 **「죽은 숫자」로 표시**한다.
