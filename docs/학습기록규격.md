기계 판본은 `trainlog/spec.py` 이고 **이 문서가 인용하는 이름·상수는 거기서 온다**
(두 벌을 손으로 적으면 갈라진다 — 노트 546·549·670 이 세 번 밟은 병).

> ## 🔴 왜 이 규격이 있나
>
> 노트 897 이 파이썬 **604개를 전수 AST** 로 훑어
> `state/masked_encoder` · `shared_encoder` · `fewshot` · `transfer_eval`

## 0. 세 줄로 쓴다

```python
from trainlog import Run
with Run("909-ssl", pushes="③", ruler="소수 라벨 곡선") as r:
    r.arch(model)                       # torch 모듈이면 자동 추출
    for step in range(...):
        r.log(step=step, split="train", loss=..., acc=...)
```

- 🔴 **torch 는 필수가 아니다.** `r.arch()` 는 **셋** 중 하나를 한다 —
  torch 모듈이면 introspect, dict 면 그대로, 아무것도 없으면
  **「아키텍처 못 읽음」으로 기록**한다(조항 59: *'없다'와 '못 봤다'와 '못 읽었다'는 셋이다*).
- `with` 를 안 써도 된다 — `r = Run(...)` … `r.finish()`.
  🔴 `finish()` 없이 프로세스가 끝나면 상태가 **「끝남」이 아니라 「터짐」**으로 남는다.

## 1. 저장 자리 — 🔴 **덮어쓰기 금지**

```
data/trainlog/<run_id>/
    manifest.json    자기서술 — 누가 · 언제 · 어떤 코드 · 어떤 자로
    metrics.jsonl    append-only 지표 스트림 (step · split · name · value)
    arch.json        아키텍처 그래프 (층 · 간선 · 파라미터 수 · 가중치)
```

`run_id = <ASCII 로 접은 이름>-<UTC YYYYMMDDThhmmssZ>` 이고, 같은 초에 또 만들면
`-2`, `-3` 이 붙는다. **지난 학습을 새 학습이 지우면 이력이 거짓이 된다.**
한글 이름은 `이름(원래)` 칸에 그대로 남는다(id 만 ASCII 로 접는다 · 노트 693).

## 2. `manifest.json` — 반드시 있는 칸

`trainlog.spec.REQUIRED_MANIFEST` 가 정본이고 `check_manifest()` 가 검사한다.

| 칸 | 무엇 | 없으면 |
|---|---|---|
| `규격` · `규격 판` | `trainlog/1` · `1.0.0` — 🔴 **규격은 나중에 바뀐다** | 규격 위반 |
| `run_id` | ASCII 만(`[A-Za-z0-9._-]`) · 충돌 불가(UTC 접미) | 규격 위반 |
| `이름(원래)` | 사람이 준 이름(한글 가능) | — |
| `데모인가` | 🔴 데모 run 은 **참**이어야 한다 — 진짜 기록과 안 섞이게 | — |
| `상태` | `도는 중` / `끝남` / `터짐` — **셋을 합치지 않는다** | 규격 위반 |
| `시작 UTC` · `끝 UTC` · `초` | 도는 중이면 `끝 UTC` 는 `null` | — |
| `씨앗` | 난수 씨앗 | `null` 로 **적힌다** |
| `하이퍼파라미터` | dict 그대로 | `null` |
| `코드 sha256` | 🔴 `Run` 을 만든 **바깥 파일**의 sha256(`{경로, sha256, 바이트}`) · 목록도 가능 | `못 읽음` 사유가 적힌다 |
| `입력 데이터 sha256` | `data=[...]` 로 준 파일들 | `없음` 사유가 적힌다(≠ 못 읽음) |
| `미는 출력` | 🔴 `docs/목표.md` 의 다섯 중 무엇을 미나. **「해당 없음」도 값이다 — 안 적는 것만 금지** | 규격 위반 |
| `자` · `자 없음` | 🔴 **무엇으로 판정하나.** 자 없는 run 도 **기록은 되되** `자 없음: true` 로 **보인다** | 어긋나면 규격 위반 |
| `지표 줄 수` · `기록 실패 n건` | 쓴 쪽이 센 수 · 🔴 실패를 **조용히 안 삼킨다** | — |
| `아키텍처` | `{읽음, 출처, 층 수, 간선 수, 간선 출처, 총 파라미터, 가중치를 읽었나, 왜 못 읽음}` | — |
| `환경` | python · platform · torch 판(없으면 `"torch 없음"`) · pid | — |

🔴 **읽는 쪽은 쓰는 쪽을 믿지 않는다.** 목록 화면은 `지표 줄 수(manifest)` 와
**직접 센 수**를 나란히 내고, 어긋나면 `수가 어긋나나` 가 참이 된다(조항 60).

## 3. `metrics.jsonl` — append-only 지표 스트림

첫 줄은 자기서술 헤더, 그 뒤로 한 줄에 한 점.

```json
{"규격":"trainlog/metrics/1","run_id":"…","UTC":"…","칸":["step","split","name","value"]}
{"step":2,"split":"train","name":"loss","value":1.0782,"t":"2026-08-11T05:05:31Z"}
```

- `r.log(step=…, split=…, **지표)` 는 **리스트에 튜플을 붙일 뿐**이고 실제 쓰기는
  묶어서(`flush_every=50` · `flush_secs=1.0`) 한다 — **학습을 못 느리게 한다.**
- 🔴 **줄 단위로 흘린다**(`flush()`) — 프로세스가 죽어도 그때까지 쓴 줄은 읽힌다.
- 🔴 **쓰기가 터져도 학습을 안 죽인다.** 대신 `기록 실패 n건` 이 오르고 앞 5건은
  사유까지 남는다. *조용히 삼키는 것*과 *학습을 죽이는 것*은 둘 다 틀렸다.
- 수가 아닌 값(문자열)은 **버리지 않고** 적되 곡선에서는 뺀다(화면이 그 사실을 적는다).

## 4. `arch.json` — 아키텍처 그래프

```json
{"규격":"trainlog/arch/1","읽음":true,"출처":"torch introspect",
 "층":[{"id":"0","이름":"0","종류":"Linear","입력 모양":[null,12],"출력 모양":[null,64],
        "파라미터 수":832,"활성함수":"ReLU","뉴런 수":64,"입력 뉴런 수":12,
        "가중치":{"있나":true,"모양":[64,12],"담음":true,"값":[[…]],"행 노름":[…]}}],
 "간선":[{"from":"__입력__","to":"0"},{"from":"0","to":"2"}],
 "간선 출처":"torch.fx 추적","총 파라미터":1387,"학습 가능 파라미터":1387}
```

| 칸 | 규율 |
|---|---|
| `출처` | `torch introspect` / `준 dict` / **`못 읽음`** — 셋뿐이고 합치지 않는다 |
| `간선 출처` | 🔴 `torch.fx 추적`(실제 호출 그래프) 인가 **`모듈 등록 순서(가정)`** 인가. **가정을 실측인 양 적지 않는다** |
| 활성함수 | 별도 층으로 두지 않고 **앞 층의 `활성함수` 칸**으로 접는다(접은 목록을 남긴다) |
| 가중치 | 요소가 **4,096개**를 넘으면 값을 **안 담고 이유를 적는다** → 그림은 **「구조만」**. `행 노름`(행 8,192개까지)은 남겨 **뉴런 고르기**에 쓴다 |

## 5. 🔴 뉴런 단위 그림 — 자를 때 무엇을 몇 개로 잘랐는지 **화면에 적는다**

`/api/trainlog/run?id=…&max_neurons=32` 가 층마다 낸다:

```
{"이름":"hidden","전체 뉴런":1024,"그린 뉴런":32,"잘림":true,
 "고른 기준":"🔴 고른 간격으로 32개를 골랐다 --- 가중치를 못 읽어서 세기로 고를 수 없었다",
 "말":"🔴 **1,024개 중 32개만 그렸다** --- …"}
```

- **작은 층은 뉴런 하나를 점 하나로** 그린다. 층 사이 간선도 다 긋는다.
- **큰 층은 다 못 그린다.** 그때 `잘림: true` 와 **「N개 중 k개만 그렸다」**와
  **고른 기준**이 화면 표에 그대로 나간다. 조용히 자르면 그것이 조항 59 위반이다.
- 고르는 기준은 둘뿐이다 —
  ① 가중치 **행 L2 노름 상위**(가중치를 읽었을 때)
  ② **고른 간격**(🔴 *가중치를 못 읽어서 세기로 고를 수 없었다*고 적는다).
- 간선 굵기·색은 **가중치가 있을 때만** 뜻이 있다. 없으면 화면이
  **「가중치를 못 읽어 구조만 그렸다 — 굵기에 뜻이 없다」**를 적는다.
- 🔴 이 그림은 층을 **차례로** 이은 것이다. 갈래(잔차·분기)가 있으면 그림이 안
  보여 주므로, 층 사이 진짜 연결은 `arch.json` 의 `간선` 을 봐라(화면에도 적힌다).

## 6. 창구 — `/trainlog`

| 자리 | 무엇 | LLM 을 부르나 |
|---|---|---|
| `GET /trainlog` | 한 페이지 — run 목록 → 곡선 여러 개 겹쳐 보기 + 뉴런 그림 | **안 부른다** |
| `GET /api/trainlog/runs` | run 목록 | 안 부른다 |
| `GET /api/trainlog/run?id=…&max_neurons=…` | manifest · 곡선 · 구조 · 뉴런 | 안 부른다 |
| `GET /api/trainlog/metrics?id=…` | 곡선만 | 안 부른다 |
| `GET /api/trainlog/arch?id=…` | 뉴런 그림만 | 안 부른다 |
| `GET /api/trainlog/selftest` | 🔴 **이 창구의 자**를 잰다 | 안 부른다 |

- 🔴 **CDN 없음 · 외부 요청 없음.** 차트도 뉴런 그림도 `<canvas>` 에 직접 그린다.
- 🔴 **HTTP 200 을 성공으로 읽지 마라**(조항 59). 지표가 없는 run 은 200 을 주면서
  `곡선 수 = 0` 과 「비었다」를 낸다 — **그것이 정직한 답이다.**

### 이 창구의 자 — **주장하지 않음**

등록 규율 ②는 *자 없는 능력은 등록 불가* 다. 관측 창구에는 ρ 같은 성능 수치가 없다.
그래서 자를 **주장하지 않음** 쪽에서 세운다:

> **이 페이지는 모형 정량 주장을 내지 않는다.**

강제하는 방법 둘 —
① 이 창구가 내는 **모든 응답**이 `serve/layers.py:gate()` 의 **금지 꼴 다섯**을 지난다
(걸리면 **내용을 안 보낸다** · 조용히 고치지 않는다 · 노트 133),
② **지표가 없으면 곡선 점이 0개**다.
`serve/test_trainlog.py` 가 **미끼 3 + 음성 대조**로 그것을 잰다(노트 676 —
*"통과는 아무것도 말하지 않는다"*).

## 7. 🔴 기존 러너에 **세 줄로** 붙이는 법

> **이 팔은 다른 코드에 로깅을 안 심었다.** 아래는 주 세션이 붙일 때의 본이다.
> (`lab/semtoken908.py` · `state/ssl909.py` 는 다른 에이전트가 쓰는 중이라 **열지도 않았다**.)

### 가. 이미 학습 루프가 있는 러너

```python
from trainlog import Run                                       # ① 들여온다

with Run("909-ssl", pushes="③", ruler="소수 라벨 곡선 k=8·16·32·64·128",
         seed=SEED, hparams=CFG,
         data=["data/records/…jsonl"], code=__file__) as r:     # ② 감싼다
    r.arch(model)
    for step, batch in enumerate(loader):
        loss = train_step(batch)
        r.log(step=step, split="train", loss=float(loss))       # ③ 한 줄 적는다
```

- `code=__file__` 을 **주는 편이 낫다.** 안 주면 `Run` 을 만든 바깥 프레임을 찾는데,
  `python3 -m …` 껍데기를 건너뛰긴 해도 여러 겹으로 감싼 러너에서는 엉뚱한 파일을
  집을 수 있다(🔴 처음엔 표준 라이브러리를 안 건너뛰어 **`runpy.py`** 를 해시했다).
- `pushes` 는 **반드시** 적는다. 미는 게 없으면 `pushes="해당 없음"` 이라고 **적는다**.
- 자가 없으면 `ruler` 를 비워 둔다 — 기록은 되고 화면에 **🔴 자 없음**으로 뜬다.

### 나. torch 를 안 쓰는 학습(회귀·부스팅·직접 짠 것)

```python
r.arch({"층": [{"id": "ridge", "종류": "Ridge", "입력 뉴런 수": 128, "뉴런 수": 1}],
        "간선": []})
```

### 다. 아키텍처를 못 적을 때

`r.arch()` 를 **안 부르면** `arch.json` 에 「못 읽음」이 남는다 —
그것이 **빈 그래프보다 정직하다.** 억지로 채우지 마라.

## 8. 이 규격이 **안** 하는 것

- **학습을 안 돌린다.** `trainlog` 는 기록기이고 `/trainlog` 는 관측 창구다.
- **분산 학습을 안 다룬다.** run 하나 = 프로세스 하나로 본다(여러 랭크가 같은
  `run_id` 에 쓰는 경우는 판 1.0.0 이 정의하지 않는다 — **「없다」가 아니라 「아직 안 정했다」**).
- **곡선을 비교하지 않는다.** 두 run 을 겹쳐 보는 화면은 아직 없다(한 run 안에서
  split 을 겹칠 뿐이다).
- **점을 만들지 않는다.** 보간·평활·외삽이 한 줄도 없다. 점이 2,000개를 넘으면
  솎되 **솎았다고 적는다.**
