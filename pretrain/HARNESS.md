# 하네스 플레이북 — 월드모델을 도구로 쓰는 LLM 의 규약

**구조**: 사용자 자유 질문 → 하네스 LLM(Claude) → `wm_*` 도구 호출(여러 번) → 합성 답.
**등록**: 저장소 루트 `.mcp.json` — 이 저장소에서 여는 Claude Code 세션은 `wm_*` 도구 전부(MANIFEST 가 정본 — 수는 MANIFEST 를 세라 · 2026-08-19 시점 11종)를 자동으로 가진다.
(HTTP 하네스는 `serve.py` 의 `/api/…` · 프로그램은 `from pretrain import wm_tools; wm_tools.call(name, args)`.
⚠ 상시 창구 8899 는 재시작 금지 — MANIFEST 에 «새로» 든 도구는 창구 재시작 «후»에야 8899 경유 소비자에 반영된다.)

## 철칙 여섯

1. 🔴 **낯선 질문이면 `wm_model_card` 먼저** — 할 수 있는 일·도메인·성적·«원리상 못 하는 것»이 계약으로 온다. 커버리지 밖이면 **밖이라고 말하고** 가장 가까운 근사를 제안한다.
2. 🔴 **미래 질문엔 «하나»가 아니라 «앙상블»을 돌려라** — `wm_compare` 에 변환 시나리오 여러 개(시점 ±·초기 관심 ±·추세 ±)를 한 번에. 답은 「최적 시나리오 + 차이의 크기」다.
3. 🔴 **수치를 지어내지 마라** — 답의 모든 수는 도구 응답에서. 곡선도 지어내지 말고 변환 연산(`curve_scale` 등)으로만 조합.
4. 🔴 **답 형식 고정**: ① 결론(수 + q05~q95 구간) ② 근거 사례(`wm_similar` — 실패 사례 포함) ③ 리스크 시점(`wm_risk`) ④ 민감도/대안(`wm_compare`) ⑤ ⚠ 한계(도구가 준 것 그대로 — 특히 «인과 아님». 🔴 덮개율·MdAPE 등 현행 성적은 배포 `report.json` 을 읽는 도구 ⚠(`wm_tools._caveat`)이 정본이다 — 이 문서에 수를 박아 두지 않는다. #142 ⑤ 수리(2026-08-19): 낡은 「덮개율 59.6%」 하드코딩 제거 — 당시 report 실측은 91.7%였다).
5. 🔴 **인과 단어 금지** — 「~하면 ~된다」가 아니라 「~인 입력에서 모형은 ~를 예측한다」. 개입 효과 주장은 A/B 실험 몫이라고 말한다.
6. 🔴 **거절은 최후 수단이다 — 답의 형태를 사다리로 낮춰서라도 유추 경로를 제시한다**(사이클 1007 — 실전 질문 2연속 거절이 만든 조항):
   **① 모형 점추정+구간**(곡선 있음) → **② 참조군 분포**(콜드스타트 — `wm_coldstart`) → **③ 인접 도메인 참조군**(도메인 밖 — 라벨 필수) → **④ 일반 지식**(모형 근거 아님 라벨).
   각 층은 자기 라벨을 달고, **위 층이 가능한데 아래 층으로 도망가면 안 된다.** 신작이라고 `wm_forecast` 에 0 곡선을 넣어 「학습 밖」으로 끝내는 것이 정확히 이 조항 위반이다.
   🔴 **④ 층 수치 규율(#142 사소 ㉲)**: ④ 층에서 수를 말하려면 「모형 근거 아님」 라벨에 더해 그 수의 «출처»를 명시해야 한다 — 철칙 3(모든 수는 도구 응답에서)과의 충돌을 라벨+출처로만 비켜간다. 출처를 못 대는 수는 ④ 층에서도 못 쓴다. 이 사다리는 거절을 답으로 바꾸는 규칙이지 라벨(수치 지어내기 금지 · 인과 화법 금지 · OOD 통과)을 무르는 규칙이 아니다.

## 질문 유형 → 도구 계획

| 유형 | 예 | 계획 |
|---|---|---|
| 예측 | 「얼마나 갈까?」 | 🔴 **`council` 먼저**(방법 4 비교·검증 성적 채택·불일치 폭) → `similar`(근거) → `risk`(단서). `forecast` 는 구간 세부용 |
| 신작(콜드스타트) | 「이 기획, 내면 얼마나?」(연재·출시 전 · 곡선 없음) | 🔴 **`coldstart`**(기획 텍스트+도메인 → 도메인 기후값 분위수(정본 — 1007 §11 티처 #142 처분 재등록) + 유사 실작 참조군의 «실측» 90일 분위수·명단(참고 — 쌍둥이 ⚠)). 0 곡선 `forecast` 금지 — 거절이 아니라 참조군 답(철칙 6-②). ⚠라벨: 눈금은 위키 조회(플랫폼 지표 아님) · 최초 관측 정렬(데뷔 곡선 아님) · 쌍둥이 제외 시 기후값과 비김(1007 §7·§11 — 그래서 정본이 기후값이다) |
| 결정 | 「12월 vs 3월 오픈?」 | `compare`(변환 앙상블) → 각 승자에 `risk` → 결론+차이 크기 |
| 진단 | 「왜 안 뜨지/뭐가 문제?」 | `similar`(주저앉은 사례 포함) → `compare`(끌어올릴 지렛대 후보) — «민감도» 라벨 필수 |
| 시점 | 「언제 위험/재판단?」 | `risk` — 하방 열리는 날 · 불확실성 최대 주 |
| 담론 | 「이 문구 자연스러워?」 | `surprisal` — 시대별 모델 서기 전까진 거친 자임을 명시 |
| 여론 | 「요즘 X 반응 어때?」 | `discourse`(실측 스트림 검색 + LM 자연스러움) — «예측» 아님 라벨 필수. 시대별 모델(큐 대기)·페르소나 뱅크가 다음 단 |
| 데이터 신뢰 | (답하기 전 상시) | 🔴 **`data_health`** — 원천이 12h+ 조용하면 답에 그 사실을 밝혀라 |
| 신뢰 | 「이거 믿어도 돼?」 | `entity` 몇 개(예측 대 실제) + `model_card` 성적표 |
| 범위 밖 | 지식 질답 · 인과 · 미학습 도메인 | `model_card` 로 확인 → 못 한다고 말하고 대안 제시 |

## 예시 궤적 (결정형)

> **Q. 「신작 팝업, 일평균 200 예상. 12월 오픈이 나은가 3월인가? 리스크는?」**
```
wm_compare(base={curve:200, domain:"팝업", date:"2026-12-01"},
           variants=[{name:"3월로", date_shift_months:3},
                     {name:"12월+초기부스트", curve_scale:1.2},
                     {name:"3월+초기부스트", date_shift_months:3, curve_scale:1.2}])
wm_risk(승자 설정)  ·  wm_similar(승자 설정)
→ 합성: 「12월이 3월보다 q50 X% 위(구간 겹침 여부 명시). 위험 창은 N일째부터,
   재판단 시점은 M주째. 비슷한 사례 셋 중 하나는 0.4× 로 주저앉았는데 …
   ⚠ 시점 차이는 모형 민감도이지 인과 검증이 아니다.」
```

## 확장 예약(코드에 자리 있음)

- `--text-emb`: tiny-v1 완주 → **기획서 «텍스트»를 조건으로** 한 forecast/compare
- 시대별 LM: `wm_surprisal(model="tiny@block1")` — 개념 진입 시점 곡선
- 여론: 인터뷰 전사문 페르소나 뱅크(수집은 오프라인 일) — 이 하네스에 도구로 추가
